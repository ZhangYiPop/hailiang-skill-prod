# 逻辑调试台

用来检查当前这套 agent 代码有没有按预期往下走。它不经过产品前端，直接调用 `MainPlannerOrchestrator.handle_message`，再把这一轮新增的事件、回复和表单摊开。

启动：

```bash
cd agent-debug-console
./start.sh
```

浏览器打开 `http://127.0.0.1:8765`。

- 入口可以选专家团、单个专家，或不进专家。
- 同一会话会保留上下文。表单出现后，页面上的「按这个表单继续」会把答案写成下一句用户消息，方便看已答题会不会被再问。
- 「新开会话」会丢掉当前上下文。
- 第一次提问会加载运行时，可能要等一会儿。
