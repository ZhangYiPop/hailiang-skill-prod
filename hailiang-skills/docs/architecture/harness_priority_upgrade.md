# Harness 优先级改造进展

2026-10-18，基于独立工作树现有 v2。默认仍为 v1，未自动重启用户服务。

## 本轮落地：P0 与 P1 首批

### 对象隔离

新增主 agent 的 `set_task_subject(mode, evidence)`。必须在分派之前调用，evidence 须出现在用户原文或已提交答案中；external 模式不允许读取当前 profile/session/user 事实，仅使用当前任务树事实。模型不能指定其他用户或档案身份。模型上下文和工具适配层都应用过滤，原档案数据不修改；外部对象的追问及事实写入限定 task 范围。切换时去除继承的旧会话历史与摘要。

这是显式协议，不是按“替别人”几个字自动识别所有语义。模型仍须正确调用对象工具；此部分需继续真实对话验证。分派后的对象变更被拒绝，避免修改已有子任务的语义；用户需新 run 讨论新对象。

### 执行与完成约束

新建 v2 run 记录 `execution_contract_version=v1`，旧 run 缺少该值仍可读取旧文本结果。新专家／Skill 使用 submit_result 结束任务；普通文本只允许一次协议修正，再次不遵循则显式失败，不把问题文本自动转成虚构卡片。completed 不能携带 unresolved，也不能跳过失败、未结束或部分完成的直接子任务。

供应商 finish_reason=length 时保存 usage 与原始输出，但不作为完成结果。主 agent 有失败或取消的直属任务时不能发布模型编造的完整结论，整轮失败，给出中性未完成说明。当前直接任务按必要任务处理，尚未增加可选任务分类；部分完成的业务语义与更细的验收条件仍需后续完善。

主 agent 能看到子任务问答状态；仅传字段与状态，不重复注入答案全文。不会将模型失败转成用户缺信息。

### 证据读取体积

在此前版本哈希修复上，read_evidence 对整个 JSON 返回包计量，包含正文转义后的体积，按字符片段缩小并更新 continuation offset。原文留存，可分页无损读取；不是机械截断有效事实或用户答案。其他工具的保护内容仍由上下文保护机制处理，并非所有工具都能无限缩小。

### 精准资料工具

新增 `read_skill_asset`，只对已有本地资料检索权限的 Skill 开放。主 agent 限独立 Skill，专家限自己的授权 Skill，Skill 节点限自身。只从已加载的资料注册表匹配来源，不接受任意文件系统路径。

- source 省略：分页列资料目录。
- JSON 记录数组：filters 精确字段匹配；score 匹配 min_score/max_score 的闭区间；记录分页。
- 普通文本：按字符偏移和长度读取。
- 错误类型、权限、总工具次数、崩溃后只读重试仍受运行时管理。

匹配记录不表示当年招生承诺。年份、口径缺失不能被当作已知，资料内部筛选条件不能未经核验表述成官方资格条件。

### 主 agent 阶段收敛

根据直接子任务终态区分 planning/synthesis；汇总阶段隐藏能力目录，只提供 read_facts/read_evidence/request_user_input/propose_fact_updates 工具。模型可继续核对事实和必要信息，不能在汇总阶段重开专家分派或搜索。事实变化使任务重新排队时回到 planning。阶段进入 trace diagnostics，不增加模型调用。
