# 海亮 Skills 正式服务器发版手册

本文用于已经完成基础环境初始化的服务器。服务器采用单节点部署：PostgreSQL、Redis 运行在本机 Docker 中，API 和内部前端由 systemd 管理。

## 一、发版原则

- 每次代码修改都必须使用新的版本号，例如 `4.11.0.1_bug_fix_3`。
- 代码发布到 `/opt/hailiang-skills/releases/<版本号>`，禁止直接修改 `current`、`current-test` 或 `current-prod`。
- 统一使用 `deploy/bin/deploy-version.sh` 完成构建和发布。
- 固定顺序：测试环境发布并验证 → 正式数据库备份 → 正式环境发布并验证。
- 数据库迁移只允许向前兼容；应用回滚不会自动回滚 SQL。
- 环境文件包含密钥，禁止提交 Git、复制到聊天或写入普通日志。

## 二、服务器固定信息

以下内容以实际服务器为准，示例中的地址和端口如有变化，必须以 `/etc/hailiang-skills/*.env` 为准。

```bash
SERVER_HOST=10.153.3.146
SSH_PORT=51180
SOURCE_ROOT=/home/hljy/tmp/hailiang-skill_sensitive_v02121_2
PYTHON_BIN=/usr/local/bin/python3.11
PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple
```

登录服务器：

```bash
ssh -p 51180 hljy@10.153.3.146
```

## 三、每次发版前准备代码包

在本地完成代码修改和测试后，给本次发布分配唯一版本号，例如：

```bash
VERSION=4.11.0.1_bug_fix_3
```

将源码包上传到服务器。源码根目录必须同时包含：

```text
<SOURCE_ROOT>/hailiang-skills/
<SOURCE_ROOT>/agent_skill_runtime_core/
```

Mac 示例：

```bash
scp -P 51180 -r \
  /Users/ayi/Project/hailiang-skill_sensitive_v02121_2 \
  hljy@10.153.3.146:/home/hljy/tmp/
```

确认服务器目录：

```bash
export SOURCE_ROOT=/home/hljy/tmp/hailiang-skill_sensitive_v02121_2
export VERSION=4.11.0.1_bug_fix_3

ls -la "$SOURCE_ROOT/hailiang-skills/pyproject.toml"
ls -la "$SOURCE_ROOT/agent_skill_runtime_core/agent_skill_runtime_core"
```

## 四、首次部署或版本发布脚本准备

确保当前源码包中包含最新的发布脚本：

```bash
cd "$SOURCE_ROOT/hailiang-skills"
chmod +x deploy/bin/deploy-version.sh
bash -n deploy/bin/deploy-version.sh
```

如果脚本不是随代码包一起上传，可单独从本地上传：

```bash
scp -P 51180 \
  /Users/ayi/Project/hailiang-skill_sensitive_v02121/hailiang-skills/deploy/bin/deploy-version.sh \
  hljy@10.153.3.146:"$SOURCE_ROOT/hailiang-skills/deploy/bin/deploy-version.sh"
```

检查 Python：

```bash
"$PYTHON_BIN" --version
sudo "$PYTHON_BIN" --version
```

应为 Python 3.11.x。

## 五、检查测试和正式环境文件

查看非敏感配置：

```bash
sudo grep -E '^(HAILIANG_DEPLOY_ENV|HAILIANG_RELEASE_VERSION|HAILIANG_BIND_HOST|BACKEND_PORT|FRONTEND_PORT|HAILIANG_DATABASE_URL|HAILIANG_REDIS_URL|HAILIANG_REDIS_KEY_PREFIX)=' \
  /etc/hailiang-skills/test.env

sudo grep -E '^(HAILIANG_DEPLOY_ENV|HAILIANG_RELEASE_VERSION|HAILIANG_BIND_HOST|BACKEND_PORT|FRONTEND_PORT|HAILIANG_DATABASE_URL|HAILIANG_REDIS_URL|HAILIANG_REDIS_KEY_PREFIX)=' \
  /etc/hailiang-skills/prod.env
```

测试环境必须满足：

```text
HAILIANG_DEPLOY_ENV=test
HAILIANG_DATABASE_URL=...@127.0.0.1:5432/hailiang_skills_test
HAILIANG_REDIS_URL=redis://127.0.0.1:6379/1
HAILIANG_REDIS_KEY_PREFIX=hailiang:test:
BACKEND_PORT=8010
FRONTEND_PORT=4175
```

正式环境必须满足：

```text
HAILIANG_DEPLOY_ENV=prod
HAILIANG_DATABASE_URL=...@127.0.0.1:5432/hailiang_skills
HAILIANG_REDIS_URL=redis://127.0.0.1:6379/2
HAILIANG_REDIS_KEY_PREFIX=hailiang:prod:
BACKEND_PORT=8015
FRONTEND_PORT=4176
```

数据库主机应为 `127.0.0.1`，不能写成 Docker 网络名 `postgres`。确认权限：

```bash
sudo chmod 600 /etc/hailiang-skills/test.env /etc/hailiang-skills/prod.env
```

## 六、发布测试环境

先执行测试环境发布：

```bash
cd "$SOURCE_ROOT/hailiang-skills"

sudo env \
  PYTHON_BIN=/usr/local/bin/python3.11 \
  PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple \
  INSTALL_MS_AGENT_RUNTIME=auto \
  ./deploy/bin/deploy-version.sh \
  test \
  "$VERSION" \
  "$SOURCE_ROOT"
```

脚本会自动：

- 创建 `/opt/hailiang-skills/releases/$VERSION`；
- 创建 Python 虚拟环境并安装依赖；
- 同步 `agent_skill_runtime_core`；
- 更新 `test.env` 的版本号；
- 执行测试数据库迁移；
- 构建前端；
- 切换 `current-test`；
- 重启测试 API 和前端；
- 执行健康检查。

验证测试版本：

```bash
readlink -f /opt/hailiang-skills/current-test
cat /opt/hailiang-skills/current-test/VERSION
systemctl is-active hailiang-skills-api@test.service
systemctl is-active hailiang-skills-web@test.service
curl -i http://10.153.3.146:8010/health/ready
curl -I http://10.153.3.146:4175/
```

API 返回 JSON 中必须包含：

```json
"status":"ok",
"environment":"test",
"version":"4.11.0.1_bug_fix_3",
"postgres":true,
"redis":true,
"llm_rate_limiter":true
```

## 七、发布正式环境

只有测试环境验证通过后，才执行正式发布。正式发布仍使用同一个 release，不需要重新上传或重新安装依赖：

```bash
cd "$SOURCE_ROOT/hailiang-skills"

sudo env \
  PYTHON_BIN=/usr/local/bin/python3.11 \
  PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple \
  INSTALL_MS_AGENT_RUNTIME=auto \
  ./deploy/bin/deploy-version.sh \
  prod \
  "$VERSION" \
  "$SOURCE_ROOT"
```

正式发布自动执行：

1. 备份正式数据库；
2. 执行 Alembic 前向迁移；
3. 构建前端；
4. 更新 `prod.env` 的版本号；
5. 切换 `current-prod` 和 `current`；
6. 重启正式 API 和前端服务；
7. 检查正式 API 和前端可用性。

验证正式版本：

```bash
readlink -f /opt/hailiang-skills/current-prod
readlink -f /opt/hailiang-skills/current
cat /opt/hailiang-skills/current-prod/VERSION

systemctl is-active hailiang-skills-api@prod.service
systemctl is-active hailiang-skills-web@prod.service

curl -i http://10.153.3.146:8015/health/ready
curl -I http://10.153.3.146:4176/
```

正式 API 返回应包含：

```json
"status":"ok",
"environment":"prod",
"version":"4.11.0.1_bug_fix_3",
"postgres":true,
"redis":true,
"llm_rate_limiter":true
```

确认数据库备份已生成：

```bash
ls -lh /var/lib/hailiang-skills/prod/backups/
```

## 八、回滚应用版本

回滚只回退应用软链接，不回滚数据库迁移：

```bash
sudo /opt/hailiang-skills/current-prod/deploy/bin/rollback-prod.sh
```

验证回滚结果：

```bash
readlink -f /opt/hailiang-skills/current-prod
curl -fsS http://10.153.3.146:8015/health/ready
```

如果数据库迁移已经执行，旧应用必须兼容新的数据库结构；禁止直接执行未经验证的 SQL 回滚。

## 九、常见问题排查

### 1. `python3.11 is required`

确认路径：

```bash
ls -l /usr/local/bin/python3.11
sudo /usr/local/bin/python3.11 --version
```

执行时显式指定：

```bash
sudo env PYTHON_BIN=/usr/local/bin/python3.11 \
  ./deploy/bin/deploy-version.sh test "$VERSION" "$SOURCE_ROOT"
```

### 2. `failed to resolve host 'postgres'`

说明当前环境变量没有正确加载。检查：

```bash
sudo grep '^HAILIANG_DATABASE_URL=' /etc/hailiang-skills/test.env
sudo grep '^HAILIANG_DATABASE_URL=' /etc/hailiang-skills/prod.env
```

数据库地址必须使用 `127.0.0.1`。更新脚本后重新执行发布，不要直接在旧 release 上修改。

### 3. `release already exists`

说明该版本目录已经存在。先检查：

```bash
ls -la /opt/hailiang-skills/releases/$VERSION
```

如果是失败的半成品，保留证据后移动：

```bash
sudo mv /opt/hailiang-skills/releases/$VERSION \
  /opt/hailiang-skills/releases/${VERSION}.failed
```

然后使用相同版本重新发布。

### 4. 服务启动失败

```bash
journalctl -u hailiang-skills-api@test.service -n 150 --no-pager
journalctl -u hailiang-skills-api@prod.service -n 150 --no-pager
journalctl -u hailiang-skills-web@prod.service -n 100 --no-pager
```

检查当前软链接和版本：

```bash
readlink -f /opt/hailiang-skills/current-prod
cat /opt/hailiang-skills/current-prod/VERSION
```

### 5. Pillow 或旧 GCC 编译失败

部署脚本会优先安装二进制 wheel，并使用国内镜像。如果仍失败，确认脚本是最新版本，并保留完整 pip 输出。不要直接修改系统 Python。

### 6. 前端 200 但页面异常

检查前端服务和构建目录：

```bash
systemctl status hailiang-skills-web@prod.service --no-pager
ls -la /opt/hailiang-skills/current-prod/frontend/dist
curl -I http://10.153.3.146:4176/
```
