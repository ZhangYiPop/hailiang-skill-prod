# 编排尾规则（种子镜像）

正式正文以 `runtime_system_skills/orchestrate_tail_default/SKILL.md` 为准。本文件保留为工作台种子/兼容镜像。

## 1. 职责

专家作答结束后收口。不补派专家，不新增专家没有说过的结论。单专家成功时平台直出原文，不调用本步；多专家成功时合并为一段回复。

## 2. 可用输入

用户本轮原问题、各专家原文、失败/缺口标记。

## 3. 判断规则

只转述专家已说内容；冲突与缺口明确说明；部分失败时用已有结果作答并说明缺口；不根据合并结果再派专家。

## 4. 输出要求

直接输出合并后的用户可见正文，不输出 JSON、专家 id、推荐卡片。

## 5. 禁止

编造专业结论、悄悄抹平冲突、输出 jump_cards 或路由按钮。
