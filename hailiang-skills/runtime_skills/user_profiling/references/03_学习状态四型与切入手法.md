# 孩子的学习状态怎么判、怎么用（内部）

> 这一项**只影响怎么开口、用什么办法帮，不影响给什么方向**。不进画像网格，也不是必采项。
> 四种类型的名字是内部叫法，一个字都别说出口。

按「孩子自己想不想学」和「别人催管有没有用」两条轴，分四种：

| 内部叫法 | 听到这些就往这边归 | 怎么切入 |
|---|---|---|
| 自主高效 | 目标清楚、自己会安排、不用怎么管 | 少干预，给资源和进阶建议就够 |
| 自驱抗管 | 有自己的想法和节奏、一催就烦、一管就逆反 | 尊重自主权，给选择而不是下命令，给方法别施压 |
| 任务驱动 | 自己不太主动，但有人盯就动、给了任务就做 | 靠外部机制补动力：计划表、陪伴、打卡、托管 |
| 推不动 | 既没动力又抵触管，怎么推都不动，容易对抗 | 先别硬压。修复关系、找到意义、降低冲突，必要时找专业帮助 |

**用法**：同样年级、同样成绩的两个孩子，一个要给他选择权，一个要先帮他把机制建起来。方向完全一样，开口的方式不一样。

## 怎么判

不用专门问，从家长的话里捡就行：

- 「说了不听」「一管就吵」→ 自驱抗管或推不动
- 「盯着就写，不盯就玩」→ 任务驱动
- 「他自己知道该干嘛」→ 自主高效
- 「怎么说都没反应」「躺那儿不动」→ 推不动

判不出来就空着。这一项没有比判错强。

## 和学习指导师怎么分

你判学习状态，是为了决定**这次对话怎么开口**。

一旦话题落到「具体怎么建机制」「用什么计划表」「怎么改掉拖延」——这是方法问题，交给学习指导师，别自己展开讲一套体系。

**一个例外**：判成「推不动」且伴随情绪信号（长期低落、拒绝上学、把自己关起来），这不是学习方法问题，走家庭教育兜底话术库的二级，**不转学习指导师**。转过去等于把一个情绪问题当成懒来处理。
