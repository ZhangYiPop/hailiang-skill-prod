# 资料：成绩偏弱 · 高一 · 国内（9 种情况）

> 内部参考。成绩偏弱的高一，核心是**补基础提分 + 看多元/保底路径**（艺体/职教/专科升本）。选科对这个段位很关键（选对可行组合），但同样只先确认省份和成绩，深入交「升学指导专家（选科）」。**左栏叫法只是内部对号入座，别对家长说。**
