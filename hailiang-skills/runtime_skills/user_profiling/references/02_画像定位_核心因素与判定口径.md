# 定位一个孩子要哪几项信息（内部）

> 这是你内部判断的标尺。**对用户只用口语**——成绩说「比较靠前 / 中等 / 暂时偏弱」，不要说档位名，也别提「学段」「画像」这类词。

## 五个核心因素

用最少的信息把人群分开，只有这几项进网格：

| 因素 | 字段 | 什么时候要 |
|---|---|---|
| 升学方向 | `education_direction` | 初三及以上尽量确认；之前默认「国内·未定」 |
| 年级阶段 | `grade` | 所有情况的硬前提 |
| 成绩档 | `score_band` | 小学低段不采；其余都要 |
| 兴趣特长型 | `talent_type` | 全学段。五型判定见 `04` |
| 选科倾向 | `subject_preference` | 只有高中要，且只在国内线 |

**学习状态** `learning_state` 不进网格。它只影响「怎么开口帮」，不影响给什么方向，判定见 `03`。

其余信息（省份、预算、地域偏好、意向专业、特殊身份等）都是长尾，**主Agent 不主动采**，交给专家在具体场景里问。

---

## Step 0 · 升学方向

这是最高层的分叉，它决定后面用哪一套成绩轴、哪一套路径逻辑。

- **国内线**：默认值。走国内成绩轴
- **国际线**：走国际成绩轴，年段不细分，合并成「高中阶段」

怎么判：家长自己提出国、国际学校、双语学校、不想卷高考、A-Level、IB、AP、托福雅思，就往国际线上归。**但只是随口提一句「实在不行就出国」不算**，那是情绪不是方向，先聊清意愿再定。

国际线一旦确定，经济投入会从长尾升格成必问项——但这个问题交给留学咨询师，你不问。

---

## Step 1 · 年级阶段

- 小学：低段（一到三年级）／高段（四到六年级）。探索期，容错大，重点是养兴趣和习惯
- 初中：初一初二／初三。关键决策期
- 高中：高一／高二／高三。容错小，选科和路径的影响直接

## Step 2 · 成绩档

### 国内线

| 年级 | 比较靠前 | 中等 | 暂时偏弱 |
|---|---|---|---|
| 小学高段 | 班级前 30%，或得分率高 | 中间 40% | 后 30%，或得分率低 |
| 初一初二 | 重高线以上 | 普高到重高之间 | 普高线以下 |
| 初三 | 有把握上重高或优高 | 有把握上普高 | 普高线以下 |
| 高一 | 年级前 30% | 中间 40% | 后 30% |
| 高二 | 年级前 30% 且学考达标 | 中间 40% | 后 30% |
| 高三 | 见下方五档 | | |

小学低段不采成绩档。

**高三细分五档**（临考期用这套更准，主要看选考总分预估位次）：

| 内部档位 | 大致含义 | 对用户怎么说 |
|---|---|---|
| 稳定特控 | 位次稳在特控线以上 | 稳上重点线 |
| 特控临界 | 卡在特控线上下浮动 | 卡在重点线附近 |
| 稳定一段 | 稳在本科线以上、够不到特控 | 稳上本科 |
| 本科临界 | 卡在本科线上下浮动 | 卡在本科线附近 |
| 二段及以下 | 本科暂时无望 | 目前够专科，本科还得再拼 |

各省市划线不同。**拿不准就按相对位置谈**（靠前 / 中间 / 靠后），别硬套线。

### 国际线

年段不细分，高中合并成一档看：

| 内部档位 | 判断依据 | 大致对应 |
|---|---|---|
| 上游 | GPA 与标化双高 | 冲世界前 30 / G5 / 藤校 |
| 中游 | GPA 中上、标化达标 | 世界前 100 / 主流名校 |
| 下游 | 标化或语言尚未达标 | 保底校 / 双录取 / 语言桥梁 |

取数看 GPA 加标化或语言成绩，按目标地区（美 / 英 / 澳加 / 港新）的口径来。

**初中段的国际线口径未定**，遇到就不定档，只记 `education_direction=国际`，把人交给留学咨询师。

五型的判定信号和对用户怎么描述，见 `04_画像网格_索引与五型.md`。

## Step 4 · 选科倾向（只有高中国内线要）

- 高一：未定向（含文理均衡）／偏文／偏理
- 高二、高三：已选科的直接记选科结果

文和理各对应一套完全不同的策略——专业范围、竞赛、志愿逻辑都不一样，所以这一项在高中必须采。

国际线不看文理，看标化和申请方向，那是留学咨询师的事。

## 怎么把这些问出来

**不要连着问。** 一轮一个，而且包在「给」里面。

| 要采 | 别这么问 | 这么问 |
|---|---|---|
| 年级 | 请问孩子几年级？ | （开场）孩子现在几年级了？ |
| 成绩档 | 孩子成绩多少分？ | 大概在班里（年级里）什么位置？前面一点、中间、还是暂时靠后？ |
| 升学方向 | 你们考虑国际路线吗？ | （只在用户提到国际、民办、不想卷时才问）你们是在考虑体制外这条路，还是先按国内走？ |
| 兴趣特长 | 孩子有什么特长？ | 孩子平时有没有比较愿意花时间的事？ |
| 选科倾向 | 孩子选科倾向是什么？ | （高一）文科理科这边，孩子自己有偏好吗？ |

从对话里直接捡，别专门问：

- 「他小学就没坐得住过」→ 学习状态
- 「我们打算送出去读」→ 升学方向
- 「班上四十几个人他二十来名」→ 成绩档
- 「画画学了六年，考过八级」→ 兴趣特长型偏特长发力

**用户没明说的，只能记成待确认，不能当成已确认。** 下次开口带着错信息，比不知道更伤。
