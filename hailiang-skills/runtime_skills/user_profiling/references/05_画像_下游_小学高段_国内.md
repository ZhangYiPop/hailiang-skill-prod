# 资料：成绩偏弱 · 小学高段（G4-6）· 国内（5 种情况）

> 内部参考。小学成绩波动大，暂时落后不代表以后；这阶段核心是**降焦虑、建自信、养习惯、别过早定性**，不要和升学挂钩。成绩偏弱=班里靠后。特长以兴趣深化为主。**左栏的叫法只是内部对号入座用，别对家长说。**

| 孩子情况（内部） | 通俗描述 | 家长常问 | 怎么聊（先后分寸） | 给的方向 | 可转介的专家 |
|----------|---------|---------|------------------|---------|--------------|
| 还没怎么探索过 | 成绩偏弱、也没什么特别喜欢的 | - 成绩不好也没兴趣怎么办？<br>- 要不要补课/留级？<br>- 怎么提积极性？ | 小学成绩波动大、暂时落后不代表以后，别对立；先从他能做好的小事里建"我能学会"的自信 | ① 从最基础处建自信，让他体验做得到；② 抓最基础的习惯（预习、作业）；③ 多尝试找闪光点 | 特长发展专家 |
| 兴趣广没聚焦 | 成绩偏弱、但什么都愿意玩 | - 光爱玩不爱学怎么办？<br>- 兴趣能帮上忙吗？<br>- 怎么带动学习？ | 有兴趣是好支点，用他喜欢的事建自信、带动学习，别一味压分数 | ① 用兴趣建自信；② 抓最基础的学习习惯；③ 别盲目补课 | 特长发展专家 |
| 能力还行、兴趣一般 | 成绩偏弱但其实学得动、就是没劲没信心 | - 明明不笨怎么就是不学？<br>- 怎么让他有动力？ | 他能学，缺的是动力和信心；先修复动机和亲子关系，用他擅长的事带动 | ① 先修复学习动机、降对立；② 用相对好的科目建自信；③ 抓方法 | 特长发展专家 |
| 很喜欢但能力没跟上 | 成绩偏弱、但对某方向很有热情 | - 成绩不好但很喜欢 XX，要不要发展？<br>- 会不会耽误学习？ | 这份热情很重要，是他的自信来源；学业保底即可，别两头施压 | ① 兴趣作为核心支点保持投入；② 学业保底、不追排名；③ 条件允许可考虑更重个性化的环境（家长提了再聊） | 特长发展专家 |
| 有成型特长 | 成绩偏弱 + 已有拿得出手的特长 | - 成绩不好但有特长，以后能走这条路吗？<br>- 要不要重点培养？ | 特长可能是他将来"换赛道"的关键；小学先深化兴趣、建自信，家长若问可提将来艺体/特色这条路 | ① 特长深化、当自信来源；② 学业保底；③ 家长问长远，可提未来艺体/特色方向 | 特长发展专家 |
