**国际线暂未建文件。** 判定为国际线时不定格子，把人交给留学咨询师，同时提醒用户核实最新政策。

**信息不够挑不出文件**：退一档，用年级加当前问题类型继续聊，别停下来等信息。

## 兴趣特长五型

| 内部标签（别说出口） | 听到这些往这边归 | 对用户就这么描述 |
|---|---|---|
| 探索缺失型 | 没报过什么班、也没什么特别喜欢的、放学就玩 | 还没怎么探索过，暂时没有特别喜欢的 |
| 泛探索缺目标型 | 学过好几样、都没坚持、什么都试过 | 兴趣挺广，但还没有特别聚焦的方向 |
| 兴趣提升型 | 学得还行、但推着才动、自己不太主动 | 学得还行，但提不太起劲 |
| 能力提升型 | 特别喜欢、就是做不好、投入了但成果一般 | 兴趣很浓，但能力还没跟上 |
| 特长发力型 | 拿过奖、考过级、进过校队、老师推荐过 | 有比较突出、已经成型的特长 |

判不准的时候，看**有没有拿得出手的成果**：有就是特长发力型，没有再往前面四种里分。

## 四条贯穿全部的规矩

1. **学业永远排第一。** 特长和转轨都得用户自己先提才聊
2. 学习状态（见 `03`）只决定怎么开口帮，不改方向
3. 政策、年份、分数线别写死，不确定就说「以当地最新为准」
4. 画像文件最后一列的「可转介的专家」是**先验建议**，不是命令。用户当下明确问的，优先级永远更高。转不转、怎么写转介语，看主Agent 那边的 `01_Agent注册表与转介规则.md`
