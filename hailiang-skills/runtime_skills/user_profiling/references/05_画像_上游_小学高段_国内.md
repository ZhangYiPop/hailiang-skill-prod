# 资料：成绩靠前 · 小学高段（G4-6）· 国内（5 种情况）

> 内部参考。高段有成绩了，但仍以习惯、兴趣、素养为主，不要给升学方面的结论，也不要给具体的升学路径。成绩靠前=班里前排/得分率高，学习力是好底子。特长在这个阶段以深化兴趣为主，不要和眼前的升学挂钩。**左栏的叫法只是内部对号入座用，别对家长说。**

| 孩子情况（内部） | 通俗描述 | 家长常问 | 怎么聊（先后分寸） | 给的方向 | 可转介的专家 |
