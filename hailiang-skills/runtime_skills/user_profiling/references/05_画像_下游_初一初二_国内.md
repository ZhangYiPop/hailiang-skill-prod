# 资料：成绩偏弱 · 初一/初二 · 国内（4 种情况）

> 内部参考。这个成绩在普高线附近甚至线下，初中还有时间和窗口；核心是**提分冲普高 + 了解保底路径**（职教/民办/普职融通）。保底路径等家长自己担心、提起再聊。怎么按孩子状态开口看 `03`。**左栏的叫法只是内部对号入座用，别对家长说。这个阶段不做选科的提前规划。**

| 孩子情况（内部） | 通俗描述 | 家长常问 | 怎么聊（先后分寸） | 给的方向（先学业） | 可转介的专家 |
|----------|---------|---------|------------------|-----------------|--------------|
| 兴趣广没聚焦 | 成绩偏弱、兴趣广没定、缺方向感 | - 这成绩能上普高吗？<br>- 怎么提上去？<br>- 啥都试过没坚持要紧吗？ | 初中还有时间，先聚焦提分保普高；方向感能带出动力。家长担心考不上、提到职高/民办，才聊保底 | ① 提分保普高：补基础、抓习惯；② 兴趣收敛带动力；③ 家长担心普高没把握，可了解职教/民办等保底（家长提了才聊） | 升学指导专家（多元升学路径，家长问保底才推）<br>特长发展专家 |
| 能力还行、兴趣一般 | 成绩偏弱但学得动、就是没劲没信心 | - 明明能学怎么就是上不去？<br>- 怎么让他有动力？ | 他能学，缺的是动力和信心；先修动机、补基础冲普高 | ① 先修动机、补基础提分；② 优势科目建自信；③ 保底路径家长提了再聊 | 升学指导专家（多元升学路径，家长问才推） |
| 很喜欢但能力没跟上 | 成绩偏弱、对某方向兴趣浓 | - 成绩不好但很喜欢 XX，能走这条路吗？<br>- 是先补成绩还是发展这个？ | 常规提分压力大时，这个兴趣/特长可能是"换赛道"的关键；先看家长意愿 | ① 学业尽量保底、冲普高；② 家长愿意，可评估艺体/职教特色这条路；③ 文化课别彻底放 | 升学指导专家（多元升学路径，家长愿意走特色才推）<br>特长发展专家 |
| 有成型特长 | 成绩偏弱 + 已有拿得出手的特长 | - 成绩不好但有 XX 特长，能走什么路？<br>- 艺体/特长升学靠谱吗？ | 常规路径压力大，特长（艺体/科技等）可能是最现实的一条路；家长提了就重点聊特长生/艺体/职教特色 | ① 家长愿意，深入了解特长生/艺体/职教特色通道；② 守住这些通道要求的文化课底线；③ 必要时考虑特色校/转轨（家长提了） | 升学指导专家（多元升学路径，家长愿意走特长才推）<br>特长发展专家 |
