# 特长培养与升学应用检索规范

> 适用范围：Path B（方向深耕）场景
> 核心定位：只提供检索规范和信息结构模板，不预置方向知识
> 执行逻辑：用户说任何方向 → 检索公域信息 → 按模板组织 → 输出

---

## 一、检索关键词组合模板

| 检索目标 | 关键词模板 | 示例（方向：编程，城市：南京，年级：五年级） |
|---------|-----------|----------------------------------|
| 培养路径 | `{方向} 培养 {年级} 阶段 建议` | `编程 培养 小学阶段 建议` |
| 当地中考政策 | `{城市} 中考 {方向} 特长生 招生 2026` | `南京 中考 编程 特长生 招生 2026` |
| 当地高考政策 | `{城市所在省份} 综合评价 招生 2026` | `江苏 综合评价 招生 2026` |
| 赛事/考级 | `{方向} 比赛 白名单 2026` / `{方向} 考级 认证` | `编程 比赛 白名单 2026` |
| 升学路径 | `{方向} 升学 中考 高考 路径` | `编程 升学 中考 高考 路径` |
| 风险与门槛 | `{方向} 学习 风险 注意事项` | `编程 学习 风险 注意事项` |

**扩展规则**：
- 方向名称生僻时（如"马术""航模"），同时检索 `{方向} 特长生` 和 `{方向} 升学`
- 检索结果不足时，向上扩展至所属大类（如"书法"扩展检索"艺术特长生"）
- 小学年级重点检索"培养""启蒙"；初中年级重点检索"中考""特长生""竞赛"

---

## 二、来源优先级

| 优先级 | 来源类型 | 使用规则 |
|--------|---------|---------|
| P0 | 教育局/政府官网 | 优先采用，可直接引用 |
| P1 | 学校官方渠道 | 招生简章类可直接引用 |
| P2 | 阳光高考网/省教育考试院 | 高考政策类可直接引用 |
| P3 | 权威行业协会 | 赛事、考级标准可直接引用 |
| P4 | 主流媒体 | 政策解读类需交叉验证 |
| P5 | 培训机构/自媒体 | 禁止作为唯一来源 |

**交叉验证**：涉及具体数字（招生人数、降分幅度）时，需至少 2 个 P0-P2 来源确认。

## 三、信息结构模板（检索后按此结构组织）

### 结构一：培养路径

```
当前阶段：{根据年级和基础判断，1句话}
关键动作：
  1. {短期，3-6个月，1句话}
  2. {中期，1-2年，1句话}
  3. {长期，升学衔接，1句话}
常见风险：{普遍风险，1句话}
```

### 结构二：升学应用

```
中考路径：{当地政策要点或通用路径，1-2句话}
高考路径：{强基/综评/艺体/竞赛等路径，1-2句话}
关键节点：{赛事/考级名称、时间窗口，1句话}
```

## 四、输出填充规则（B4 模板对应）

B4 输出模板共 4 个字段，总字数（含标题、标点、空格）**不得超过 600 字**。

| B4 字段 | 填充来源 | 字数约束 |
|--------|---------|---------|
| 【当前阶段】 | 结构一：当前阶段 | ≤ 30 字 |
| 【培养建议】• 短期 | 结构一：关键动作 1 | ≤ 30 字 |
| 【培养建议】• 中期 | 结构一：关键动作 2 | ≤ 30 字 |
| 【培养建议】• 长期 | 结构一：关键动作 3 | ≤ 30 字 |
| 【升学应用】• 中考 | 结构二：中考路径 | ≤ 60 字 |
| 【升学应用】• 高考 | 结构二：高考路径 | ≤ 60 字 |
| 【注意】 | 结构一：常见风险 + 下一步建议 | ≤ 60 字 |

**字数计算方式**：按最终输出文本的字符数（含汉字、字母、数字、标点、空格）统计。

---

## 五、话术柔性要求（低自由度：MUST）

1. **禁止绝对化表述**：输出中不得出现"硬门槛""必要条件""绝对""必须""一定""肯定"等词汇。
2. **改用柔性表达**：
   - "需要" → "建议""通常"
   - "必须满足" → "一般要求""多数情况下"
   - "不满足则关闭" → "可能受影响""建议评估"
   - "禁止" → "不建议""需谨慎"
3. **政策表述**：用"据检索到的 XX 文件显示""目前公开信息表明"，不用"政策规定"
4. **风险提示**：用"常见风险是""建议留意"，不用"否则无法升学"

---

## 六、执行约束（低自由度：MUST）

1. **禁止编造**：不编造学校名称、招生人数、分数线、费用、通过率、政策原文。
2. **时效标注**：所有政策标注年份，附加"政策每年变化，以当年官方文件为准"。
3. **地域精准**：检索以用户城市为首要关键词，不套用其他城市政策。
4. **信息局限兜底**：检索不足时标注"公开信息有限，建议咨询当地教育局或目标学校"，不强行填充。
5. **不暴露检索过程**：不提及"我搜索了""我查到了"等过程性描述。
6. **禁止机构推荐**：不得推荐具体机构或学校名称，只用"具备 {资质} 的 {机构类型}"描述。
