## 一、标签定义

| 标签文案 | 内部类型 | 核心指向 |
|---|---|---|
| 喜欢问"为什么"，能自己琢磨一道题很久不烦躁，你跟孩子讲道理讲得通，但孩子也会反过来用逻辑反驳你 | 理科思维 | 逻辑推理、专注沉稳、探索驱动 |
| 看到新东西第一反应是上手拆、上手试。做事有条理，观察细致，经常注意到旁人没注意到的细节 | 实验探究 | 动手实践、观察洞察、归纳系统 |
| 精力旺盛，坐不住但运动时高度专注。摔了爬起来继续，天生有股不服输的劲儿 | 体育竞技 | 身体素质、意志韧性、竞争意识 |
| 对美有天然的敏感——听到一段音乐会停下来，看到好看的东西会盯着看很久，有自己的审美主张，而且想要表达出来 | 艺术感知 | 审美感知、表达表现、观察洞察 |
| 表达欲旺盛，爱模仿、爱表达，听到新词就会用，学语言不觉得苦，反而觉得有意思 | 语言沟通 | 模仿学习、表达表现 |
| 对"人"的事情特别敏感——谁开心了谁不高兴了，新闻里发生了什么，都会好奇，喜欢讨论、喜欢辩论，有自己的观点 | 人文素养 | 共情开放、探索驱动、自驱行动 |

## 二、标签 → 方向池映射

| 标签 | 对应二级方向 |
|---|---|
| 逻辑清晰，喜欢追问 | 数学特长、信息学特长、物理学特长 |
| 爱拆东西，想探究内部结构 | 机器人特长、科学创新特长、科技体育特长、化学特长、生物特长 |
| 精力旺盛，好胜心强 | 田径特长、舞蹈特长、水上运动特长、球类运动特长、武术特长 |
| 对声音、画面色彩十分敏感 | 美术特长、音乐特长 |
| 跟谁都能聊起来，也喜欢模仿别人说话 | 小语种能力培养、传媒特长 |
| 对"人"的经历和观点特别感兴趣 | 思辨能力、商业洞察、社会认知 |

## 三、方向池并集示例

- 单选"逻辑清晰，喜欢追问" → 方向池：{数学特长、信息学特长、物理学特长}
- 单选"爱拆东西，想探究内部结构" → 方向池：{化学特长、生物特长、机器人特长、科学创新特长、科技体育特长}
- 双选"逻辑清晰，喜欢追问 + 爱拆东西，想探究内部结构" → 方向池并集：{数学特长、信息学特长、机器人特长、科学创新特长}
- 双选"对声音、画面色彩十分敏感 + 精力旺盛，好胜心强" → 方向池并集：{美术特长、音乐特长、田径特长、舞蹈特长}
