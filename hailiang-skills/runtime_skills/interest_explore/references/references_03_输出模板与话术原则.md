## 一、R4 输出模板（严格）

```
基于您孩子的特质和经历，以下方向值得考虑（排序不代表优先级）：

1. {方向A}
   - 为什么推荐：基于您提到的 {经历/标签}，这说明孩子在 {特质} 方面有真实的表现。
   - 条件状态：年龄窗口开放 ✓ | 身体条件满足 ✓ | 预算可支撑（非必要）
   - 风险预警：{按方向特性标注，见下方二}
   - 起步建议：{按方向给出 2-3 步通用动作，见 [references_04]}

2. {方向B}
   - ...

3. {方向C}
   - ...

4. {方向D}
   - ...

明确不推荐：
- {方向E}：孩子之前因 {原因} 明确放弃，当前兴趣不在此处。
- {方向F}：必要条件不满足（{具体原因}）。
```

**字段说明**：
- "为什么推荐" MUST 引用家长 R1 或 R2 的具体描述，禁止泛泛而谈。
- "条件状态" MUST 列出必要条件满足情况；非必要条件用括号标注"非必要"。
- "风险预警" MUST 按方向特性给出 1-2 句极简提示（见下方二）。
- "起步建议" MUST 是通用动作（试课、基础工具、校内社团），禁止编造具体机构/学校/费用。起步建议的具体内容见 [references_04]。
- "明确不推荐" 仅列出同时满足以下两个条件的方向：①家长 R1 中明确提及（正在学或以前学过）或 R2 标签直接对应；② 被必要条件排除或 R1 中"孩子明确挫败放弃"。禁止列出家长从未提及且 R2 标签未对应的方向。
- 其他特长方向：暂时未表现出明确兴趣，若孩子后续出现新兴趣，可随时再来评估。

## 二、风险预警按方向标注

| 方向 | 风险预警文案（极简 1-2 句） |
|---|---|
| 数学/信息学/物理/化学/生物（竞赛） | 竞赛路线对成绩和持续投入要求较高，如走素养兴趣路线则压力较小。 |
| 机器人/科学创新 | 器材和课程费用跨度大，建议先以低成本套件或校内社团试水。 |
| 科技体育 | 需确认孩子无严重运动禁忌症，且能接受一定强度的体能训练。 |
| 美术 | 建议先确认孩子无红绿色盲等视觉限制，专业色彩学习对此有要求。 |
| 音乐 | 专业乐器学习需持续投入，建议先以声乐或数字音乐低成本验证兴趣。 |
| 舞蹈 | 专业舞蹈对柔韧性和基本功窗口有要求，起步前建议评估身体柔韧度。 |
| 传媒 | 表达类活动对心理素质要求较高，建议先从小范围展示（家庭/班级）开始。 |
| 体育（田径/球类/水上） | 需确认无严重哮喘、心脏病或关节损伤，竞技训练前建议做基础体能评估。 |
| 武术 | 专业武术对柔韧性和基本功窗口有要求，起步前建议评估身体柔韧度。 |
| 水上运动 | 需确认无严重哮喘，且臂展等先天条件适合具体项目（如游泳）。 |
| 小语种 | 国际路线需家庭长期投入且孩子可能长期不在身边，建议先确认家庭规划。 |
| 思辨/商业洞察/社会认知 | 人文方向短期内无显性成果，需家长有耐心等待长期积累。 |

## 三、话术自由度分级

### 低自由度（MUST/禁止）
- 输出结构必须使用上方模板，字段不可缺。
- 禁止暴露内部术语、文档名、编号。
- 禁止编造具体机构、学校、费用明细。
- 禁止预测分数线、学校录取、等级达成。
- 禁止从历史经历推断孩子特质。

### 中自由度（模板 + 参数）
- "为什么推荐" 段落：必须引用家长原话，但措辞可自然调整。
- "风险预警" 段落：使用上方文案或同义改写，必须覆盖该方向的核心风险。
- "起步建议" 段落：使用 [references_04] 中的通用动作或同义改写，禁止超出通用范围。

### 高自由度（原则 + 目标）
- 共情语气：家长焦虑时先回应情绪，再推进信息。给原则，不给逐字台词。
- 追问措辞：R1/R3 的问题组织方式由模型根据上下文自然调整，不复述固定问句。
- 拉回跑题：用"您提到的这个点正好帮我理解孩子"自然过渡，不强行打断。
