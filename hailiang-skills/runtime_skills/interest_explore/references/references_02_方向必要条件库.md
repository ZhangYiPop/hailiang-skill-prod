# 方向必要条件库

> 总原则：**方向不淘汰，只限路线**。本库中任何条件不满足时，均不得将方向整体排除出结论，仅关闭对应路线（专业/竞赛路线），兴趣/素养/平替路线保留，并在风险预警中说明受限原因。

## 一、路线级条件（不满足时关闭对应路线，方向保留）

| 方向 | 路线限制条件 | 不满足时处理 |
|---|---|---|
| 数学/信息学/物理/化学/生物（竞赛路线） | 成绩优秀（信息学另要求年级 ≤ 初二） | 竞赛路线关闭，素养兴趣路线开放，风险预警说明竞赛对成绩要求较高 |
| 舞蹈/武术（专业路线） | 年级 ≤ 小学高段（6 年级），且柔韧性达标 | 专业路线窗口已过，兴趣素养路线开放 |
| 水上运动（专业竞技路线） | 年级 ≤ 小学高段（6 年级），臂展比身高多 10cm 左右 | 专业竞技路线受限，兴趣体验开放 |
| 美术（专业色彩路线） | 无色盲/色弱 | 专业色彩路线受限（如艺考、设计类对色彩辨识有要求），兴趣素养路线开放 |
| 田径/球类/水上（安全类条件） | 无严重哮喘、心脏病、高血压，或医生明确禁止剧烈运动 | **安全红线**：方向保留，风险预警必须明确"先经医生评估，以兴趣体验为主"，禁止做医学判断 |

**输出要求**：条件不满足时，条件状态写受限路线（如"专业路线受限（色盲），兴趣路线开放"），禁止写"排除""不推荐""不能学"。

## 二、投入级条件（不满足仅影响路径深浅，方向与路线均保留）

| 方向 | 投入级条件 | 不满足时的处理 |
|---|---|---|
| 机器人特长 | 教育投入 | 可走平替路线（白名单赛事、校内课程） |
| 科学创新特长 | 教育投入 | 可走平替路线（白名单赛事、校内课程） |
| 美术特长 | 教育投入 | 可走平替路线（基础工具+线上资源） |
| 音乐特长 | 教育投入 | 可走平替路线（声乐） |
| 小语种 | 家长接受孩子长期不在身边 | 不接受则国际路线受限，国内语言素养路线开放 |
| 舞蹈/武术/水上运动/球类 | 教育投入 | 可走平替路线（校内队、自主训练） |
| 传媒特长 | 教育投入 | 可走平替路线（校内广播站、自主短视频创作） |
| 思辨能力 / 商业洞察 / 社会认知 | 教育投入 | 可走平替路线（读书会、辩论社团、社会实践） |

- 教育投入是否满足，需结合用户所在城市该方向的普遍投入水平动态判断。
- 所在城市为固定必问项：R1 未采集到时，在 R3' 末尾的补采问题中必须问出。

## 三、R3 提问触发规则

补采问题在 R3' 末尾与初步结论同轮发出，按方向池并集判断需要问哪些类别，按类别合并提问，禁止按方向逐个提问。

### 身体类问题（方向池含对应方向时才问）

| 方向池包含 | 必问问题 |
|---|---|
| 美术特长 | 孩子有没有色盲或色弱？ |
| 音乐特长 | 听力正常吗？ |
| 田径/球类/水上运动 | 有没有严重哮喘、心脏病，或医生不建议剧烈运动的情况？ |
| 舞蹈特长 / 武术特长 | 身体柔韧性怎么样？能轻松下腰或劈叉吗？ |
| 水上运动特长 | 臂展怎么样？ |

### 家庭类问题（方向池含对应方向时才问）

| 方向池包含 | 必问问题 |
|---|---|
| 任何方向 | 家庭每年教育投入大概在什么范围？（固定必问，禁止因问题数量上限舍弃） |
| 小语种 | 能否接受孩子将来出国读高中或大学？ |

### 成绩类问题

- 成绩在 R1 未采集到且方向池含竞赛方向（数学/信息学/物理/化学/生物）时，R3' 补采问题中必问；方向池不含竞赛方向时可不问。
- 成绩中等/中下 → 竞赛路线关闭，素养路线开放；成绩优秀 → 竞赛路线开放（信息学另需年级 ≤ 初二）。
