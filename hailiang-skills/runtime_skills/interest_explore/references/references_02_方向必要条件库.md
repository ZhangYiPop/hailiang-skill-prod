## 一、必要条件（不满足则明确不推荐）

| 方向 | 必要条件 | 说明 |
|---|---|---|
| 信息学特长（竞赛路线） | 年级 ≤ 初二，且成绩优秀 | 初三全部关闭 |
| 舞蹈特长 | 年级 ≤ 小学高段（6 年级），且柔韧性达标 | 初中全部关闭 |
| 武术特长 | 年级 ≤ 小学高段（6 年级），且柔韧性达标 | 初中全部关闭 |
| 水上运动特长 | 年级 ≤ 小学高段（6 年级），且无严重哮喘/心脏病，臂展比身高多10cm左右 | 初二及以上全部关闭 |
| 美术特长 | 无色盲/色弱（严重色盲影响专业发展） | 仅影响专业路线；素养涂鸦不受限 |
| 田径/球类/水上 | 无严重哮喘、心脏病、高血压，或医生明确禁止剧烈运动 | 安全红线 |

## 二、非必要条件（不满足仅标注风险，不关闭方向）

| 方向 | 非必要条件 | 不满足时的处理 |
|---|---|---|
| 数学/信息学/物理/化学/生物 | 成绩优秀 | 其余成绩仍可走素养兴趣路线，仅关闭竞赛路线 |
| 机器人特长 | 教育投入不满足 | 可走平替路线（白名单赛事、校内课程） |
| 科学创新特长 | 教育投入不满足 | 可走平替路线（白名单赛事、校内课程） |
| 美术特长 | 教育投入不满足 | 可走平替路线（基础工具+线上资源） |
| 音乐特长 | 教育投入不满足 | 可走平替路线（声乐） |
| 小语种 | 家长接受孩子长期不在身边 | 不接受则关闭国际路线，国内语言素养路线仍开放 |
| 舞蹈/武术/水上运动/球类 | 教育投入不满足 | 可走平替路线（校内队、自主训练） |
| 传媒特长 | 教育投入不满足 | 可走平替路线（校内广播站、自主短视频创作） |
| 思辨能力 / 商业洞察 / 社会认知 | 教育投入不满足 | 可走平替路线（读书会、辩论社团、社会实践） |

 - 教育投入根据用户所在城市动态判断，需查询当地该方向普遍投入水平
 - 城市 R1 已提问，R3仅调用，不重复问

## 三、R3 提问触发规则

根据方向池并集，判断需要问哪些类别：

### 身体类问题（方向池含对应方向时才问）

| 方向池包含 | 必问问题 |
|---|---|
| 美术特长 | 孩子有没有色盲或色弱？ |
| 音乐特长 | 听力正常吗？ |
| 田径/球类/水上运动 | 有没有严重哮喘、心脏病，或医生不建议剧烈运动的情况？ |
| 舞蹈特长 / 武术特长 | 身体柔韧性怎么样？能轻松下腰或劈叉吗？ |
| 水上运动特长 | 臂展怎么样？ |

### 家庭类问题（方向池含对应方向时才问）

| 方向池包含 | 必问问题 |
|---|---|
| 任何方向 | 家庭每年教育投入大概在什么范围？ |
| 小语种 | 能否接受孩子将来出国读高中或大学？ |

### 成绩类问题（第一步已采集，R3 不再问）

- 第一步已采集成绩位置，R3 仅内部使用：
  - 若成绩中等/中下，且方向池含数学/信息学/物理/化学/生物竞赛路线 → 内部标注"竞赛路线关闭，仅素养路线可行"
  - 若成绩优秀，竞赛路线开放
