# 方向简要说明库

> 用途：R3' 初步结论中，为每个推荐方向提供一句话简要说明，帮助家长快速理解"这个方向是做什么的"。
> 使用规则（低自由度：MUST/禁止）：
> - MUST：使用下方文案或同义改写，不得超出原文含义。
> - 禁止：在说明中添加推荐理由、条件判断、风险预警、起步建议——这些仅在校准结论（R4）中出现。
> - 禁止：编造本库不存在的方向说明；若推荐方向不在本库中，该方向不附说明。

## 数理方向

| 方向 | 简要说明 |
|---|---|
| 数学特长 | 关注数学素养的长期建构，让不同学习进度的孩子都能在数学中获得成长优势。 |
| 信息学特长 | 聚焦计算思维与编程素养的启蒙与提升，适配不同基础、不同学习目标的孩子。 |
| 物理特长 | 以自然现象探究、逻辑能力构建、数理推理分析为核心，是理工科各类专业的底层根基。 |
| 化学特长 | 培养实验探究能力、微观思维和科学素养，训练"透过现象看本质"的科学思维方式。 |
| 生物学特长 | 培养观察探究能力、系统思维和科学素养，训练"理解生命系统运行逻辑"的思维方式。 |

## 科创方向

| 方向 | 简要说明 |
|---|---|
| 机器人特长 | 通过机器人设计、搭建、编程与实操训练，培养科技创新思维与动手实践能力，优秀赛事经历可作为科技特长生认定与升学规划的参考依据。 |
| 科学创新特长 | 以生活实际问题为切入点，动手钻研小发明、小创造，融汇信息技术、AI 等跨学科知识，是差异化升学的优质路径。 |
| 科技体育特长 | 以科技为活动基础、无需身体直接对抗的体育项目群，涵盖航空、航海、航天、车辆模型等子项，是科技与体育深度融合的典型代表。 |

## 艺术方向

| 方向 | 简要说明 |
|---|---|
| 美术特长 | 提升审美与艺术创作能力的成长路径，具备长远的个人成长意义，往专业方向发展还可通过艺术升学进入理想院校。 |
| 音乐特长 | 以声乐或器乐为核心，培养音乐感知、审美鉴赏和艺术表现能力，也能帮助孩子管理情绪、建立自律习惯。 |
| 舞蹈特长 | 以身体语言为核心，培养节奏感、协调性、表现力与审美能力，本质是"用身体表达情感与故事"的能力。 |
| 传媒特长 | 以"用媒介讲故事、传递信息、表达审美"为核心，培养观察生活、提炼故事、用镜头或声音传递情感与观点的内容思维。 |

## 体育方向

| 方向 | 简要说明 |
|---|---|
| 田径特长 | 涵盖短跑、长跑、跳远、跳高、实心球等项目，培养身体素质、运动能力与意志品质。 |
| 球类运动特长 | 以团队协作或隔网对抗为核心，以篮球、足球为代表项目，兼顾强身健体、团队意识与体育升学路径。 |
| 武术特长 | 中华传统国粹体育项目，具有体能训练、体态矫正、武德育人与竞技参赛四大价值，兼顾身心健康与升学规划。 |
| 水上运动特长 | 依托水环境开展的综合性体育方向，以游泳为代表项目，既能强身健体，也可通过专项训练适配体育升学路径。 |

## 国际方向

| 方向 | 简要说明 |
|---|---|
| 小语种能力培养 | 以英语之外的第二外语为核心，培养多语言沟通能力和跨文化理解力，帮孩子打开另一扇看世界的窗户。 |

## 人文方向

| 方向 | 简要说明 |
|---|---|
| 思辨能力 | 以逻辑论证、批判性思维和深度表达为核心，形成"阅读—理解—思辨—表达"的完整能力链条。 |
| 商业洞察 | 以经济学思维、管理学框架和商业案例分析为核心，帮孩子建立理解市场运转、企业决策的"商业视角"。 |
| 社会认知 | 以法学、社会学、心理学等社会科学为核心，培养理解社会运行、洞察人类行为的"透视社会"视角。 |
