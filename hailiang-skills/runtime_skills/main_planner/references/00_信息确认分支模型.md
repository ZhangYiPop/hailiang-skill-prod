# 信息确认分支模型（Phase 3 核心逻辑）

> 用途：Phase 3「信息确认与需求诊断」的统一推进逻辑。信息确认**不是一段平铺话术，而是按"先学业 → 再特长 → 再转轨"顺序推进的门控决策树**。每个非学业方向都是一道"门"，门不通过就不展开该方向、后续也不再主动推。
> 话术措辞【软】由现场发挥；门的顺序、触发条件、不通过即收回【硬】必须遵守。

## 目录
- 门 0：处境判断 + 学业为先（无条件主线）
- 门 1：特长升学意愿门（按兴趣/特长型分角度）
- 门 2：特长能力水平评估（仅高中）
- 门 3：转轨意愿门
- 学习状态切入（调节维度，见 03）

---

## 门 0｜处境判断 + 学业为先（默认主线，所有画像无条件执行）

基于学段 + 成绩给一句有信息量的处境判断，**首要落到学业规划**：初中=提分/方法/目标校梯度；高中=提分 +（高一）摸清各科成绩或（高二/高三）志愿匹配。这是默认主线，不需要前置确认。

> 高一专项硬规则：本环节**只先确认省份 + 摸清各科大致成绩，不深入讲选科**，更不能因学生当前倾向文/理就锁死方向（文科整体就业偏弱，倾向需用真实成绩验证）。"是否深入选科"作为规划策略里的可选探索，由用户决定后路由到子场景【选科参谋】。

## 门 1｜特长升学意愿门

触发：兴趣/特长型为 兴趣提升型 / 能力提升型 / 特长发力型，或家长主动提及特长。

1. 先用 **1~2 句**点出特长升学的价值（如"现在有特长生/综评通道，能帮孩子进比纯拼分更好的学校"），**不长篇铺垫**。
2. 确认意愿：「你们有没有想过把孩子的 XX 发展成升学上的优势？还是更想让它就当个兴趣？」
3. 分支：
   - **认可** → 初中：进特长生通道规划；高中：先过门 2。
   - **没想过 / 不认可** → 收回："那我们就专注学业，特长保持兴趣就好"，**后续不再主动推特长**。
4. **按型选确认角度**：
   - **特长发力型**（能力兴趣双高）：直接确认意愿 + 既有方向，重点走通道。
   - **兴趣提升型**（能力尚可、兴趣一般）：先问**能力到什么水平**——能力其实不错就点明对升学（综评/特长类）有帮助、借此**反向激发兴趣**；能力一般则不强推。
   - **能力提升型**（兴趣浓、能力一般）：重点**评估时间分配**——能力未成型而成绩中游时，务必摆明"提分 vs 培养特长"的时间矛盾，请家长权衡。

## 门 2｜特长能力水平评估（仅高中，门 1 通过后）

高中时间预算紧、特长升学对能力有硬要求，须先评估客观水平再决策。
1. 追问：「孩子这个特长现在到什么程度了？参加过什么比赛、拿过奖、考过级吗？」
2. 结合成绩中游的时间预算按下表决策：

| 特长能力 | 家长意愿 | 处理 |
|---|---|---|
| 够（省级以上奖项/达标水平） | 强 | 走特长类/艺体/综评升学路径，文化课守底线 |
| 够 | 弱 | 说明特长可作综评/加分的低成本用法，不强推全力培养 |
| 不够（未成型/校级） | 强 | **明确时间矛盾**：提分与培养特长抢时间，请家长权衡；建议学业为主、特长为辅，给观察期再评估 |
| 不够 | 弱 | 专注学业，特长不展开 |

## 门 3｜转轨意愿门

触发：家长提"不想卷"/民办/国际，或初中段有转轨国际倾向时**单独确认一次**（路径与国内完全不同）。
确认：「你们有没有考虑过民办或者国际学校这条路？」→ 认可：转轨方向规划并提示投入差异；不认可：公办体系内规划。
