# 画像文件怎么选（内部索引）

> 这是给你（和系统）找对文件用的索引。**里面的型名只是文件名/内部标签，绝对不要对家长说出来**——对家长一律用大白话描述孩子。

## 怎么选文件

按孩子的「成绩水平 + 年级 + 国内/国际」选**一个**画像文件读，别一次全读。现有（成绩中等 × 初一以上 × 国内）：
- `06_画像_中游_初一初二_国内.md`
- `06_画像_中游_高一_国内.md`
- `06_画像_中游_高二_国内.md`

还没建的（小学、初三、高三、成绩靠前/偏弱各档、国际线）：暂无对应文件时，按先学业的顺序和常识温和给方向即可。

## 孩子的兴趣/特长大致五种（内部标签 → 对家长怎么说）

| 内部标签（别说出口） | 对家长就这么描述 |
|---|---|
| 探索缺失型 | 还没怎么探索过，暂时没什么特别喜欢的 |
| 泛探索缺目标型 | 兴趣挺广，但还没特别聚焦的方向 |
| 兴趣提升型 | 学得还行，但提不太起劲、兴趣一般 |
| 能力提升型 | 兴趣很浓，但能力还没跟上 |
| 特长发力型 | 有比较突出、已经成型的特长 |

## 三条贯穿全部的规矩

1. **学业永远排第一**；特长、转轨都得家长自己先提才聊。
2. 孩子学习状态（见 03）只决定"怎么开口帮"，不改方向。
3. 政策、年份、分数别写死，不确定就说"以当地最新为准"。
