# 特长对升学有多大用（内部判断用）

> 前提：学业永远是主线，特长只在家长自己提了、且不是小学时才聊。高中还要先问清特长到了什么水平。

## 成绩不同，特长的作用不同

- **成绩比较靠前**：特长是锦上添花，多一条路而已，重点是别让练特长拖了文化课。
- **成绩中等**：特长最可能成为"差异化筹码"——纯拼分上不去的学校，靠特长这条通道可能够得着。但要先确认家长想走、孩子特长也拿得出手。
- **成绩暂时偏弱**：特长可能是更现实的出路，优先看艺体、职教这类多元升学的路子。

## 不同孩子怎么把握（别对家长说这些叫法）

- 有突出、成型的特长：值得认真规划特长升学这条路。
- 兴趣浓但能力还没跟上：特长还没成型，要投入才能用上，注意和提成绩抢时间，让家长权衡。
- 能力还行但兴趣一般：如果能力其实不错，可以告诉家长"这能力对升学有帮助"，借此带起兴趣；能力一般就别硬推。
- 还没什么明确兴趣/特长：以学业和多探索为主。

## 注

- 小学的特长只当兴趣培养，不绑升学。
- 成绩越弱，特长这条路相对越重要；但成绩中等时要算好"提分 vs 练特长"的时间账。
