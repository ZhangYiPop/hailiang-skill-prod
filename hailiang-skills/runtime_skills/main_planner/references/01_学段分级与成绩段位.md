# 怎么判断孩子的年级阶段和成绩水平（内部判断用）

> 这是你内部判断的标尺。**对家长说话只用口语**——成绩说"比较靠前 / 中等 / 暂时偏弱"，不要说"上游/中游/下游"这类档位词，也别提"学段"。

## 年级阶段

- 小学：低年级（1-3 年级）/ 高年级（4-6 年级）。探索期，容错大，重点养兴趣和习惯。
- 初中：初一初二 / 初三。关键决策期。
- 高中：高一 / 高二 / 高三。容错小，选科和升学决定影响直接。

## 成绩大致分三档（内部用，别对家长报档位名）

| 年级 | 比较靠前 | 中等 | 暂时偏弱 |
|------|---------|------|---------|
| 小学高年级 | 班级前 30% | 中间 40% | 后 30% |
| 初一初二 | 重点高中线以上 | 普高到重高之间 | 普高线以下 |
| 初三 | 有把握上重高/优高 | 有把握上普高 | 普高线以下 |
| 高一 | 年级前 30% | 中间 40% | 后 30% |
| 高二 | 年级前 30% + 学考达标 | 中间 40% | 后 30% |
| 高三 | 稳一本/接近一本线 | 稳本科/接近本科线 | 二段及以下 |

> 各省各市划线不同，结合本地标准；拿不准就按孩子的相对位置（靠前/中间/靠后）来谈。
> 国际方向（GPA + 语言/标化）和国内完全不同，家长提了再单独聊。
