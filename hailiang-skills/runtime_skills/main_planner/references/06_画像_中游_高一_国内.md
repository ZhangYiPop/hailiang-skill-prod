# 资料：成绩中等 · 高一 · 国内（9 种情况）

> 内部参考。高一容错小，但选科是最大的杠杆。**左栏叫法只是内部对号入座，别对家长说。**
> **高一聊选科的铁律**：这里只先确认是哪个省、各科大概成绩，**不要展开讲选科规则、也别因为孩子现在偏文/偏理就替他定死方向**（文科整体就业偏弱，倾向要用真实成绩验证）；真要深入选科，引导去「选科参谋」。
