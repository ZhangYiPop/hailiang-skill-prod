# 孩子的学习状态不同，切入方式也不同（内部参考）

> 这只影响"怎么开口、用什么办法帮"，不影响给什么方向。**别对家长说下面这些类型叫法。**

按"孩子自己想不想学"和"别人催管有没有用"，大致分四种：

- **自己想学、也吃管**：目标清晰、自我管理好。少干预，给点资源和进阶建议就够。
- **自己有主意、但反感被催**：有自己的节奏，一管就逆反。尊重他的自主权，用引导和给选择，而不是命令，给方法别施压。
- **自己缺动力、但有人盯就动**：得靠外部机制——计划表、陪伴、打卡，用结构补上动力。
- **既没动力又抵触管**：先别硬压，重点修复关系和找到学习的意义，降低对抗，必要时找专业帮助。

> 用法：同样情况的两个孩子，第二种给他选择权、第三种先帮他建机制——方向一样，但开口的方式不同。
