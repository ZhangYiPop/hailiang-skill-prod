## 三、线索归属歧义的判别规则

> 用途：同一句描述同时命中两个标签时，按本节判别；判别不出来就把两个候选**一起**给家长确认。

| 歧义线索 | 判别问题 | 归此标签的情形 | 归另一标签的情形 |
|---|---|---|---|
| “爱问为什么” | 追问的是**事物、原理**，还是**人、社会、事件**？ | 事物原理 → P1 | 人与社会 → P6 |
| “爱动手做东西” | 做出来的是**结构、机械、能动的**，还是**好看的、造型的**？ | 结构机械 → P2 | 造型审美 → P4 |
| “话多、爱说” | 重点在**说本身、模仿、语言**，还是在**观点、立场、辩论**？ | 语言本身 → P5 | 观点辩论 → P6 |
| “爱表演、爱上台” | 重点在**说和演**，还是在**美感和艺术表达**？ | 说和演 → P5 | 美感表达 → P4 |
| “坐得住、能专注很久” | 专注在**思考琢磨**，还是**动手操作**？ | 思考琢磨 → P1 | 动手操作 → P2 |
| “爱看书” | 看的是**科普原理类**，还是**故事、历史、人物类**？ | 科普原理 → P1 | 故事历史人物 → P6；说不清 → 不作为归类依据，另找线索 |

> **本表是"方向池"的唯一来源，也是最终结论补位的唯一来源**：推荐方向不足 3 个时，回到每个**已确认标签**对应的那一行，把**还没进表**的方向按 SKILL.md 的收敛顺序取进来，直到满 3 个或该池取尽。**禁止跨标签池补位**；**禁止因为某方向的培养路线被条件关闭就把它从池里划掉**——受限方向照常可以进表，「条件判断」里写受限口径即可。

> **俗称归并口径（项目 → 方向，供兴趣归库判定与方向可行性判定用）**：家长提到孩子学过、在学或想学的具体项目时，参照上表括号内示例归并到对应方向——如"学游泳""练花样游泳"→水上运动特长，"学钢琴"→音乐特长，"练跆拳道"→武术特长，"学画画"→美术特长。括号示例**不是穷举**，含义相近即可归并；与所有方向都对不上（如马术、击剑）→ **库外兴趣**，按 SKILL 的库外兴趣附段处理，**禁止强行归并**。

## 五、方向池并集示例

> **「并集」是把两个标签的方向加在一起，一个都不许丢；它不是推荐结果。** 收敛到最多 3 个是后面的事（见 SKILL.md 收敛规则）。

- 单选 P1（3 个）→ 方向池：{数学特长、信息学特长、物理特长}
- 单选 P2（5 个）→ 方向池：{化学特长、生物特长、机器人特长、科学创新特长、科技体育特长}
- 双选 P1 + P2 → 方向池并集（3 + 5 ＝ **8 个**）：{数学特长、信息学特长、物理特长、化学特长、生物特长、机器人特长、科学创新特长、科技体育特长}
- 双选 P4 + P3 → 方向池并集（2 + 5 ＝ **7 个**）：{美术特长、音乐特长、田径特长、舞蹈特长、水上运动特长、球类运动特长、武术特长}

**自查（MUST）**：写完并集数一遍个数，与「两个标签的方向数相加（去重后）」核对。个数少了 → 判定为漏掉方向，MUST 回第四节补齐，**不许带着漏项进入推荐**。
