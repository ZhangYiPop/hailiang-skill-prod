# 艺术方向 · 必要条件

> 艺术方向（美术特长、音乐特长、舞蹈特长、传媒特长）的必要条件库。本大类数据按类型拆为五个细粒度库：
> references_艺术_必要条件 / 简要说明 / 赛事 / 优势 / 起步.md；脚本按 references_01 表六路由，查询只解析对应小文件。
> 口径：**方向不淘汰**——条件不满足只关闭对应培养路线，方向保留，受限按「不满足时口径」列；**安全类条件优先级最高**、禁止医学判断；**未采集 ≠ 满足**；教育投入结合所在城市普遍投入水平动态判断，不满足仅影响路径深浅。舞蹈特长为窗口敏感方向，两层窗口判定口径见 §一B。

### 窗口期两层判定口径（本库适用：舞蹈特长）

> 本节所有带「窗口」的条件 MUST 区分**两层窗口**，分别判断、分别表述，禁止混成一句。

| 窗口 | 判断依据 | 它回答的问题 |
|---|---|---|
| **起学窗口** | **起学年级**（开始学这项技能时的年级 / 年龄）+ 是否持续训练至今 + 基本功是否达标 | 基本功能积累是否在该技能的窗口期内完成 |
| **转化窗口** | **当前年级**距中考、艺考、专业选拔节点还剩多少时间 | 在已建立的基本功之上，还能走多远 |

* **禁止用「当前年级」判断「起步是否偏晚」**——判断起步 MUST 看**起学年级**。
* **起学年级的获取与推算**：优先问家长；未采集到时按 `当前年级 − 已学时长（年）` 推算，并按通行口径（6 岁入学、年级 ≈ 年龄 − 6）换算；推算结果只作内部判断依据，输出时说"按已学 X 年推算，大约从 X 年级开始"。
* **已学时长 ≥ 4 年且仍在学 → 起学窗口视为已满足**。此时禁止出现"起步偏晚""窗口已过""零基础""来不及""时间不够了"等任何暗示基本盘不足的表述。
* **信息不足时禁止下窗口结论**：起学时间与已学时长两者都未采集前，禁止输出任何关于起步早晚、窗口开闭的判断；此时只能说领域层面的常识。

**两层窗口的组合输出口径：**

| 起学窗口 | 转化窗口 | 输出口径 |
|---|---|---|
| 满足 | 满足 | 专业路线开放，正常按专业方向规划 |
| 满足 | 不满足 | 方向与专业路线**均不否定**。说明"基本功已经建立，受限的是依赖专业院校附中 / 少年班早期选拔的那条路，初中阶段的特长生升学仍可探索"，并保留素养路线 |
| 不满足 | 满足 | 专业路线受限（起学过晚），但仍有时间建立基本素养；素养路线开放 |
| 不满足 | 不满足 | 专业路线窗口已过；素养路线开放 |
