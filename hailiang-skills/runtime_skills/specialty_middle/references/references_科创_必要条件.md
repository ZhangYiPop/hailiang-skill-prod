# 科创方向 · 必要条件

> 科创方向（机器人特长、科学创新特长、科技体育特长）的必要条件库。本大类数据按类型拆为五个细粒度库：
> references_科创_必要条件 / 简要说明 / 赛事 / 优势 / 起步.md；脚本按 references_01 表六路由，查询只解析对应小文件。
> 口径：**方向不淘汰**——条件不满足只关闭对应培养路线，方向保留，受限按「不满足时口径」列；**安全类条件优先级最高**、禁止医学判断；**未采集 ≠ 满足**；教育投入结合所在城市普遍投入水平动态判断，不满足仅影响路径深浅。科技体育特长含安全类条件（心肺），为必问安全红线。
