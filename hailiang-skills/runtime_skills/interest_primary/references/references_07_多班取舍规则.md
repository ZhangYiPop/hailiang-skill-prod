# 多班取舍规则（流程二）

> 用途：流程二"报了 n 个班怎么取舍"专用——查表优先原则、两轮分层提问纪律、客观四维判定规则、意愿冲突兜底（A/B）、态度/表现示例与结论模板。
> 定位：本文件为 SKILL.md 第四节的自足版全量规则（两处文本一致）；SKILL.md 第四节在轻量运行环境下可独立执行全流程，本文件供可加载资料时相互印证。
> 使用规则（低自由度）：
> - MUST：判定只依据四个客观维度（态度、表现、教育投入、陪练强度），影响程度 **表现 > 陪练强度 > 教育投入 > 态度**；已获成就、家长期望、孩子想法只作为"建议您再考虑的层面"呈现，禁止作为排除依据。
> - MUST：除"表现明显不喜欢"可一次排除多个外，其余维度合计只排除一个班。
> - MUST：向家长提问**总轮次不超过 2 轮、每轮最多 1 问**（班名清单确认与班名对齐回问不计入轮次）；两问**分层**——第 1 轮只问态度层（有没有不想去的），第 2 轮仅针对第 1 轮点名不想去的班问表现层；禁止一次罗列多个问题、禁止混层提问。
> - MUST：**禁止把已答过的内容或维度再问一遍**——用户给出的任何信息（点名某班最不喜欢、口述花费、陪练情况）直接采用，追问只针对尚未获得且判定需要的信号。
> - MUST：**年费与陪练强度一律查表（速查数据层，与 lookup.py 同源），禁止问家长**；表外班这两维视为"无法对比"顺延级联，不追问家长，结论注明"未收录在精选指导表中"；家长主动提供的信息（实际总花费、陪练情况）优先于查表值。
> - MUST：**流程二（多班取舍）唯一的必问信息是班名清单——不采集基础三问（年龄/预算/城市）**：三者的判定作用由查表承担（年费/陪练）、城市不影响取舍，缺失一律不问，第〇节基础三问与状态类问句不进入本流程（六十六测实测：入口已给三个班名，仍误问年级/城市/预算并加发状态类问句，被家长质疑）；仅开口消息已带年龄/年级时用于学段闸门判定（第一节第 0 步），**年龄/年级未带时不做学段闸门判定、不索要，正常展开取舍**（六十七测实测：仍问年级——学段闸门"先于一切"的高优先级被误当"须先知道年龄才能取舍"，本流程判定完全不依赖年龄：年费/陪练查表、态度/表现来自两轮问句，闸门只对已带年龄的时点顺手拦截，缺失即跳过、绝不反问）。**本流程也不问经历三问、不做测评**——经历三问只属流程一 d 步与流程三 b 步、测评只属流程一，第〇节「测评第 1/2 轮」与「经历三问」代码块均不进入本流程（七十测实测：取舍入口已给三个班名，仍发出经历类问句）。
> - MUST：**先问后结论（v1.2.20）**：第 0 步班名确认与立即查表完成后，**必须先发出第 1 轮态度层固定问句；问句未发出前禁止输出任何取舍结论/停班建议**，判定完成或两轮用尽后才进第四节输出（七十一测实测：班名已给、一句未问就直出结论）。
> - MUST：家长期望、孩子想法、已取得成就**不作为提问**，仅写入结论"建议您再考虑的层面"（第五节）与兜底段（第四节），逐条附原因。
> - MUST：两轮提问用尽仍无区分信号 → 按已有信息（查表数据优先）判定并输出结论，**禁止继续追问**。
> - MUST：**判定完成即停**——任一轮回答已点名排除对象后，对其余班级不再有任何提问（其余默认保留）；家长明确想再多砍才按第六节对应行处理。
> - MUST：**结论输出后禁止追加任何提问**——结论给出即为流程二终点，其余班级默认保留，不追问其余班的表现/状态；家长主动再问按第六节对应行处理。
> - MUST：家长明确要求代为决定（"你帮我决定吧"）或表达不耐烦（"别问了""怎么一直问"）→ **剩余轮次立即作废**，停止一切提问，按已有信息判定并输出第四节完整结论；结论可明确倾向，但保留收尾句、不替家长拍板。
> - MUST：家长期望的**换皮问法同属禁止提问**（"哪个更有长远价值""您更希望孩子坚持哪个""哪个更符合您对孩子的期待"）；对比班级特点只引用速查数据层的优势原文，**禁止凭通用印象描述**。
> - MUST：**意愿冲突兜底（兜底 A/B）纯输出、不提问**，不打断两轮提问纪律（详见第四节兜底段）。
> - MUST：态度、表现两段示例在结论中原文照录（第三节）。
> - MUST：引用年费区间时必附价格地区差异提示（第五节末固定句）。
> - 禁止：替家长拍板；承诺考级、获奖、升学结果；推荐新班（兜底 A 方向示意除外——可点班名作方向举例，不带年龄费用数据，细筛转流程三/四；家长顺势问"换什么班"→ 有类别词走流程三、点名班名走流程四、无方向转流程一（测评邀请按三步规则））。

## 一、班名确认与查表、两轮分层提问

**第 0 步 班名清单确认（不计入提问轮次）**

- 固定问句："孩子现在都在上哪些兴趣班？"
- 用户开口消息或对话中已说明 → 直接采用、问句跳过不发，**禁止重复提问**（SKILL.md 第二节「开口消息信息预提取」——开口已给的年级/年龄、城市、预算、班名清单一律视为已采集，对应问句不再发；十六测后实测：家长开口已说年级和已报的班，仍被固定问一遍年级）。
- **必问信息先于结论**：跳过的只是已给信息对应的问句，缺失的必问项必须先问、收齐后才输出结论——**禁止先给结论/推荐清单/方向列表再回头补问**（SKILL.md 第二节「必问信息先于结论」；十七测实测：未问城市/预算先给 5 个方向推荐清单再补问——倒序输出）。
- 班名按 SKILL.md 第十节速查数据层主表「班名」列对齐：唯一命中即采用，复合班名支持部分匹配（如"跆拳道"→"跆拳道 / 空手道"）；对不齐 → 回问"您说的是哪一项？"，禁止猜。

**第 0 步后立即查表（MUST）**

- 班名确认后立即对照 SKILL.md 第十节速查数据层：每个班对到主表一行，取逐班年费区间（「年费区间」列）与家长陪练强度（「陪练」+「陪练说明」列）——这两个维度**禁止问家长**。
- 速查表外班级（如大提琴、体操；含类型库收录但速查表未收录的班）：可参与取舍，但无年费/陪练数据，这两维"无法对比"顺延级联，不追问家长。

**第 1 轮提问（固定问句，态度层）**

> "这几个班里，孩子有没有哪个是明显不想去的？"

- 回答点名了不想去的班（一个或多个）→ 按下方"点名后两条路径"处理。
- 回答没有不想去的（都喜欢/都一般/说不清）→ **第 2 轮不发**，直接进第二节级联判定。

**点名后两条路径**（判定表现信号是否已给，二选一；**禁止把原因、期望或问句同义反复加工成表现信号**）

- **路径一（原话已给负面感受/上课状态 → 点名即排除）**：家长原话超出问句本身、直接刻画孩子对这个班的感受或上课时的状态——"不太喜欢""很排斥""上着没劲""去了就烦""上课走神""老师让练就叹气"这类 → 表现信号成立，**第 2 轮不发**，点名的班全部按"表现明显不喜欢"列入排除（可多个），直接进第四节输出结论。
- **路径二（原话未给 → 必发第 2 轮核实）**：家长原话只有点名 + 问句同义反复（如"不太想去了"——只是回答了"不想去"本身）、客观原因（"运动量太大""太累了""时间太长"）或家长期望（"想让他锻炼身体"），无负面感受与上课状态描述 → 表现信号未给，**必须发第 2 轮表现层固定问句**核实，按回答判定（走神/应付 → 排除；能正常跟着练 → 无排除信号，进第二节第 2 步）。

**第 2 轮提问（固定问句模板，表现层——仅针对第 1 轮点名不想去的班）**

> "那这个不想去的班，孩子上课时实际表现怎么样——是能正常跟着练，还是走神、应付、老师让练就叹气这种？"

- 点名多个班时把"这个班"说成"这几个班"。
- 第 2 轮只能问这一个问题；已答过的信号禁止再问。

**轮次用尽**

- 两轮提问后仍无区分信号 → 按第二节级联以查表数据判定（陪练强度 → 年费区间），仍无法区分 → 难分高下路径（第四节）；结论按第四节"轮次用尽路径"输出。**禁止继续追问**。

**代决策 / 不耐烦终局**

- 家长明确要求代为决定（"你帮我决定吧"）或表达不耐烦（"别问了""怎么一直问"）→ 剩余轮次立即作废，停止一切提问，按第二节级联以已有信息判定（查表数据优先），按第四节输出完整结论。
- 结论可明确倾向，但保留第四节收尾句——最终决定权在家长与孩子，不替家长拍板。

## 二、客观四维判定规则

**总规则**：只依据四个客观维度判定，优先级 **表现 > 陪练强度 > 教育投入 > 态度**；除表现可排除多个外，其余合计只排除一个。

**判定流程**（固定顺序，逐步执行）：

```
第 1 步 表现：第 1 轮点名"不想去"的班，表现信号成立吗？（成立途径二选一：① 第 1 轮原话已给负面感受/上课状态——第一节路径一；② 经第 2 轮核实为"明显不喜欢"——走神/应付/叹气抗拒/课后不愿练/提起就烦，满足其一即算）
   成立 → 全部列入排除（可多个），判定完成即停，其余默认保留，直接进第四节
   不成立（第 1 轮未点名任何班，或第 2 轮答"能正常跟着练"）→ 进第 2 步
第 2 步 陪练强度：能比出唯一"最高"的一个班吗？（查表，禁止问家长）
   能 → 排除它，结束
   不能（并列最高/表外班无数据）→ 进第 3 步
第 3 步 教育投入：能比出唯一"最高"的一个班吗？（家长口述总花费直接比大小、不主动问；无口述用查表年费区间，区间不重叠 → 高者排除）
   能 → 排除它，结束
   不能（区间重叠/表外班无数据）→ 进第 4 步
第 4 步 态度：第 1 轮点名了唯一一个"不想去"的班吗（且第 2 轮核实其表现正常）？
   有 → 排除它，结束
   没有（未点名/点名多个无法区分）→ 四维均无法区分：不强行排除，按第四节"难分高下"模板输出
```

**判定示例**（照此执行）：
- 例 1：篮球、钢琴、跆拳道 / 空手道、儿童创意美术。第 1 轮答"没有不想去的"——态度无信号、第 2 轮不发；查陪练：钢琴「高」为唯一最高（其余三个「低」）→ 建议优先停掉钢琴（陪练口径），对其余班零提问，直接进第四节。
- 例 2：同上四班。第 1 轮答"篮球和跆拳道他不太想去了"→ 第 2 轮问这两个班的上课表现，答"上课都走神、老师让练就叹气"——表现一次排除两个 → 建议优先停掉篮球、跆拳道 / 空手道（表现口径，同一表现覆盖两班→合并一条），钢琴、儿童创意美术默认保留，对其余班零提问，直接进第四节。
- 例 3：同上四班。第 1 轮答"就钢琴不太想去"→ 第 2 轮问钢琴上课表现，答"还能正常跟着练"——表现无排除信号；查陪练：钢琴「高」为唯一最高 → 建议优先停掉钢琴（陪练口径，结论可同时提及孩子去之前也最磨蹭），直接进第四节。
- 例 4（十测案例·路径一）：同上四班。第 1 轮答"篮球和跆拳道他不太喜欢"——原话已给负面感受（"不太喜欢"）→ 点名即排除，**第 2 轮不发** → 建议优先停掉篮球、跆拳道 / 空手道（表现口径，同一表现覆盖两班→合并一条），钢琴、儿童创意美术默认保留，对其余班零提问；家长同时说"想让他锻炼身体"→ 期望落在被排除班上，结论第 4 段触发兜底 A（换载体 / 降频不退班 / 和孩子约定三条出路）。
- 例 5（十测案例·路径二）：篮球、足球、乒乓球。第 1 轮答"足球吧，他觉得运动量太大了，但我希望他能锻炼一下身体"——点名足球但原话只有原因（运动量太大）与期望（锻炼身体），无负面感受表述 → **必发第 2 轮**"那这个不想去的班，孩子上课时实际表现怎么样……"：答"上课走神、应付" → 排除足球（表现口径）+ 兜底 A 触发；答"能正常跟着练" → 表现无排除信号，进第二节第 2 步查陪练——**两种回答都不得把"运动量太大"直接当表现信号排除**。

**维度细则**：

1. **表现**（上课当时的状态）
   - "明显不喜欢"信号（满足其一即算）：课上走神注意力不集中、老师让练就叹气抗拒、课后不愿练、提起上课就烦、多次说不想学。
   - "投入"信号：主动举手参与、下课意犹未尽、主动要求加练或回家继续。
   - 本维信号来自第 2 轮对"不想去的班"的核实；第 1 轮未点名不想去的班时，本维无数据、顺延级联，不追问家长。
2. **陪练强度**（课外家庭需付出的看护与练习成本）
   - 表内班：直接取速查数据层「陪练」与「陪练说明」列（与 lookup.py escort 字段同源），**禁止问家长**；强度排序：低 < 低–中 < 中 < 中–高 < 高。
   - 家长主动口述陪练情况 → 优先于查表值（"基本不用陪/孩子自己练"=低；"每周需要陪 1–3 次"=中；"每天盯练或全程陪同"=高）。
   - 表外班：无查表数据，不追问家长，本维视为"无法对比"。
   - 取强度最高者；最高档并列多个 → 无法对比，进下一维。
3. **教育投入**
   - 家长主动口述全年总花费（学费+装备+赛事+加课+考级）→ 直接比大小，最高者排除（总额相同 → 无法对比）；**不主动问**。
   - 无口述 → 用速查数据层年费区间对比：区间不重叠 → 上限高者排除；区间重叠或含表外班 → 无法对比，进下一维。
4. **态度**（去上课之前的状态）
   - 本维信号来自第 1 轮"有没有不想去的"：点名唯一一个且第 2 轮核实表现正常 → 态度口径候选（级联最后一维）；点名多个并列 → 无法区分；未点名 → 无信号。
   - 家长主动补充的出发前状态描述可直接采用。

## 三、态度与表现示例（输出必附）

> 结论中必须原文照录以下两段，帮家长分清"态度"和"表现"分别指什么：

- **态度示例**："比如：一听说要去上课，孩子就提前把东西收拾好、出发很积极，这是态度积极；每次都磨磨蹭蹭、找借口不想去，这是态度消极。**态度，看的是去上课之前的状态。**"
- **表现示例**："比如：课上主动举手、下课还意犹未尽想再练一会儿，这是投入；全程走神、老师让练就叹气，这是明显不喜欢。**表现，看的是上课当时的状态。**"

## 四、结论输出模板（七段式 + 兜底 A/B）

> **输出前兜底（MUST）**：输出结论前确认查表已完成——班名确认后已查过则直接复用结果；未查过（判定即停、代决策、轮次用尽任一路径直达本节）→ 立即对照 SKILL.md 第十节速查数据层逐班取数，再按本节模板输出。

家长要求代决策时同用本模板，可在初步结论前加一句衔接（如"您让我直接给建议，那我就说得直一点："），模板要素不省略。

**正常路径**（七段式，按序输出）：
1. **【初步结论】**（固定句式）："从客观条件看，建议优先停掉的是：「班名」。"
2. **为什么建议停它**（明确排除原因，按实际维度取一种，引用数据；**排除多个时按家长口径定形式——同一句表现描述覆盖几个班就合并成一条、班名并列；家长分别描述了不同表现的才逐班分列**，禁止同一表现写两遍一模一样的话）：
   - 表现口径（单班或各班表现不同）："孩子在这个班上课时「表现描述原话」，属于明显不喜欢——建议优先停掉。"
   - 表现口径（同一表现覆盖多个班，合并一条）：""「班名1」和「班名2」"：孩子在这几个班上课时「表现描述原话」，都属于明显不喜欢——建议优先停掉。"
   - 陪练口径："按速查数据层，「班名」的家长陪练强度是「表内值」（「陪练说明原文」），是这几个班里陪练压力最大的——班再好，家长长期跟不上，也很难坚持下去。"
   - 投入口径："「班名」一年花费约「口述总额或年费区间」，是这几个班里投入最高的，而收益看不出明显优势——优先精简投入最大的。"
   - 态度口径："去上课之前，「班名」是孩子最磨蹭、最不想去的一个——也说明这个班对孩子的吸引力最低。"
3. **其余班的对照**（固定段；数据一律取自第十节速查数据层、逐字照录，表外班无数据的维度不提）："剩下的「班名列举」，孩子都没有点名不想去。从家里的投入看：「班名」的陪练最重（「陪练说明原文」），「班名」的年费最高（「年费区间」万/年）。如果您之后还想再精简，可以优先考虑「班名」——先给家里减掉投入最大的一块。"（陪练最重与年费最高为同一个班时合并为一句；剩余仅 1 个班时只报该班数据、不附"再精简"句；**剩余各班陪练强度相同且年费区间相当/重叠（比不出"陪练最重/年费最高"，即第二节第 2/3 步都"无法对比"）时——本段只列数据对照，不附"再精简优先考虑「班名」"句，也不说"从这几个里再选一个"：客观条件给不出"投入最大的一块"，此类建议是空话，改成一句平实收束（如"这几个班投入相当，若确实还想再精简，客观条件分不出先后，可结合下方'【建议您再考虑的层面】'与孩子的软因素来判断"）**；剩余班全部表外无数据时本段改为"其余班的费用与陪练未收录在精选指导表中，暂无法对比"；引用年费必附价格提示。）
4. **关于您提到的「XX」**（兜底段，触发才写、未触发整段跳过；两项同时触发时分两小段，兜底 A 在前，见下方兜底 A/B）。
5. **态度、表现示例**：第三节两段原文照录。
6. **【建议您再考虑的层面】**：第五节三条，编号列举（逐条附原因）。
7. **收尾**（固定）："以上是结合孩子的状态和家里的实际投入整理的初步参考，最终怎么定，建议您和孩子聊过之后再做决定。"涉及年费必附价格提示（第五节末固定句）；取舍建议不附附近开设尾句；**输出后禁止追加任何提问**——结论给出即为流程二终点，其余班级默认保留，不追问其余班的表现/状态。

**结论第 4 段：关于您提到的「XX」（兜底 A/B，触发才写、未触发整段跳过；两项同时触发时分两小段，兜底 A 在前）**

- **兜底 A（孩子不喜欢 × 家长想让他学）**——排除建议落定后，家长对被排除班表达过明确目标（锻炼身体、练坐姿、识字、社交等）时写：
  1. 先确认目标合理（不否定家长）；
  2. 摆矛盾：孩子已明显不喜欢还硬撑，常见结果是课上应付、课外抵触，兴趣反而彻底变成负担——兴趣才是能坚持的前提；
  3. 三条出路供家长和孩子商量：**换载体**（目标不必绑死这个班——从速查数据层主表「大类」列筛同类、优先陪练强度低的班点到名为止作方向示意，不带年龄费用数据；想细选就请家长告知孩子年龄，转流程三帮筛）、**降频不退班**（如每周两次降到一次，观察一学期再定）、**和孩子约定**（再坚持一学期，仍不喜欢就换——把"换"变成孩子努力后的选择）。
- **兜底 B（孩子喜欢 × 家长不想让他学）**——孩子点名喜欢/最来劲的班落在排除建议上，或家长对孩子喜欢的班表达顾虑（太贵、太花时间、怕影响学习、觉得没用）时写：
  1. 先摆数据不否定顾虑：该班年费区间、陪练强度照速查数据层报出（引年费时附价格提示）；
  2. 摆价值：孩子自己选的班坚持概率最高，砍"最喜欢的班"容易连兴趣一起伤；
  3. 三条出路：**降规格**（如一对一改小组课）、**降频**（每周减次）、**阶段性约定**（先学一学期、约法三章再议）。
- 兜底段**纯输出、不提问**，不打断两轮提问纪律；家长期望、孩子想法、已取得成就仍不作为提问（含换皮问法），只写入第五节考虑层面与本兜底段。

**难分高下路径**（四维均无法区分时）：
"这几个班在客观条件上难分高下：孩子上课表现都没有明显抗拒，陪练强度、教育投入、态度也拉不开差距。这种情况下，硬按客观条件砍掉哪一个都可惜，建议把决定权主要交给下面这些'软因素'——"（跳过第 2 段，**第 3 段其余班的对照保留输出的数据对照部分，但此路径本就四维拉不开差距——同样不附"再精简优先考虑「班名」"句，只列数据后作平实收束**，口径与正常路径条件相当分支一致；转入第五节列举，重点展开孩子自己的想法）。

**轮次用尽路径**（两轮提问后仍无态度/表现排除信号——第 1 轮未点名不想去的班，或第 2 轮核实表现正常）：
- 陪练强度或年费查表能区分 → 按正常路径对应口径输出，结论开头注明："孩子的主观状态这两轮没聊出明显的排除信号，下面的判断先按客观条件（查表数据）给您参考。"
- 查表仍无法区分 → 按难分高下路径输出。
- 两种情况均须在【建议您再考虑的层面】末尾追加观察建议（第五节第 4 条）。

**输出示例**（供格式参考）：
> 从客观条件看，建议优先停掉的是：钢琴。按速查数据层，钢琴的家长陪练强度是"高"——低龄需全程陪练、记笔记、盯手型，是这三个班里对家长要求最高的；游泳是"低"（课后可自主加练），围棋是"中–高"（需监督网练与复盘）。孩子上课表现都没有明显抗拒，这时候陪练压力就是最值得先减掉的负担。剩下的游泳和围棋，孩子都没有点名不想去；从家里的投入看，围棋的陪练更重一些（需监督网练与复盘）。如果您之后还想再精简，可以优先考虑围棋——先给家里减掉投入最大的一块。

## 五、建议您再考虑的层面（详细列举）

> 排除建议给出后必附（编号列举，逐条附原因）；这几条**不向家长提问**——当下答不出来很正常，写清楚需要考虑什么即可：

1. **已取得的成就（获奖与考级）**："如果孩子在某个班已经考出了级别、拿过奖，停掉它比停掉一个刚起步的班'可惜'得多——前期投入都成了沉没成本。不过也别被沉没成本绑住：级别保得住技能，保不住兴趣；实在犹豫，可以和孩子商量'降频不退班'，比如从每周两次降到一次。"
2. **您对这个班的期望（升学 or 素养提升）**："如果某个班承担的是升学期待（比如竞赛成绩、证书在小升初简历里的分量），砍掉前要想清楚有没有替代路径；如果只是素养提升，孩子不喜欢就停，不可惜——素养类兴趣恰恰以'有兴趣'为前提。"
3. **孩子自己的想法**："孩子的声音最不该被忽略。建议把这份初步分析讲给孩子听，让TA参与决定——孩子自己选择留下来的班，比家长替TA保留下来的，更容易坚持下去。"
4. **观察建议（仅轮次用尽路径附）**："这两轮里孩子的状态您暂时说不太清——很正常，不用勉强回忆。建议接下来一两周留意下孩子上课前后的反应：哪个是一听说要上课就提前收拾东西的，哪个是总找借口磨蹭的。观察清楚了，再做最终决定也不迟。"

**价格提示**（结论引用年费区间时必附，固定句）："以上价格为参考区间，不同地区价格差异较大，请以您家附近机构的实际报价为准。"

## 六、边界情况处理

| 情况 | 处理 |
|---|---|
| 只报了 1 个班 | 无取舍问题：直接说明"目前只有一个班，还谈不上取舍"，可按四维框架帮家长看这个班的去留状态 |
| 全部班明显不喜欢（第 1 轮全部点名 + 第 2 轮核实） | 全部列入排除建议，但结论升级为"整体调整"：建议先与孩子逐班聊清楚原因（换机构、换老师、暂停一段都可能解决），不着急一刀切全停 |
| 家长明确想再多砍一个 | 在剩余班级上重新走一遍级联（陪练强度→教育投入→态度，仍只排除一个）；已采集信息保留复用，禁止重新提问 |
| 结论输出后家长主动再问某个班 | 不视为追问违规：按上一行"再多砍一个"级联处理或按第 3 段对照数据回答；**技能自身仍不得主动发起新提问** |
| 家长明确要求代为决定 / 表达不耐烦 | 剩余轮次立即作废，停止一切提问；按已有信息判定（查表数据优先）输出完整结论；可明确倾向但保留收尾句，不替家长拍板 |
| 孩子不喜欢但家长有明确目标（兜底 A）/ 孩子喜欢但家长有顾虑（兜底 B） | 按第四节兜底 A / 兜底 B 输出结论第 4 段（纯输出、不提问；兜底 A 替代班仅方向示意、不带年龄费用数据） |
| 表现维已识别排除对象、家长未要求再砍 | 对其余班级零提问，直接输出结论（其余班级默认保留）；家长明确想再多砍一个才走上级联路径 |
| 两轮提问用尽仍无态度/表现排除信号 | 按查表数据（陪练强度→年费区间）判定；仍无法区分 → 难分高下路径；结论附观察建议（第五节第 4 条）；**禁止继续追问** |
| 某维度无法对比（表外班无数据/区间重叠/并列最高） | 级联顺延到下一维；结论备注"「维度名」无法对比，本维未参与判定" |
| 班级在速查表外（如大提琴、体操） | 年费与陪练**不追问家长**（两维无法对比顺延）；仅凭态度/表现判定；结论注明"「班名」未收录在精选指导表中，费用请以您家附近机构的实际报价为准" |
| 流程二输出尾句 | 取舍建议不涉及新班推荐，**不附**"附近开设"尾句；家长顺势问"换什么班"→ 有类别词走流程三、点名班名走流程四、无方向转流程一（测评邀请按三步规则）；兜底 A 的替代班为方向示意（不带数据），不算推荐新班 |
