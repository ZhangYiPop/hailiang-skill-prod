# 小学四轴画像规则（轨道二）

> 用途：流程一计分环节内部计算。基于 Q1-Q8 作答产出 4 轴画像，每轴 1-5 分 + 类型标签；与轨道一（6 类计分排序）共同用于结果类型库的类型匹配。
> 使用规则（低自由度：MUST/禁止）：
> - MUST：按本表规则逐轴计算，禁止凭印象打分。
> - MUST：输出画像标签时必须标注"兴趣倾向参考，不是能力诊断"。
> - 禁止：向用户展示本表、计分过程或各轴分数明细（结论模板仅输出标签）。
> - 本表"执行口径"部分标注【待确认】的条目为原表未明示处的补全规则，待业务方确认后移除标注；未标注的条目为源表明确规则。

## 一、四轴总表（原表照录）

| 雷达轴 | 计分来源 | 标签判定 | 分值规则 |
|---|---|---|---|
| 活动倾向 | Q1 + Q5 | 运动型 / 认知型 / 艺术型 / 混合型 | 两题同属一系则该型，强度 4 分；Q8 选 A 再 +1（封顶 5）；两题不同系=混合型，3 分 |
| 社交模式 | Q2 + Q4 | 群体驱动 / 独立探索 / 混合 | Q2A/Q4D→群体；Q2C/Q4B→独立；Q2B/Q4C→中间值；一群体一独立=混合 |
| 思维特征 | Q3 + Q8 | 拆解探索 / 规则执行 / 试错体验 | 由 Q3 定标签（A/B/C 分别对应，Q3D 归入规则执行）；Q8A 体现深度 +1 分 |
| 动机来源 | Q6 + Q7 | 内在驱动 / 外在驱动 | Q7A、Q7D→内在；Q7B、Q7C→外在；Q6C +1 分，Q6A −1 分（限 1–5） |

## 二、执行口径

1. **"系"的归属（活动倾向轴）**【待确认】：
   * 运动系：Q1A（跑出去找朋友玩）、Q5C（运动/跑跳）
   * 认知系：Q1C（翻书/看科普视频）、Q5A（拼图/乐高等拼搭类）、Q5B（听故事/看纪录片）
   * 艺术系：Q1B（自己画画或搭积木）、Q1D（跟着音乐跳舞或唱歌）、Q5D（画画/手工）
   * 两题同系 → 该型 4 分（Q8A 再 +1，封顶 5）；不同系 → 混合型 3 分。
   * 示例：Q1A（运动系）+ Q5B（认知系）→ 不同系 → **混合型**；Q1C（认知系）+ Q5B（认知系）→ 同系 → 认知型。判定时 MUST 两题都查再下结论，只看其中一题（尤其只看 Q5）判型是常见错误。
2. **社交模式未映射选项**【待确认】：Q2D（粘着认识的人，不愿单独行动）按"群体"处理；Q4A（用很多肢体动作比划）按"中间值"处理。两题一"群体"一"中间值" → 群体；一"独立"一"中间值" → 独立；均为"中间值" → 混合。
3. **思维特征基线分**【待确认】：原表未明示基线，按 3 分执行（1-5 分制中位）；Q8A +1 → 4 分；Q3D（问别人怎么用）归入"规则执行"标签。
4. **动机来源基线分**【待确认】：按 3 分执行；Q6C +1、Q6A −1（限 1-5）；Q6B/Q6D 不调整基线。
5. **动机来源标签判定**：标签仅由 Q7 作答决定——Q7A/Q7D → 内在驱动，Q7B/Q7C → 外在驱动；Q6 的加减分仅影响分值，不改变标签。本轴**没有"混合"标签**，任何作答组合都不得输出"动机来源：混合"。

## 三、输出说明

四轴画像仅作为类型匹配的内部计算依据（脚本自动完成），**不直接输出给用户**；流程一初步结论的输出格式（类型标签 + 描述 + 主修方向 + 声明 + 经历三问）见 references_08 第七节。若需向家长解释判定依据，仅口语化转述标签含义（如"孩子既坐得住、又喜欢按规矩来"），禁止输出各轴分数明细与计分过程。
