# 类型兴趣询问与单班结论（流程四）

> 用途：流程四"我想看看某兴趣班适不适合孩子"专用——兴趣询问话术、四分支结论模板与兜底规则。
> 使用规则（低自由度）：
> - MUST：兴趣询问只用第一节话术（按所问班级自然嵌入班名），禁止自创问法。
> - MUST：结论按第四至七节分支模板输出，固定句式照录，「」内为待填项；优势话术照录 references_04 优势列原文。
> - MUST：安全提示照录 references_05 第八节硬红线表"提示类型"列内容，禁止自行编写、禁止省略命中班级的提示。
> - MUST：年龄判定线（硬红线"生效年龄"与速查表"最早起始年龄"取更严值）与逐班年费/陪练/优势数据同源自 SKILL.md 第十节速查数据层（轻量运行环境无资料加载时直接对照第十节，两处数据一致）。
> - MUST：任何信息最多追问一轮，仍未提供按第八节兜底处理，并在结论中备注"未提供"。
> - 禁止：承诺考级、获奖、升学结果；禁止编造速查表与风险资料之外的数据；禁止替家长拍板。

## 一、八大类兴趣询问话术

> 流程四 b 步使用：按所问班级所属大类取一句话术问家长，一句话术一轮内只问一次。

| 大类 | 兴趣询问话术 |
|---|---|
| 体育运动类 | 孩子平时有没有运动的习惯？喜不喜欢跑跑跳跳、出一身汗？ |
| 音乐表演类 | 孩子平时爱听音乐吗？会不会跟着旋律哼唱、打拍子？ |
| 舞蹈体态类 | 孩子听到音乐会不会不自觉地晃动身体、跟着跳？ |
| 美术创作类 | 孩子平时喜欢涂涂画画、做手工吗？ |
| 语言表达类 | 孩子平时爱说话、爱讲故事吗？敢不敢当众表达？ |
| 思维益智类 | 孩子平时喜欢拼搭、下棋这类动脑筋的游戏吗？遇到问题爱琢磨吗？ |
| 文化素养类 | 孩子平时喜欢看书、听故事吗？会不会追着问"为什么"？ |
| 生活素养与其它 | 按下表所问班级取专用话术 |

生活素养与其它（班级差异大，逐班细问）：

| 班级 | 兴趣询问话术 |
|---|---|
| 厨艺 / 烘焙 | 孩子平时喜欢在厨房搭把手、摆弄食材吗？ |
| 财商教育 | 孩子对零花钱怎么花有想法吗？会主动攒钱或记账吗？ |
| 摄影 | 孩子平时喜欢拿手机拍拍拍、琢磨怎么拍好看吗？ |
| 营地教育 / 户外生存 | 孩子喜欢户外活动吗？愿意离开家跟团队住上几天吗？ |

**兴趣情况判读标准**：

| 大类 | 算"相符"的信号 | 算"不符"的信号 |
|---|---|---|
| 体育运动类 | 有运动习惯、好动、爱跑跳出汗 | 不爱动、能坐不站、提到运动就躲 |
| 音乐表演类 | 主动听音乐、哼唱、打节奏 | 对音乐没反应、从不主动听 |
| 舞蹈体态类 | 听音乐会扭动、爱模仿舞蹈动作 | 听音乐无身体反应、抗拒跳舞 |
| 美术创作类 | 主动涂画做手工、能专注完成 | 很少动笔、坐不住、画不完就放弃 |
| 语言表达类 | 话多爱讲故事、敢当众说 | 不爱开口、人前就退缩 |
| 思维益智类 | 主动拼搭下棋、爱琢磨问题 | 对动脑游戏没耐心、遇难题就绕开 |
| 文化素养类 | 主动看书听故事、爱问"为什么" | 很少翻书、听故事坐不住 |
| 生活素养与其它 | 所问班级的专用话术得到正向回应 | 专用话术被明确否定 |

家长答不清或没答 → 记"未知"，走第八节兜底，不算相符也不算不符。

> **本表双用途（v1.2.11，SKILL.md 铁律 7）**：除流程四兴趣询问判读外，**流程一/流程三的推荐候选班也按本表做"特质信号核验"**——对话中家长描述的孩子特质（性格文静/内向、不爱开口、坐不住、好动、不爱动、怕水、对音乐没反应、很少翻书等）命中某大类"算不符的信号"时：流程一该大类班默认不进推荐（同方向递补、确需保留附 references_08 第九节适配说明固定句）；流程三类别为家长点名不整类剔除（命中班排序降级、进推荐必附适配说明）——禁止明知特质不符仍无说明直接推荐（六十/六十一测实测）。

## 二、询问执行顺序

1. **先对齐班名**：所问项目经 references_04 第九节班名对照表对齐为标准班名；口语无法对应唯一班级 → 回问"您说的是哪一项？"，禁止猜。
2. **第 1 轮问年龄**（一个问题）："孩子现在几岁？或者告诉我上几年级也行。"
   - 年龄已在前文出现 → 直接采用，禁止重复问。
   - 判定线：班级在 references_05 第八节硬红线表内 → 取"生效年龄"列；表外班级 → 取速查表"最早起始年龄"。
   - 判定不满足 → 直接走分支一，**不再询问**兴趣情况与孩子意愿。
3. **第 2 轮问兴趣与意愿**（年龄满足或未知时；两问合并一轮、分行编号）：
   ```
   1. 「所问大类的话术」
   2. 孩子自己想学「班名」吗？有没有主动跟您提过？
   ```
4. **追问纪律**：任何一问最多追问一轮；仍无 → 视为未采集，按第八节兜底继续推进，结论备注。

## 四、分支一：年龄身体条件不满足

**触发**：孩子年龄 < 生效年龄（硬红线表"生效年龄"或速查表最早起始年龄）。

**输出结构**（按序）：
1. **直接结论**（固定）："以您孩子现在的年龄，「班名」可以先缓一缓，暂时不建议报名。"
2. **不符原因**（三选一，引用原文，禁止改写数值）：
   - 速查表口径（生效年龄 = 速查表最早起始年龄）："该班最早起始年龄是「X」岁，您孩子现在「Y」岁，还没到。"
   - 风险加严口径（生效年龄来自风险红线）："该班虽然最早「速查表起始年龄」岁就能报，但从身体发育角度建议「生效年龄」岁后再开始：「references_05 红线机制与权威建议原文压缩」。"
   - 速查表外项目（references_05 第九节独有班）："该项目建议「红线年龄」岁后再开始：「红线要点」。另外该项目未收录在精选指导表中，费用与课程安排请以当地机构为准。"
3. **替代建议**（可选，规则见下）："如果想先安排起来，同类的「替代班名」最早「A」岁就能开始，可以先考虑——「替代班优势，取 references_04 优势列原文」。"
   - 规则：仅限速查表内、与所问班级**同大类**、孩子年龄已满足最早起始年龄的班级，最多列 2 个；替代班在硬红线表内的，各自附安全提示。
   - 同大类没有年龄满足的班级 → 不给替代建议，改说（固定）："可以先留意着，等孩子到了年龄再报也不迟。"
4. **尾句**（固定，有替代建议时必附，无替代建议不附）："请确认您家附近有开设此兴趣班，以便您带着孩子报名学习。"

## 五、分支二：条件满足兴趣情况不符

**触发**：年龄/身体条件满足 + 兴趣情况不符（孩子平时没有相关习惯或明确不感兴趣）。

**输出结构**（按序）：
1. **结论**（固定开场）："「班名」对您孩子这个年龄来说是可以学的。平时看不出相关的兴趣习惯也不用太担心——不少孩子是先会做了、才慢慢爱上的，兴趣常常是被'我做到了'的成就感带出来的。"
2. **该班优势**：照录 references_04 优势列原文。
3. **鼓励尝试**（固定）："建议您先带TA上一节体验课，用轻松的方式试一试：课上您在旁边看看TA的投入程度，课后多鼓励、少比较；试过几次还是提不起劲，再换个方向也不迟。"
4. （命中时）**未到建议切入年龄提示**：第八节固定句。
5. （硬红线表内班级必附）**安全提示**：references_05 硬红线表"提示类型"列内容。
6. **尾句**（固定）："请确认您家附近有开设此兴趣班，以便您带着孩子报名学习。"

## 六、分支三：兴趣相符孩子不想学

**触发**：年龄/身体条件满足 + 兴趣情况相符 + 孩子自己不想学。

**输出结构**（按序）：
1. **结论**（固定开场）："从您的描述看，孩子平时对这个方向是有兴趣基础的，但TA自己现在还不想学——这个信号值得认真对待：硬报容易把"喜欢的事"变成"要交的差"，反而把兴趣磨没了。"
2. **体验课建议**（固定）："建议先带TA上一节体验课再定。提前跟孩子说好"就是去玩一玩，不喜欢咱们就走"，把选择权交给TA，孩子反而更愿意尝试。"
3. **观察要点**（固定）："体验课上您可以重点观察三点：①TA是主动参与，还是全程旁观应付；②下课后TA还会不会主动提起这件事；③直接问TA"下次还想来吗"，听TA自己的答案。还想来，再正式报名不迟；明确说不想，就先放一放——保护兴趣比赶进度重要。"
4. （命中时）**未到建议切入年龄提示**：第八节固定句。
5. （硬红线表内班级必附）**安全提示**。
6. **尾句**（固定）："请确认您家附近有开设此兴趣班，以便您带着孩子报名学习。"

## 七、分支四：全部通过

**触发**：年龄/身体条件满足 + 兴趣情况相符 + 孩子自己想学。

**输出结构**（按序）：
1. **结论**（固定）："「班名」目前看很适合您孩子：年龄条件满足、平时也有相关的兴趣习惯、TA自己也想学——三个条件都齐了，可以着手了解报名。"
2. **学习优势**：照录 references_04 优势列原文。
3. （命中时）**未到建议切入年龄提示**：第八节固定句。
4. （硬红线表内班级必附）**安全提示**。
5. **尾句**（固定）："请确认您家附近有开设此兴趣班，以便您带着孩子报名学习。"

## 八、通用附录：兜底与固定句

**1. 未采集信息兜底**（追问一轮仍无 → 按此处理，结论必须附备注句）：

| 未采集项 | 处理 | 备注句（固定） |
|---|---|---|
| 年龄 | 不判满足与否；结论附"该班最早「X」岁可开始、建议「Y」岁切入，请您对照孩子的年龄确认"，再按兴趣/意愿实际采集结果走分支二/三/四 | "您孩子的年龄我还没了解到，以上判断请先对照年龄要求确认。" |
| 兴趣情况 | 孩子想学 → 分支四话术；不想学或意愿未知 → 分支三体验课路径 | "孩子平时的相关兴趣情况我还没了解到，建议通过体验课直接观察。" |
| 孩子意愿 | 兴趣相符 → 分支三体验课路径；兴趣不符 → 分支二（不依赖意愿，无需备注） | "孩子自己的想法我还没了解到，建议先上体验课，把选择权交给TA。" |

**2. 未到建议切入年龄固定句**（年龄 ≥ 最早起始年龄但 < 建议切入年龄下限时，插入分支二/三/四）：
"另外，该班的建议切入年龄是「X–Y」岁，您孩子现在「Z」岁——已经到了能开始的年龄，但不用急着系统学，先以体验、感受为主就好。"

**3. 安全提示规则**：
- 所问班级在 references_05 第八节硬红线表内 → 分支二/三/四必附该表"提示类型"列内容（原文或原文压缩，禁止自行编写、禁止省略）；分支一的不符原因已引用风险原文的，不再重复附。
- 分支一的替代建议班级在硬红线表内 → 每个替代班各自附对应提示。
- 仅涉及训练动作的红线（下腰、空翻、足尖、地板动作、指力板等）不否决整班——班级照常推荐，但安全提示必须附（见 references_05 使用规则）。
- 家长提及"疑似脊柱侧弯""听力下降""指根持续隐痛"等健康疑虑 → 一律建议就医，培训不能替代医疗。

**4. 风险资料独有班**（references_05 第九节：大提琴，体操/艺术体操/蹦床/跑酷，力量/抗阻训练，大重量杠铃/举重/长期静力，长距离耐力跑/负重徒步）：
- 可判年龄红线（不满足走分支一；满足走分支二/三/四）；速查表未收录其优势与费用数据。
- 年龄通过时不输出"优势"（无数据可引，禁止编造），改为引用风险资料要点描述项目特点，并附（固定）："该项目未收录在精选指导表中，费用与课程安排请以当地机构为准。"

**5. 固定尾句**（凡给出推荐或体验课建议的输出，最后必附）：
"请确认您家附近有开设此兴趣班，以便您带着孩子报名学习。"
