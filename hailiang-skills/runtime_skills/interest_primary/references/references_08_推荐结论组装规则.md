# 推荐结论组装规则（流程一/流程三共用）

> 用途：流程一 e-f 步与流程三 c-d 步的推荐池组装、验证排除、顺位兜底与结论模板。
> 使用规则（低自由度）：
> - MUST：硬性验证只有三项——**年龄**（生效年龄 = 速查表最早起始年龄与 references_05 硬红线口径取更严格值）、**经历排除**（学过且不喜欢）与**特质信号核验**（家长亲述特质对照 references_06 第一节"兴趣情况判读标准"命中"不符信号"大类的班：流程一默认不进推荐由顺位递补、确需保留必附第九节适配说明固定句；流程三类别为家长点名不整类剔除、命中班排序降级且进推荐必附适配说明——禁止明知不符无说明直接推荐，SKILL.md 铁律 7）。**预算不产生硬排除但参与四级阶梯分级（v1.2.12，第一节）**：预算低于年费区间下限的班降为第三级（年龄满足+预算不足）——仅第一、二级合计不足 3 个时进入推荐、必附"预算可能不足"说明（第九节模板）；过窗且预算不足（第四级）默认不进推荐；预算未知按充足处理、不降级。
> - MUST：任何输出涉及年费/预算/费用对比时，必附价格地区差异提示（第九节固定句）。
> - MUST：推荐清单中命中 references_05 第八节硬红线表的班级，逐班附该表"提示类型"列内容，禁止自行编写、禁止省略。
> - MUST：优势话术照录 references_04 优势列原文；班名用速查表标准名（第二节对齐表转换）。
> - MUST：任何信息最多追问一轮，仍未提供按第十节兜底，结论备注。
> - MUST：**数据来源表述口径（无联网能力）**——本技能全部数据来自内置精选速查表与脚本核验，**结论中禁止出现"检索得出""搜索到""查了资料""网上查的"等暗示联网检索能力的表述**，统一表述为"根据精选指导表的数据""经速查表核验""按表里的数据"（六十二测实测：结论出现"检索得出"类文案，家长会误以为顾问能联网查实时信息——本技能没有该能力，也不承诺实时价格）。
> - MUST：**必问信息先于结论**——各流程结论前的必问项（流程一：基础三问缺失项 + 测评；流程三：基础三问缺失项 + 该类型经历三问；流程二：班名清单；流程四：年龄）收齐前，**禁止输出任何结论、推荐清单、方向列表（含"方向参考/几个方向供参考"变体；把方向名/班名包进问句里试探与直接给结论同罪——"回复只含问句"不是逃生门），禁止先给结论再回头补问必问信息（倒序输出）**（SKILL.md 第二节；十七测实测：开口已给年级但城市/预算未问，模型先输出 5 个方向推荐清单、之后才补问——本文件全部模板仅在必问项收齐后启用）。
> - 禁止：承诺考级、获奖、升学结果；编造速查表/风险资料之外的数据；用主修方向名（"体育竞技"）或泛化词（"运动课"）当班名输出；替家长拍板。

## 一、总则：验证项与预算口径

| 验证项 | 性质 | 口径 |
|---|---|---|
| 年龄 | **硬性**（不满足不进推荐） | 生效年龄 = max(速查表最早起始年龄, references_05 硬红线生效年龄)；≥ 生效年龄即通过；≥ 最早起始但 < 建议切入年龄下限 → 通过，附"未到建议切入年龄，可先体验"句 |
| 经历排除 | **硬性**（学过且不喜欢不进推荐） | 见第三节 |
| 预算 | **软说明+四级阶梯分级殿后**（不硬排除） | 预算 < 年费区间下限 → 降为第三级殿后：仅第一、二级合计不足 3 个时进入推荐 + 必附"预算可能不足"说明（过窗且预算不足=第四级，默认不进推荐）；预算 ≥ 下限 → 可注"在您预算内"；预算未提供 → 按区间列出 + 备注句、不降级 |
| 城市 | 不参与判定 | 仅用于尾句提醒与上下文记录，不做城市差价调整 |

**顺位触发口径**："当前池全部不可推荐"仅指**年龄均不满足或均被经历排除**（含类型库年龄标注不满足的只删项）；预算不足、预算未提供**不触发**顺位。

## 三、经历采集与排除规则

**经历三问**（流程一 d 问全部经历；流程三 b 只问所询类型的经历；分行编号、一轮问完）：

流程一（固定）：
```
为了把推荐做得更准，想再了解几点：
1. 孩子以前学过哪些兴趣班？
2. 已经不学的，当时是因为什么不学的？
3. 现在还在学的有哪些？
```
流程三（固定，"这个类型"替换为用户所询类别，如"体育类"）：
```
1. 孩子以前学过「这个类型」的兴趣班吗？分别是哪些？
2. 已经不学的，当时是因为什么不学的？
3. 现在还在学的有哪些？
```
- 已在前文出现的信息直接采用，禁止重复提问；每问最多追问一轮。

**排除判定表**（每个停学班按原因归类）：

| 停学/在学状态 | 处理 |
|---|---|
| 停学原因：不喜欢、没兴趣、抗拒、学不进去、太累、受挫、压力大 | **不进推荐**（主观负反馈） |
| 停学原因：时间冲突、搬家、换机构、费用、家长安排等客观原因 | 可推荐 + 注明"此前因「原因」停学，与兴趣无关，可重新考虑" |
| 停学原因：自然结课、只是短期体验 | 可推荐，无需注明 |
| 停学原因未问清（追问一轮仍无） | 不排除 + 备注"「班名」停学原因未了解，如与兴趣无关可自行斟酌" |
| 在学且孩子喜欢/状态好 | **优先展示**（第六节），排首位 |
| 在学但明确不喜欢 | 不进推荐（同主观负反馈） |
| 在学、喜欢与否未说明 | 优先展示排首位，话术按"在学班"处理 |

## 四、流程一推荐池组装与顺位

> 班池与排序取数：执行 lookup.py 时把方向作为 directions 参数传入（T11 直接传 score.py 的 t11_directions），返回 direction_packages——该方向全部班级已按第六节四级阶梯排序（第一级 年龄满足+预算充足 > 第二级 过窗+预算充足 > 第三级 年龄满足+预算不足；第四级 过窗+预算不足殿后，级内陪练低在前 > 年费下限低在前），逐班含年龄判定 / 年费 / 预算话术 / 优势原文。对照表取班、换班与顺位截取均以该数据为准，禁止凭记忆报年费与优势。**逐班的年费 / 陪练 / 优势必须取自该班自身的返回值，禁止照抄其他班级返回值或从 references_03 类型库拼凑。**

**常规类型（T1–T10）**：
1. 首选池 = 命中类型行"推荐兴趣班"列原文逐项（写法差异按第二节对齐表归一；速查表外班照录原文，按第二节表外班规则处理）。
2. **任何兴趣班的条件（年龄/年费/陪练/优势）一律查 references_04**：逐项经 lookup.py 年龄硬验证，不满足的**只删不换**（表外班无年龄数据，不判年龄、不编造）。
3. 逐项执行：年龄硬验证（lookup.py）→ 经历排除 → **特质信号核验**（家长亲述特质对照 references_06 第一节判读标准，命中"不符信号"大类的班默认不进推荐，班池内下一班递补；班池全命中 → 按第 5 步顺位继续下一方向；确因方向内无更合适班保留时必附第九节适配说明固定句）→ 预算软说明。通过项进入推荐清单。
4. **截取（v1.2.12 四级阶梯）**：通过项按第六节四级阶梯排序取**前 3——最终推荐最多 3 个班**；**第一级（年龄满足+预算充足）优先**——**已过建议切入上限的班（age_status=past_recommended）默认不进推荐**，仅第一级合计不足 3 个时按第二级（过窗+预算充足）补位，补位必附第六节固定句；一、二级合计仍不足 3 个 → 第三级（年龄满足+预算不足）进入，必附"预算可能不足"说明（第九节）；第四级（过窗+预算不足）默认不进推荐；不足 3 个照常输出、不凑数；表外班排有数据班之后，仅在有数据班不足 3 个时补位。
5. 首选池**全部不可推荐**（仅年龄/经历原因）→ **顺位**：取轨道一得分第 2 名类别 → 班池 = 速查表"主修方向"列等于该方向的全部班级（references_04 第十节）→ 逐班验证排除 → 按第六节排序取前 3。
6. 第 2 名班池仍全部不可推荐 → 继续顺位第 3、4…名，**直到选出至少 1 个班**；6 个方向全部不可推荐（理论极端）→ 按第十节口径在结论中说明原因并建议先体验再定。
7. **恰好推荐 3 个班时**，结论按固定顺序附体验课建议句（第九节）。
8. **安全提示核对（最终输出前必做，逐班）**：推荐清单每个班逐一对照 references_05 硬红线表与 lookup.py 该班返回的 risk_note——**命中必附"提示类型"列原文，不得省略、不得改写**（第八节模板"命中硬红线表"行即本步骤输出落点；十一测-2 教训：T11 推荐游泳，risk_note 有"学会≠会自救"提示，最终结论漏附）。

**T11 均衡探索者**：
1. **组装取数执行 lookup.py**：把 score.py 的 `t11_directions` 作为 directions 传入，返回 direction_packages（已按第六节排序）——每个方向取排序第一的班，禁止同方向取 2 班；references_03 第四节对照表仅作脚本不可用时的备选。
2. 某方向的班年龄验证不过、被经历排除或已过建议切入上限（past_recommended，默认跳过）→ 换该方向班池内排序下一班（班池已按四级阶梯排好，预算不足班殿后）；班池内仍选不出 → 该方向**只删不换（推荐数减 1）**，禁止补库外班；仅当某方向班池全部为过窗班时，才取排序第一的过窗班补位并附第六节固定句；班池仅剩预算不足班时取排序第一、必附"预算可能不足"说明（第九节）。
3. 三个方向都选不出 → 从轨道一第 4 名方向起继续顺位（同常规规则第 5-6 步），直到选出至少 1 个班。
4. 输出形式："「班A」「班B」「班C」——各 1 节体验课"，并附均衡探索者的试课对比说明（输出本身即体验课建议，不再重复附第九节体验课句）。
5. **安全提示核对同常规规则第 8 步**：三个班逐一对照 references_05 硬红线表与返回值 risk_note，命中必附原文（十一测-2 教训：游泳漏附安全提示）。

## 五、流程三班池组装

> **启用前置**：本节仅在**该类型经历三问已收齐**（学过哪些/为何停学/在学哪些，或已按追问规则处理完毕；"以前啥也没学过"这类全空回答视为已收齐——学过/在学为无、停学原因不适用）后启用——未收齐时先问经历三问（SKILL.md §五b），**禁止先组装班池输出再补问**（十八测实测：问完城市预算直接输出 5 个表演类方向含年费、末尾才补问经历三问——经历排除没跑就推荐，推的班里可能就有孩子学过且放弃的班）。**经历收齐后直接组装班池输出推荐，禁止在此发起 8 题测评**——测评是流程一的环节，流程三不需要（十九测实测：家长答"以前啥也没学过"后被错发测评第 1 轮；零基础正是直接推荐的场景）。取数：逐班年龄判定 / 年费 / 陪练 / 优势取自 SKILL.md 速查数据层（轻量运行环境直接对照，与 lookup.py 同源生成）——年龄判定按「最早起始」与硬红线表「建议生效年龄」取更严值；逐班数值与话术取自该班自身的数据层行，禁止照抄其他班、禁止凭记忆拼凑。

1. 用户所询类别经 references_04 第十节"流程三类别别名对照"对齐到班池（如"体育类"→体育运动类 14 班；"艺术类"→音乐+舞蹈+美术 28 班）；轻量运行环境按 SKILL.md 速查数据层主表「大类」列对齐，对不齐回问，禁止猜。
2. 对不齐（不在对照表内的说法）→ 回问一句"您想看的是哪一类？比如体育、音乐、美术、棋类、编程这些"，禁止猜。
3. 逐班执行：年龄硬验证 → 经历排除 → **特质信号核验（铁律 7 流程三口径：类别为家长点名不整类剔除——命中"不符信号"大类的班不删，排序降级到该类别未命中班之后；进推荐时必附第九节适配说明固定句；全类别命中 → 逐班附说明）** → 预算软说明；输出前按第四节第 8 步逐班核对安全提示（references_05 硬红线表，命中必附原文）。
4. 通过班按第六节排序取**前 3**；在学班优先（第六节）。
5. 班池全部不可推荐 → 按第四节顺位规则处理吗？**不顺位**（流程三无轨道一排序基础）：结论中说明"「类别」的班级目前都不满足年龄条件/都被孩子学过不喜欢"，并给两条出路（固定）："可以等孩子到了年龄再看，或者告诉我孩子的大致兴趣，我帮您从别的类别里找找。"
6. 推荐不足 3 个时如数输出，不凑数。

## 六、排序与优先展示规则

**在学班优先**：孩子在学且属于推荐池/方向的班 → 无条件排首位（不在默认前 3 时插入排首），话术调整："孩子正在学「班名」，这个方向可以继续深入——进阶课、考级班或同方向的横向拓展都值得看。"

**默认排序键**（顺位班池与流程三班池取前 3 时使用，依次比较）：
1. **四级阶梯（v1.2.12，第一排序键——lookup.py 返回已按此排好）**：第一级 年龄满足（建议切入区间内 > 已到最早起始、未到切入下限——后者照常推荐，附下方偏早句）且预算充足 > 第二级 已过切入上限（past_recommended，**默认不进推荐**仅补位）但预算充足 > 第三级 年龄满足但预算不足（殿后，仅第一、二级合计不足 3 个时进入）> 第四级 过窗且预算不足（默认不进推荐）；预算未知按充足处理、不降级；
2. 家长陪练强度：低 < 低–中 < 中 < 中–高 < 高（低在前）；
3. 年费区间下限：低在前。

**未到建议切入年龄的班**（已过最早起始、未到建议切入下限）：照常推荐，附句"「班名」最早「X」岁就能开始，建议「Y」岁左右切入，现在可以先以体验为主"。

**已过建议切入年龄上限的班**（孩子年龄 >「建议切入」上限，lookup.py age_status=past_recommended）：**默认不进推荐**——排序（四级阶梯第二级）排在窗口内与未到下限且预算充足的班（第一级）之后；仅当第一级合计不足 3 个时才补位，补位必附句"「班名」建议「Y–Z」岁切入，孩子现在「X」岁已过这个区间，课程内容偏基础启蒙向、同班孩子会偏小——孩子自己特别感兴趣可以试，否则建议优先看建议切入区间内的同类班"；**禁止"现在学正合适"类自圆其说的表述**（十四测实测：8 岁孩子被推荐建议切入 4–6 岁的班，还附了自相矛盾的解释；六十三测实测：9 岁孩子被推荐建议 5–7 岁切入的游泳，文案写"仍在合适区间内，现在学正合适"——与速查表事实直接相悖，窗口内明明还有 35 班可选）。

## 七、流程一初步结论模板

> 开头必须带"**初步结论**"标识字样，让家长一眼认出这是测评的中期结果；score.py 返回的 prompts 非空时必须逐条输出（不得遗漏），输出位置在声明句之前。

**常规命中**（按序输出，同轮附经历三问——**经历三问已收齐时第 6 步整个跳过**）：
1. "**初步结论**：根据孩子的 8 题作答，TA 的兴趣类型是——**「类型标签」**。「标签描述」（references_03 原文）。"
2. "TA 的主修方向（特长候选赛道）是：**「主修方向」**。"（T5/T6 注明视觉/听觉细分线，T7 注明舞蹈线）
3. 判定依据口语化转述（如"孩子既坐得住、又喜欢按规矩来，理科思维得分最高"），禁止暴露内部规则编号与判定条件原文。
4. 测评提示（仅当计分结果 prompts 非空时，逐条输出，话术取 references_01 第二节末"不计分提示的输出位置与话术"）："另外有个小观察：「提示话术」。"
5. 声明（固定）："以上是兴趣倾向的参考，不是能力诊断——孩子还在探索期，方向会慢慢清晰。"
6. 经历三问（第三节流程一版本，分行编号）——**流程一里经历三问只在初步结论输出后的这一步出现一次，此前的每间测评轮都不发经历类问题**；**条件步骤：经历三问已收齐时第 6 步整个跳过**——执行前核对话历史与已登记参数，学过哪些/停学原因/在学哪些任一时点已收齐（含开口主动交代、测评前前文误发但家长已答过、"没有了/没学过"全空口径）→ **本步跳过不发任何经历问句，直接按第八节模板组装最终结论**（SKILL.md 铁律 2 单点采集 + 已收齐豁免；六十四测实测：经历在测评前已收齐，初步结论后仍原样重发三问被家长回怼；六十六测复犯：先在前文提前发了经历三问，这里又把同一三问复问一遍——经历类问题整段流程一至多出现一次）。

**T11 命中**：
1. "**初步结论**：孩子的 6 类兴趣得分咬得很紧，属于**均衡探索者**——「标签描述原文」。这个阶段广度比深度重要。"
2. "建议从得分最高的 3 个方向（「方向A」「方向B」「方向C」）里各选 1 节体验课，先试再定。"
3. 测评提示（同常规命中第 4 条，有则输出）。
4. 声明 + 经历三问（同上——**已收齐则跳过经历三问**）。

**轨道二零命中（fallback）**：按 score.py 返回的第 1 名主修方向取 references_03 兜底类型行（体育竞技→T1、理科思维→T3、实验探究→T4、艺术感知→T5、语言沟通→T8、人文素养→T9），输出（固定开场）："**初步结论**：孩子的作答没有匹配到典型类型，先按得分最高的「方向」方向给您参考——"后接该兜底行的标签、描述、主修方向、声明与经历三问（**已收齐则不附**）；最终推荐仍以第 1 名方向班池组装（顺位规则从第 2 名起备用）。

## 八、最终结论模板（流程一/三共用）

> **【模板启用前置自检——任何一条未满足，禁止套用本节模板输出】**：①经历三问已收齐（学过哪些/为何停学/在学哪些，或已按追问规则处理完毕）；②流程一场景测评已完成并计分；③推荐班 **≤3 个**（多了必须截到 3，不足 3 照常输出不凑数）；④每个班名已过 lookup.py / 速查数据层逐班核验；⑤**每个推荐班已逐班写明年龄适配**（照录该班 age_note、须与孩子年龄自洽——超出建议切入区间禁写"年龄条件满足"，禁止只写"结合孩子的年龄"一笔带过）。任一条未满足 → 本轮回复只发对应问句，不输出任何方向名、班名、年费或结论（十八测实测：城市预算问齐后直接输出 5 个方向含年费，末尾才补问经历三问，还套用了"恰好 3 个"才该附的体验课句——倒序+超量同源，全部由本自检拦截）。

> **不复述初步结论**：最终结论不整段复述上一轮已输出的初步结论——类型标签/画像/主攻方向不再原样重述，直接进入推荐班与新增内容；相邻回复禁止大段重复（十四测实测：经历补充轮把初步结论整段重发，两轮回复大面积雷同）。

**【推荐兴趣班】**逐班输出（**最多 3 个班**，每个班一条，顺序按第六节）：
- **班名**（速查表标准名；T11 加"——各 1 节体验课"形式；表外班照录类型库原文含"（低龄段）"标注）
- **优势**：references_04 优势列原文**逐字照录，禁止改写、缩写或自编**（lookup.py 的 advantage 字段即该原文）；推荐清单缺少优势条目视为不合格输出；**表外班无优势数据，不展示**
- **年龄适配**：照录该班 age_note（如"年龄条件满足（建议6–12岁切入）"；过窗班照录"孩子9岁已过建议切入区间（6–8岁）"）——**年龄核验必须逐班可见，禁止只写"结合孩子的年龄"一笔带过**；**须与孩子年龄自洽——超出建议切入区间禁写"年龄条件满足"、须照录过窗口径**（七十测实测：推荐滑板/攀岩等班，通篇无一句年龄适配说明；七十一测实测：推荐班年龄区间与孩子年龄不符、仍无任何说明）
- 年费：区间原文（lookup.py 该班返回值，禁止照抄其他班的数值）；预算不足时接"预算可能不足"说明（第九节）；预算内可注"在您预算内"
- 在学班：第六节进阶话术替换常规优势引导
- 命中硬红线表：附安全提示（references_05"提示类型"列内容）
- 未到建议切入年龄：第六节固定句
- 过窗班（第二级补位）：第六节过窗固定句必附——**禁止对已过切入区间的班写"现在学正合适""正合适"类自圆其说表述，窗口判断以速查表「建议切入」列为准，不得口头放宽**（六十三测实测：9 岁孩子推荐建议 5–7 岁切入的游泳，文案写"仍在合适区间内，现在学正合适"）
- 预算不足班（第三级进入）：必接"预算可能不足"说明（第九节）

**【推荐说明】**（发生了才写，逐条）：
- 顺位说明："「原类型/方向」对应的班级目前都不太合适（「原因概括」），所以参考了得分第二的方向「方向」。"
- 排除说明："「班名」孩子以前学过且不喜欢，就没有放进来。"
- 年龄不满足删项、T11 减推荐等，各用一句说清。

**【备注】**：未采集信息逐条（第十节备注句）；速查表未收录的表外班（第二节）附"以当地机构为准"备注。

**收尾**（固定顺序）：
1. 涉及年费/预算 → 价格地区差异提示（第九节固定句）。
2. **恰好推荐 3 个班（常规类型）→ 体验课建议句**（第九节固定句；T11 输出形式本身即体验课，不重复附）。
3. 尾句（固定，必附）："请确认您家附近有开设此兴趣班，以便您带着孩子报名学习。"
