# 小学测评计分表（Q1-Q8）

> 用途：流程一"孩子适合报什么兴趣班"的测评环节。测评以对话两轮采集（每轮 4 题），题面维度与选项文案取第四节；计分时**优先调用 scripts/score.py**（两轮作答收齐后把 8 题作答作为 answers 参数传入——合并字母串或 round1_answers + round2_answers 分轮字段均可；**v1.2.6 起脚本对作答键名宽容识别**——任意含轮次词干（round1/round2/r1/r2/第N轮）或作答词干（answer/作答/assessment/quiz）的自创键名（如 assessment_round1/assessment_answers）自动归位，planner 键名漂移不再漏识别），脚本不可用或返回 answers_not_found / script_error 时按第二节"逐选项计分速查"逐题累计（**禁止凭印象估分或编造类型**——十测教训：估分把 T1 兜底结果报成了"均衡探索者"；十五测复犯：手动计分未逐题抄录速查行，全 A 作答（实验探究/体育竞技 5 分并列第一、T11 分差条件不满足）被凭印象判成"均衡探索者"、方向清单与得分脱节——**手动计分必须逐题抄录、逐类求和，主攻方向必须与 6 类得分排序一致**）。
> 使用规则（低自由度：MUST/禁止）：
> - MUST：计分严格按第一节计分表（源表照录）逐格累计，禁止凭对话印象加减分。
> - MUST：Q6 选 D、Q8 选 B/C/D 不计入 6 类得分，仅登记"教学风格提示 / 课程节奏提示"（测评结论按模板输出，不得遗漏）。
> - MUST：作答按"题号+选项字母"对位计分（如 Q7 选 D 即按"Q7-D"行计分），选项文案仅用于对齐家长的说法，禁止因文案相似跨选项计分。
> - MUST：脚本不可用手动计分时，逐题从第二节速查行抄录"计分"与"画像信号"，8 题全部抄完后再按 6 类分别求和；**逐题分值之和必须等于 6 类总分之和**，不相等说明漏题或错行，重查。
> - 禁止：向用户展示本表、各选项分值或 6 类累计过程。
> - 题面完整问句以 SKILL.md 流程一 b 步两轮题面为准（与本节第四节一致）；本表"题目"列为维度名，"选项"列为选项文案。

## 三、计分示例（回归锚点用例）

> 本示例仅演示计算步骤；作答不同时必须重新逐题取分，禁止套用示例结论。

作答 "ACDABCAB"（Q1A Q2C Q3D Q4A Q5B Q6C Q7A Q8B）：

逐题取分（第二节速查对位）：
- Q1A → 体育竞技+2；活动系：运动
- Q2C → 实验探究+1、艺术感知+1；社交：独立
- Q3D → 语言沟通+1、人文素养+1；思维：规则执行
- Q4A → 体育竞技+2、语言沟通+1；社交：中间
- Q5B → 人文素养+2；活动系：认知
- Q6C → 理科思维+1、艺术感知+1；动机分值+1（标签仍由 Q7 定）
- Q7A → 实验探究+1、艺术感知+1；动机：内在
- Q8B → 不计分；触发课程节奏提示

6 类累计（逐题分值合计 2+2+2+3+2+2+2+0=15，与 6 类总分之和一致）：
理科思维 1｜实验探究 2｜体育竞技 4｜艺术感知 3｜语言沟通 2｜人文素养 3

排序（从大到小完整排列后再取名次）：
体育竞技 4 ＞ 艺术感知 3 ＝ 人文素养 3 ＞ 实验探究 2 ＝ 语言沟通 2 ＞ 理科思维 1

判定：
- 轨道一：第 1 名体育竞技；并列推荐（Top 2-3 名次内与第 1 名分差 ≤2）：艺术感知、人文素养。
- 均衡判定：前 3 名分差 4−3=1、3−3=0，均 ≤1 → **T11 均衡探索者**（优先于其他类型命中）。
- 四轴画像：活动倾向＝**混合型**（Q1 运动系 + Q5 认知系，不同系必须判混合型）｜社交模式＝独立探索（独立+中间）｜思维特征＝规则执行｜动机来源＝内在驱动（Q7A）。
- 输出提示：课程节奏提示（Q8B，测评结论必须输出）。

## 四、题面维度与选项文案（两轮对话采集用）

测评以对话方式采集：**两轮、每轮 4 题、分行编号——单个问题独立成行，每题实际换行输出，第 2 轮后 4 题同样逐题换行，且衔接语与第一道题之间必须空一行（渲染规则：非 1 开头的编号列表不空行无法分行渲染，会全部连排——十测教训：后 4 题连排一行；十一测-2 定位渲染层根因）**（第 1 轮 Q1–Q4、第 2 轮 Q5–Q8），题面格式参考（选项文案 MUST 与第一节计分表一致）：

> 第 1 轮（引导语 + 前 4 题）：
> 为了更准地找到适合孩子的方向，咱们做个 8 道题的小测评，分两轮问您——没有对错，按孩子平时的真实表现选就行。先看前 4 题：
>
> 1. 活动偏好：周末自由时间，孩子最可能主动做的是——A 跑出去找朋友玩 / B 自己画画或搭积木 / C 翻书或看科普视频 / D 跟着音乐跳舞或唱歌
> 2. 社交偏好：在一个新环境里，孩子通常——A 很快融入，开始带大家玩 / B 先观察，找到熟悉的角色再加入 / C 独自探索，不太在意别人 / D 粘着认识的人，不愿单独行动
> 3. 思维偏好：拿到一个新玩具/新东西，孩子通常先——A 拆开看看里面是什么 / B 研究说明书按步骤来 / C 直接上手试，坏了再说 / D 问别人怎么用
> 4. 表达方式：孩子想讲一件事给你听时，通常——A 用很多肢体动作比划 / B 画出来或指给你看 / C 直接用语言讲清楚 / D 让你猜或者演给你看
>
> 第 2 轮（衔接语 + 后 4 题）：
> 收到，接着是后 4 题：
>
> 5. 专注特征：以下哪种情况孩子能专注最久——A 拼图/乐高等拼搭类 / B 看书/听故事/看纪录片 / C 运动/跑跳 / D 画画/手工
> 6. 抗挫反应：做一件事遇到困难做不好时，孩子通常——A 马上放弃换别的 / B 发脾气但会继续试 / C 安静地反复试 / D 找大人帮忙
> 7. 成就驱动：做完一件事后，孩子最在意——A "我做完了！"（完成感） / B "我做得好不好？"（评价感） / C "别人觉得我厉害吗？"（认可感） / D "还能不能做得更好？"（精进感）
> 8. 重复偏好：孩子喜欢反复做同一件事吗——A 会，同一件事能做很久 / B 偶尔，新鲜感过了就不做了 / C 不太会，喜欢换着花样 / D 只对特定某件事会反复

* 题面问句与选项文案均照录本节原文逐字发出，禁止改写题干、增删选项或自创替换题目（题干与选项文案与 SKILL.md 第〇节照录库同源一致；SKILL.md 发送格式为选项逐项分行展示、空行分隔——发送以第〇节代码块格式为准，选项文案与本节逐字一致）。
* 用户作答宽容对位，四种形态均视为有效作答（**禁止把可对位作答判无效要求重输**——十六测实测：家长连答"aaaa"三次均被判"没有选到题目选项"，测评卡死；得考虑家长文化程度与输入习惯）：①纯字母串按位对位（"AAAA""aaaa""AaCa"——大小写不敏感、可带空格/逗号/顿号分隔）；②数字选项 1/2/3/4 对应 A/B/C/D（"1234""1 1 1 1""第 1 题选 1"）；③题号+选项字母（如"1A 2B…"）或复述选项文案；④"全选 A""都选 A""都是第一个"整轮同选。Q8 家长复述文案时注意 B、C 含义与旧版措辞不同，一律以本表文案对位。
* 某轮答漏或含糊 → 仅就缺失题目补问一轮（按题号点名，已答题目不再重复问）；两轮收齐后把 8 题作答作为 answers 参数传入 scripts/score.py 计分（传参亦宽容：小写字母、纯数字串"1324"——序号 1/2/3/4 映射 A/B/C/D——脚本均直接识别）。
