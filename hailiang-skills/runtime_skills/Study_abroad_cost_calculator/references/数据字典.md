# 数据字典

本文件说明留学费用计算器所用数据表、配置文件的字段含义和数据来源。  
所有数据文件位于 `assets/` 目录。

---

## 一、schools.json

学校主数据表。用于定位院校基本属性。全库条数汇总见 `assets/meta.json` 的 `counts`。

| 字段名 | 类型 | 说明 | 示例 |
|---|---|---|---|
| `school_id` | int | 主键 | 1001 |
| `name_zh` | string | 中文名称 | 阿德莱德大学 |
| `name_en` | string | 英文名称 | Adelaide University |
| `aliases` | array | 别名列表 | ["Adelaide Uni", "AU", "阿大"] |
| `school_type` | enum | 公立/私立 | 公立 |
| `country` | string | 所属国家 | 澳大利亚 |
| `city` | string | 所在城市 | 阿德莱德 |
| `country_city` | string | 国家-城市 | 澳大利亚-阿德莱德 |
| `city_tier` | enum | 城市层级 | 二三线 |
| `qs_rank` | string | QS排名（如有） | QS全球前90 |
| `data_year` | int | 数据来源年份 | 2026 |

---


**别名红线（2026-09-21）**：`aliases` 里**不放裸短词**。短别名必须是「地域/校名前缀 + 短词」
（`港科大` / `港理大`）或大写字母缩写（`HKUST` / `NUS`）。原因：裸短词会落进别的词的内部，
把整句话误判成点名该校——实测 `香港科技大学` 曾收 `科大` 作别名，导致
「商**科大**概多少钱」被判成点名港科大、静默只返该校一条数据（详见“口径说明与边界.md”6.5 第 0 条）。
该别名已于本次删除，保留 `港科大`。

## 二、tuition.json

学校专业费用表。确认学校对应的专业学费。

| 字段名 | 类型 | 说明 | 示例 |
|---|---|---|---|
| `school_id` | int | 关联学校ID | 1001 |
| `name_zh` | string | 中文名称 | 阿德莱德大学 |
| `level` | enum | 升学阶段 | 本科 |
| `major_category` | enum | 专业大类 | 商科 |
| `tuition_min` | decimal | 学费下限（年） | 43500.0 |
| `tuition_max` | decimal | 学费上限（年） | 43500.0 |
| `currency` | enum | 费用币种 | AUD |
| `period` | enum | 学费周期 | year |
| `data_year` | int | 数据来源年份 | 2026 |

说明：**表内存在该 (学校, 专业) 组合的行 = 该校开设该专业方向**；查不到该组合的行 = 该校**未**开设该专业方向，取数时按「该校不提供」处理。表内不出现 `null` 学费——「学费为空」与「未开设」在语义上无法区分、容易被误读成「开了但没取到学费」，因此原先 130 条空值行已于 2026-09-20 全部删除（块级删除，只摘目标记录、其余字节不动；明细见版本目录 `_删除清单_空学费行_20260920.md`）。当前 `tuition.json` 共 551 行。用户选「不限」专业时按**统一概括**取数：该范围内全部行的 `tuition_min` 最小值 ～ `tuition_max` 最大值，对应明细表标签 `学费（各专业/年）`（不逐专业拆分）。

## 五、visa_medical.json

本科留学生签证及医疗保障费用表。

| 字段名 | 类型 | 说明 | 示例 |
|---|---|---|---|
| `country` | string | 所属国家 | 英国 |
| `visa_type` | enum | 签证类型 | Student visa |
| `visa_fee` | decimal | 签证费 | 558.0 |
| `visa_validity` | string | 签证有效期 | 课程周期 |
| `medical_insurance_type` | string | 医疗保险类型 | 政府医疗附加费（IHS） |
| `medical_insurance_min` | decimal | 医疗保险费下限 | 776.0 |
| `medical_insurance_max` | decimal | 医疗保险费上限 | 776.0 |
| `medical_insurance_period` | enum | 医疗保险费周期 | year |
| `currency` | enum | 费用币种 | GBP |
| `data_year` | int | 数据来源年份 | 2026 |
| `note` | string | 备注 | 学生IHS按年度计费，实际申请费用按签证覆盖时间计算 |

计算时**不合并**：`visa_fee`（办理一次性、单值）与 `medical_insurance_min` / `medical_insurance_max`（按年、区间）分别取数。

`scripts/engine.py` 的 `get_visa_medical_detail()` 返回两者的人民币值与原币值；`calc_country_cost()` 再相加得到旧口径的「签证及医疗费」合计，逐国相等。

引擎明细字段：`details_cny.medical_min` / `medical_max` / `visa_min` / `visa_max`，以及 `details_original.medical` / `visa`（各为 `{min, max, currency}`，混币种时为 `null`）。展示规则见报告模板 §2.2。

## 七、config.json

全局配置。包含预算区间、维度枚举、专业关键词、国家别名、兜底话术、预算匹配话术、风险说明等。

### 7.1 预算区间 `budget_bands`

| code | min | max |
|---|---|---|
| 10万以下 | 0 | 10 |
| 10万-20万 | 10 | 20 |
| 20万-30万 | 20 | 30 |
| 30万-50万 | 30 | 50 |
| 50万以上 | 50 | null |
| 暂不确定 | null | null |

说明：`code` 与 `questionnaire.json` 的选项 value 逐字一致；脚本的预算上限（元）由本表 `max` 推导（`max × 10000`，`max` 为 null 时无上限），改这里即生效。

### 7.2 维度 `dims`

- `majors`：商科、文科、理科、工科、医学、艺术
- `school_types`：公立、私立、无偏好（无偏好 = 不筛）
- `city_tiers`：一线、二三线、无偏好（无偏好 = 不筛）
- `no_major_tuition`：医学、艺术（仅提示，不参与计算）

### 7.3 专业关键词 `major_keywords`

用于从自然语言中匹配专业方向。每个专业方向对应一组中英文关键词。当前共 **781** 个词条
（同一写法重复 2 处，去重后 779），分属 6 个大类（商科 123 / 文科 162 / 理科 103 / 工科 193 / 医学 85 / 艺术 115）。
（2026-09-22 第三十六次：`建筑` / `建筑学` / `architecture` / `architectural` 由**艺术**移入**工科**，
总词条数与其余 5 个大类的计数均未变。）

这张表有**两个用途**，不要混为一谈：

1. **全文扫描**：没有结构化 `major` 槽位时，从用户原话里找专业词（规则见口径说明 §7.2、§7.5）。
2. **大类归属回退**：平台已给出 `major` 槽位但值是专业全称（`金融` / `计算机`）时，
   用「词 → 大类」的反向归属表把它归回六大类（规则见口径说明 §7.6）。

> ⚠️ 第 2 个用途是 2026-09-21 补的。此前背向表只用于第 1 个用途，导致 781 个词条里
> 有 674 个（87.4%）在走「显式槽位」路径时**裸透出**、查不到任何学费行，最终误报
> 「按当前条件没有匹配到院校」。

### 7.4 国家别名 `country_aliases`

用于匹配用户提到的国家/地区，如“澳洲” → 澳大利亚，“UK” → 英国。

### 7.5 同类替代话术 `similar_school_fallback`

同类替代固定两级（都建立在「国家相同 + 学校类型相同」之上）：

| 键 | 用途 |
|---|---|
| `priority1_hit_msg` | 第 1 级（专业相同）命中时的开头话术 |
| `priority2_hit_msg` | 第 2 级（不限专业）命中时的开头话术 |
| `priority3_msg` | 两级都取不到时的兜底话术 |
| `school_ambiguous_msg` | 校名歧义（半截校名匹配到多所）时的固定追问 |
| `no_major_tuition_msg` | 无学费数据提示（当前未启用；模型侧提示语见报告模板 §2.3，两处文案已逐字对齐） |

- `priority1_hit_msg` 与 `priority2_hit_msg` **文案逐字相同**，保留两把键只为让脚本按 `result.fallback_level` 取对应文案。
- 两句开头话术均为：`我们暂未收录该校/专业明细，您可了解同类型学校的费用估算情况：`
- `priority3_msg`：`我们暂未收录该校/专业明细，您可以点击页面底部“找机构/课程”按钮，联系相关机构了解更多信息。`

### 7.6 预算匹配话术 `budget_match`

包含多种场景的提示语，见报告模板。各键当前的返回情况：

| 键 | 当前是否会被脚本返回 |
|---|---|
| `matched` | 会（预算覆盖区间） |
| `insufficient_low` | 会（预算上限 < 10 万） |
| `insufficient_high_prefix` | 会（预算上限 ≥ 10 万且有替代区域）；文案 `根据你的年度预算，还可以关注这些区域：`。**所问地区全被剔除时改用下面那条 `all_dropped_msg`**（它自带这句结尾）；点名学校单校路径仍用本键 |
| `country_match_prefix` | **否**（脚本当前不返回；确有国家被剔除时走的是下面那条 `partial_dropped_msg`） |
| `partial_dropped_msg` | 会（部分国家被剔除：有留存、也有被剔除）；文案 `其余地区（{countries}）按当前条件估算的总费用超出了你的年度预算，本次未展开。其总费用区间为：{ranges}。`，`{countries}` = 被剔除国家的名字（按人民币总费用下限降序，最多 5 个，超出时末尾加「等」），`{ranges}` = 被剔除地区的总费用区间（人民币万元，形如 `约 42.6 - 75.9 万人民币`，多国以「；」连接） |
| `all_dropped_msg` | 会（**全部**国家/地区都被剔除且上限 ≥ 10 万，第三十二次 ④-a α 新增）；文案 `你提到的地区（{countries}）按当前条件估算的总费用超出了你的年度预算，本次未展开。其总费用区间为：{ranges}。根据你的年度预算，还可以关注这些区域：`。两个占位符的填法与 `partial_dropped_msg` 相同（下限降序、最多 5 个、人民币万元、`；`连接）；**结尾那句就是 `insufficient_high_prefix`**，命中的话脚本不再拼接它，避免同一句出现两遍。点名学校单校路径不触发本键（该校费用已在正文里） |
| `sufficient` | 否（启用方式待定） |
| `undetermined_no_tuition` | 否（启用方式待定）；点名学校 `no_tuition = true` 时脚本一律不返回预算话术 |

### 7.7 风险说明 `risk_disclaimer`

末尾统一输出。**当前模板不含 `{date}` 占位符**（2026-09-20 起文案不再附数据年份与汇率日期）；脚本 `build_disclaimer()` 的占位符替换逻辑保留，文案里没有占位符时原样返回。

### 7.8 兜底话术 `fallback`

| 键 | 说明 |
|---|---|
| `out_of_scope_msg` | 学段护栏命中时的兜底话术（`action="reject"`、`reason="out_of_scope"`，只给这句话，不给数字、不带风险说明） |
| `unsupported_region_msg` | 范围外地区（中国澳门）命中时的兜底话术（`action="reject"`、`reason="unsupported_region"`，同样不给数字、不带风险说明） |
| `no_school_match_msg` | 表单路径按条件一所院校都没筛出来时的兜底话术（`action="reject"`、`reason="no_school_match"`）；文案 `按当前条件没有匹配到院校。可以放宽学校类型、城市层级或调整专业方向后再来估算。` |
| `unsupported_regions` | 库内不收录的地区及其别名（当前只有 `中国澳门`: 中国澳门 / 澳门 / 澳門 / Macao / Macau）；加一个地区只需在这里加一行 |

## 九、questionnaire.json

问卷配置。定义 5 个字段：

| id | label | 类型 | 必填 |
|---|---|---|---|
| `countries` | 目标留学国家/地区 | multi_select | **是** |
| `major` | 专业方向 | single_select | **是** |
| `school_type` | 学校类型 | single_select | 否 |
| `city_tier` | 城市层级 | single_select | 否 |
| `budget_range` | 预算范围（年） | single_select | 否 |

- **只有 `countries` 与 `major` 是必答项。** 另外三项是**精度过滤项**：用户不选等于「无偏好 / 不限」，
  引擎照常按「国家 + 专业」给区间。因此**绝不允许为了这三项中断输出、追加追问**——
  典型错误是用户已经点名了学校，却被反问「学校类型是公立还是私立」「想去一线还是二三线」。
  学校类型与城市由引擎从库内自解析，用户不需要提供（2026-09-21 修正：此前 5 项全为必填，
  导致模型读成「5 题收齐才能出数」，与线上在架包口径不一致）。
- 选项 value 使用中文枚举，与 `config.json` 逐字一致（`budget_range` 含「万」字写法）。
- `max_fields_per_form = 5`。
- 问卷**不收集**预算具体金额：金额只从用户自然语言或显式 `budget_amount` 槽位识别（见“口径说明与边界.md”3.1）。

**`countries` 选项（2026-09-21 起）**：16 个收录国家/地区 + 末尾一项 `暂不确定`，共 **17** 项，
因此 `max_selections = 17`（曾为 16；选项数一旦超过上限，多选就会提交不上）。

`暂不确定` 的语义 = **所有收录国家/地区各算一遍**（等价于不指定国家），
但它**不是**「跳过」，引擎里会与空数组、不传键走同一条路（见“口径说明与边界.md”6.7）。
与具体国家**互斥**：同一次提交里既有具体国家又有 `暂不确定` 时，整体按「未指定」处理（16 国全算）。

## 十、引擎输出的学校相关字段

`slots` 里与学校有关的字段（第三十二次新增 `school_ids` / `school_queries`）：

| 字段 | 说明 |
|---|---|
| `school_query` | 唯一命中的校名（`single` 时才有值） |
| `school_id` | 唯一命中的 `school_id` |
| `school_ids` | **多校并列 / 对比**时本轮要一起出数的学校（保序，≥ 2 才非空） |
| `school_queries` | 与 `school_ids` 一一对应的校名列表（供播报与排查） |
| `school_ambiguous` | 命中多所且无法确定时置 `true` |
| `school_candidates` | 歧义时的候选校名（最多 6 个；**不再只留最长的那个**） |
| `school_not_found` | 完整命中为空、半截匹配也无结果时置 `true` |

`result.countries` 的条目：每条都带 `school_name` / `school_type` / `city`；
一次点名多所学校时就是**多校对比**形态（报告模板 §2.5），按人民币总费用下限升序。

`result.alternative_countries` 的条目固定只有三个键：`country` / `total_min_cny` / `total_max_cny`——
原币（`currency` / `total_min_original` / `total_max_original`）与明细（`details_cny` / `details_original`）
由 `_slim_alternative()` 收敛掉（第三十二次 ④-b）：替代区域只输出折算人民币区间。

列表本身由 `build_alternative_countries()` 排定：按人民币下限降序、最多 5 条（第三十三次）——
