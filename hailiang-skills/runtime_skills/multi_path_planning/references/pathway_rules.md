# 路径匹配规则（模块⑥）

### 6.5 地区特色路径（不判定，仅展示）

仅当考生省份命中时，在「类别三 · 值得关注卡 ③ 地区特色」子板块列出（不做匹配判定、不显示是否符合）：

- 北京 → 双培外培
- 上海 → 上海春考
- 广西 → 精准专项
- 湖北 → 高职高专乡村振兴专项计划、专本联合培养计划
- 甘肃 → 建档立卡专项、革命老区专项、民族专项
- 青海 → 省内生态专项计划、省内乡村振兴专项计划、省内民族地区教育高质量发展专项计划
- 江西 → 苏区专项 

> 来源：地区特色路径名称与省份.md。这类路径因各省政策差异大，匹配引擎不强行判定，仅做信息提示，建议考生查阅本省考试院。

### 6.6 逐条匹配规则

每条路径列出「匹配情况」，满足任一即判定 ✅匹配；否则 ❌不匹配并给出首条未满足原因。偏好驱动型若 `职业兴趣` 不含对应标签 → 标记「未触发（未选对应稳就业方向）」，不展开硬条件。

**【自动规则型 / 身份驱动型】**

**普通高考**：始终 ✅匹配（保底路径，无门槛）。

**少年班**
- 情况一：五大学科竞赛获奖等级 ∈ {省一, 省二，省三, 国奖}（省级及以上）且 预估总分 ≥ TL（物理类/统一）
- 情况二：五大学科竞赛获奖等级 = 国集（国家集训队）

**保送生**
- 情况一：五大学科竞赛获奖等级 = 国集

**强基计划**
- 情况一：预估总分 ≥ TL（对应科类/统一）

**综合评价**
- 情况一：预估总分 ≥ TL（对应科类/统一）

**省属三位一体**
- 情况一：省份=浙江 且 预估总分 ≥ (BL−40) 且 预估总分 < (TL+40) 且 学考合格 ≠ 否
- 注：浙江 BL=494 → 下限 454；TL=594 → 上限 634

**小语种高考**
- 情况一：年级 ∈ {高一, 高二} 且 高考外语科目=英语 且 英语分 ≤ 70
- 情况二：高考外语科目≠英语

**高职单招**
- 情况一：预估总分 < (BL−20)


**少数民族招生**
- 情况一：`collected.民族` = 非汉族

**边防军人子女预科班**
- 情况一：`collected.边防军人子女` = 是

**港澳台华侨招生**
- 情况一：`collected.学生类型` = 港澳台考生
- 情况二：`collected.学生类型` = 华侨身份考生

**艺术升学 / 体育升学（子流程，规则已补充）**
- **不在主匹配引擎判定**：模块④已不在收集阶段询问艺术 / 体育特长（见 SKILL.md 4.3 调整）。
- **触发**：在「类别三 · 值得关注卡 ②」简要介绍艺体路径后，若用户表示感兴趣 → `stage = art_sports`，进入艺体匹配子流程。
- **匹配规则**：读取 `references/art_sports_rules.md`（**规则已补充完整**：艺术升学高一/高二三档命中、高三归谨慎判断；体育统招/单招/高水平按学段+运动员等级命中、高三归谨慎判断）。

**【偏好驱动型】**

**中外合作办学**
- 情况一：教育预算 ≥ 5万/年
 - 注：用户没有出国升学意向的情况下，补充说明中外合作办学4+0模式可全程在国内就读。

**港澳升学**
- 情况一：英语分 ≥ 100 且 预估总分 ≥ BL(本科线/一段线) 且 教育预算 ≥ 5万/年 且 

**海外升学**
- 情况一：地域偏好接受出国=是 且 教育预算 ≥ 5万/年

**公费师范生**（需职业兴趣含师范类）
- 情况一：职业兴趣含师范类 且 预估总分 ≥ (TL+50)

**军校招生**（需职业兴趣含军警类）
- 情况一：军警类 且 裸眼视力≥4.5 且 性别男 且 身高≥162 且 高考外语科目=英语
- 情况二：军警类 且 裸眼视力≥4.5 且 性别女 且 身高≥158 且 高考外语科目=英语

**公安警校招生**（需军警类）
- 情况一：军警类 且 裸眼视力≥4.8 且 性别男 且 身高≥170
- 情况二：军警类 且 裸眼视力≥4.8 且 性别女 且 身高≥160

**司法警校招生**（需军警类）
- 情况一：军警类 且 裸眼视力≥4.7 且 性别男 且 身高≥170
- 情况二：军警类 且 裸眼视力≥4.7 且 性别女 且 身高≥160

**定向培养军士**（需军警类）
- 情况一：军警类 且 裸眼视力≥4.5 且 性别男 且 身高≥160
- 情况二：军警类 且 裸眼视力≥4.5 且 性别女 且 身高≥158

**三大招飞**（需职业兴趣含飞行员）
- 情况一：飞行员 且 预估总分 ≥ 本省满分×60%（750→450 / 660→396 / 900→540）且 高考外语科目=英语 且 英语分≥95 且 身高∈[168,190] 且 裸眼视力≥4.0 且 选科含物理+化学
- 情况二：飞行员 且 预估总分 ≥ TL（物理类/统一）且 高考外语科目∈{英语，俄语} 且 身高∈[165,185] 且 裸眼视力≥5.0 且 选科含物理

**定向招生**（需职业兴趣含农科类、医学类）
- 情况一：职业兴趣含农科类 且 预估总分 ≥ BL（本科线/一段线）
 - 注：即公费农科生/定向农科生；建议查询本省报名要求，部分省份要求农村户籍或户籍归属定向就业县域，匹配时提示「建议核实户籍条件」。
- 情况二：职业兴趣含医学类 且 预估总分 ≥ BL（本科线/一段线）
 - 注：即公费医学生/免费医学定向生；建议查询本省报名要求，部分省份要求农村户籍或户籍归属定向就业县域，匹配时提示「建议核实户籍条件」。
