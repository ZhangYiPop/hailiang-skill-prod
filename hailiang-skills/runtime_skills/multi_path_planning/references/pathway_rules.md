# 路径匹配规则 · 人读说明（references / pathway_rules.md）

> **调用时机**：需要理解「路径怎么判、职业兴趣怎么映射、地区特色是什么、单路径要哪些字段」时读本文件；引擎返回 `need_facts` 需要解释补问口径时读本文件。
> **使用纪律**：**匹配判定一律调 `scripts/engine.py`，不自行逐条人工判定**。可判数据（逐条阈值、职业兴趣映射、地区特色、路径文案、单路径字段集、路径别名）已迁至 `assets/pathway_rules.json`，由引擎内部读取；本文件只保留**口径说明**（符号口径、判定优先级、档位门槛语义），不含阈值数值表。规则未覆盖的路径不输出（白名单见 SKILL.md ⑦）。

## 6.1 成绩口径与符号（读本文件后按此理解引擎判定）

- 「预估总分」= profile 单次预估；「英语分」= profile 单次英语分。引擎直接用 `collected.estimated_score` / `collected.english_score`。
- 科类来源：3+3 省份取统一线；3+1+2 取首选（`subject_choice` 含物理 → 物理类，否则历史类）；老高考（西藏 / 新疆）同按 `subject_choice`（含物理 → 理科，含历史 → 文科）取列（SKILL.md 4.1）。
- 符号：`TL` = 对应科类特控线；`BL` = 本科线/一段线；`BL−20` = 本科线减 20；`特控线+40` / `一段线−40` = 浙江三位一体上下限；`特控线+50` = 公费师范生线；招飞「本省总分 60%」按满分计（750→450、660→396、900→540）。线值取自 `assets/province_line.json`（引擎内部读）或用户当场给线（优先级见 `province_lines_2026.md` §5.3）。
- 硬性体检条件（身高/视力/性别）只做规则对照，不做医学判断；户籍/政策类只做提示。

## 6.2 优先考虑特定职业 → 职业兴趣映射（SKILL.md 4.4 写入 collected.career_priority）

**入口**：`aspiration_goal`（多选）**含**「优先考虑特定职业」→ 展开二级 `career_priority`（全档共用同一入口与同一套二级选项）。

可多选，逗号分隔：军警→军警类；师范→师范类；农学→农科类（定向招生，需总分≥本科线）；医学→医学类（定向招生，需总分≥本科线）；飞行员→飞行员。
据此触发偏好驱动路径：军警类→军校/公安警校/司法警校/定向培养军士；师范类→公费师范生；农科/医学类→定向招生；飞行员→三大招飞。

> ⚠️ **专科档（二段专科线上·一段本科线下）的收口**：该档分数低于本科线，二级选项中只有「军警」下的**定向培养军士**无分数门槛、可正常 ✅（专科层次路径）；其余路径（军校/公安/司法/公费师范生/定向招生）均按下方「档位不适用门槛」判 ➖不适用，不输出 ❌ 卡，避免给专科档学生推一串「你不够格」的卡片。

> ⚠️ **`aspiration_goal` 各取值的判定侧作用**（单字段、多选、全档共用一套选项；分层在判定侧、不在表单侧）：「冲刺更好的院校层次」**仅在 `tier_3` 且 `education_budget` ≠ 5万以上（含未答）时**把中外合作办学转 7.2④ 展示（判定见下方「中外合作办学」的值得关注分支），其余档位与情形不产生作用；「优先考虑特定职业」展开二级 `career_priority`；「没有明确想法」为默认取值。`tier_4` 整题不发（SKILL.md 4.2）。

## 6.3 地区特色路径（不判定，仅展示）

仅当考生省份命中时，在「类别三 · 值得关注卡 ③ 地区特色」子板块列出（不做匹配判定、不显示是否符合）。命中清单见 `assets/pathway_rules.json` 的 `region_features`：

- 北京 → 双培外培
- 上海 → 上海春考
- 广西 → 精准专项
- 湖北 → 高职高专乡村振兴专项计划、专本联合培养计划
- 甘肃 → 建档立卡专项、革命老区专项、民族专项
- 青海 → 省内生态专项计划、省内乡村振兴专项计划、省内民族地区教育高质量发展专项计划
- 江西 → 苏区专项

> 这类路径因各省政策差异大，匹配引擎不强行判定，仅做信息提示，建议考生查阅本省考试院。

## 6.4 逐条匹配规则（判定由引擎实现，本节只讲口径）

每条路径列出「匹配情况」，满足任一即判定 ✅匹配；否则 ❌不匹配并给出首条未满足原因。偏好驱动型若 `career_priority` 不含对应标签 → 标记「未触发（未选对应职业方向）」，不展开硬条件。**逐条规则与阈值的唯一出处是 `assets/pathway_rules.json` + `scripts/engine.py`，本文件不再重复数值。**

**判定优先级**：先看「档位门槛」（若该路径有）→ 不满足则判 **➖不适用**，直接跳过、不进入 ❌ 判定、不输出卡片；档位门槛通过后，再看是否需要 `career_priority` 标签；最后逐条比对硬条件得出 ✅/❌。

**前置口径 · `tier` 未定**（`gaokao_province` = 不参加内地高考）：先按 SKILL.md ⑥「无内地成绩口径」的判据归类 —— 以内地分数线 / 内地竞赛为前提的一律 ➖不适用，不以此为前提的照常走下方逐条判定。此时「档位门槛」一栏视为不适用，不得据以判 ✅/❌。

**【自动规则型 / 身份驱动型】**

- **普通高考**：`gaokao_province` ≠ 不参加内地高考 → 始终 ✅（保底，无门槛）；= 不参加内地高考 → ➖不适用。
- **少年班**：竞赛获奖（省级及以上）且预估总分 ≥ TL；或国家集训队。
- **保送生**：国家集训队。
- **强基计划 / 综合评价**：预估总分 ≥ TL。
- **省属三位一体**（浙江）：BL−40 ≤ 预估总分 < TL+40 且学考合格 ≠ 否。
- **小语种高考**：高一/高二 且 外语=英语 且 英语分 ≤ 70；或外语≠英语。
- **高职单招**：预估总分 < BL−20。
- **少数民族招生**：非汉族。
- **边防军人子女预科班**：是边防军人子女。
- **港澳台华侨招生**：港澳台考生 / 华侨身份考生。
- **艺术升学 / 体育升学（子流程）**：不在主引擎判定，走 `stage=art_sports` 读 `art_sports_rules.md`。

**【偏好驱动型】**

- **中外合作办学**：教育预算 ≥ 5万/年 → ✅；值得关注分支（转 7.2④、不进 ✅）：`tier_3` 且预算 ≠ 5万以上（含未答）且诉求含「冲刺院校层次」。
- **港澳升学**：英语分 ≥ 100 且 预估总分 ≥ BL 且 预算 ≥ 5万/年。
- **海外升学**：地域偏好接受出国 且 预算 ≥ 5万/年。
- **公费师范生**（需师范）：预估总分 ≥ TL+50（< BL 不适用）。
- **军校招生**（需军警）：预估总分 ≥ TL 且 视力≥4.5 且 性别/身高达标 且 外语=英语（< BL 不适用）。
- **公安警校招生**（需军警）：预估总分 ≥ BL 且 视力≥4.8 且 性别/身高达标（< BL 不适用）。
- **司法警校招生**（需军警）：预估总分 ≥ BL 且 视力≥4.7 且 性别/身高达标（< BL 不适用）。
- **定向培养军士**（需军警）：无分数门槛，视力≥4.5 且 性别/身高达标。
- **三大招飞**（需飞行员）：两条情况（60% 满分线 / 特控线），各有英语、身高、视力、选科要求。
- **定向招生**（需农科/医学）：预估总分 ≥ BL（< BL 不适用），部分省份要求农村/县域户籍。

> 上述各路径的**精确阈值、身高/视力数值、单路径最小字段集、路径别名**一律以 `assets/pathway_rules.json` 为准，改规则时改 json + `scripts/engine.py`，改完重跑 `engine.py` verify。
