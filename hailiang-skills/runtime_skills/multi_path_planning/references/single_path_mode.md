# 单路径匹配模式（references / single_path_mode.md）

> **调用时机**：`main_mode=match_single` 时读本文件（触发条件见 SKILL.md ③-3 —— 用户在科普模式就某条路径作答后提出"我能不能报 / 适不适合我 / 帮我测一下"）。
> 只收该路径判定需要的字段，输出一张卡，不重跑推荐模式的全量收集。

---

## 子状态

`target_path` → `collect` → `output`

## 确定目标路径

对齐到引擎 `path_alias`（`assets/pathway_rules.json`）归一后的内置路径。路径名不明确先澄清；指一类的（军警类、三大专项）按类下各路径分别出单卡、只收共用字段。不在内置集合里的（引擎返回 `unsupported`）按科普作答并说明无法判定，建议走完整推荐或查官方渠道。

## 字段收集（最小集）

已给的字段不重复追问，调引擎 `match-single`，按返回的 `need_facts`（= 该路径最小字段集，见 `pathway_rules.json` 的 `single_path_min_fields`）只追缺失的。单轮集中问完，允许跳过（跳过的记未知）。需要 `tier` 但缺失时只追问省份、选科、预估总分三项。不做 preference / supplement 全量收集，不触发艺体追问。

## 判定与输出

调引擎 `match-single` 判定后出单张卡（✅ / ⚠️ 按 `verdicts` 取一种），沿用 ⑦ 的白名单与禁止暴露分数线的约束。浙江三位一体的依据统一写"学考成绩合格"。字段缺失写"需补充 X 后方可确认"。单卡就是唯一输出，不罗列其他路径。

## 收尾

附免责句，可选流转引导（`是否要我帮你做完整路径推荐（覆盖更多路径）？` 或 `还要测另一条路径吗？`），默认追加可重新匹配句。
