# 艺术体育匹配规则（references / art_sports_rules）

> **本文件规则已补充完整（2026-07-22）**。
> **触发**：主流程在「类别三 · 值得关注卡 ②」简要介绍艺体路径并追问兴趣；用户表示对**艺术升学**或**体育升学**感兴趣 → `stage = art_sports`，进入本子流程。
> **匹配结果**：命中输出「类别一 · 匹配成功卡（✅）」；高三阶段表达兴趣归入「类别二 · 谨慎判断卡（⚠️）」。体育类可多条路径同时命中。

## 子流程补充收集字段（仅问缺失项，学段沿用 profile 的「当前年级」）

| 字段 | 问法要点 | 备注 |
| --- | --- | --- |
| 方向（艺术） | 美术 / 音乐 / 播音与主持 / 表演 / 舞蹈 中具体哪类？ | 用于艺术升学逐条判定 |
| 艺术基础 | 已有特长（培训基础）还是仅升学兴趣？ | 舞蹈方向要求「特长」；高一美术/音乐/播音/表演「特长或兴趣」均可 |
| 运动员等级（体育） | 无 / 二级运动员及以上 / 一级运动员及以上？ | 决定体育单招 / 高水平运动队是否命中 |

## 艺术升学匹配规则

- **情况一**：学段 = 高一 且 （有艺术类特长 或 升学兴趣） 且 方向 ∈ {美术, 音乐, 播音与主持, 表演} → ✅ 匹配成功卡
- **情况二**：学段 = 高一 且 有艺术类特长 且 方向 = 舞蹈 → ✅ 匹配成功卡
- **情况三**：学段 = 高二 且 有艺术类升学兴趣 且 方向 ∈ {美术, 播音与主持, 表演} → ✅ 匹配成功卡
- **高三 + 对艺术感兴趣** → ⚠️ 谨慎判断卡，理由：**训练 / 备考时间不足，冲刺艺考有风险**（高一/高二为关键准备窗口，高三再起步劣势明显）。

## 体育升学匹配规则

- **体育统招**：学段 ∈ {高一, 高二} 且 有体育类升学兴趣 → ✅ 匹配成功卡
- **体育单招**：学段 ∈ {高一, 高二} 且 有体育类升学兴趣 且 运动员等级 ≥ 二级 → ✅ 匹配成功卡
- **高水平运动队**：学段 ∈ {高一, 高二} 且 有体育类升学兴趣 且 运动员等级 ≥ 一级 → ✅ 匹配成功卡
- **高三 + 对体育感兴趣** → ⚠️ 谨慎判断卡，建议：**若自身体育素质优秀，可在学校体育老师 / 教练评估下确认是否选择体育统招路线**（单招 / 高水平通常需更早的等级与赛事积累）。

## 输出与收尾

- 命中路径逐条输出「类别一 · 匹配成功卡」，给出路径名、批次（艺术统考 / 校考、体育统招 / 单招 / 高水平）、关键依据、下一步（如统考报名、校考备考、等级认证）。
- 体育类多条同命中时全部列出（如二级运动员同时命中体育统招 + 体育单招）。
- 高三情形按上归入「类别二 · 谨慎判断卡」，给具体理由 / 建议，不强行匹配。
- 子流程结束回到主流程收尾（免责提示 + 是否展开科普 / 重新匹配）。
