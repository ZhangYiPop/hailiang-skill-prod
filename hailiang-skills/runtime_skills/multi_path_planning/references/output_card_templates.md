# 卡片书写细则（references / output_card_templates.md）

> **卡片骨架内联在 SKILL.md 7.1；三类卡的判定见本文件 §5。** 这份文件管 SKILL.md 放不下的细则：字段怎么写、建议卡长什么样、一个完整示例、三类卡的判定与排序。
> 输出前读本文件，按约束写，不添加问候语、前后缀或解释。

---

## §1 字段书写约束（所有卡片适用）

**换行（硬要求，做法写死）**：每张卡固定 **5 行** —— 第 1 行「徽章 + 路径名」，第 2~5 行依次是一句话定位 / 匹配依据 / 下一步建议 / 风险提示，字段名与内容用中文冒号「：」分隔。**每两行之间空一整行**（渲染侧会把单个换行折叠成空格；行尾两个空格真机实测被吞掉，不再使用这条）。不把两个字段写在同一行，不用空格或顿号串字段。卡片之间空一行。

**匹配依据写什么**：只写用户侧的客观条件和契合点，列 1~2 个与判定直接相关的字段就够，不复述全部档案。可以写的样子——「选科符合目标专业要求」「英语成绩达到报考基本门槛」「学考成绩合格」。

**匹配依据不写什么**：任何内部设定的分数线、阈值或分数区间。下面这些表述一律不出现——

- ❌ 预估高考分数达到本科线
- ❌ 成绩超过特控线即达最低录取标准
- ❌ 英语 125 分超过 100 分最低线
- ❌ 适用区间 [454, 634] / 特控线+50 / 特控线±X

硬性门槛（视力、身高、英语成绩）只做「达标 / 未达标」的客观陈述 —— **用户自己的值和门槛值都不写**。写「预估英语成绩达标」「身高未达到该类招生要求」；不写「英语 125 分超过 100 分最低线」，也不写「身高 151cm 未达 158cm 要求」。

**浙江省三位一体（含省属三位一体）的专属口径**：这条路径不输出任何分数线、分数区间或阈值。核心依据统一写「学考成绩合格」，加上必要的选科、户籍等客观事实。例如：「学考成绩合格，满足三位一体报考基础条件」。

**徽章**：只有【✅ 匹配成功】【⚠️ 谨慎判断】【🔎 值得关注】三种，类别三统一用 🔎。

## §2 专科档附行（`tier_3` 收尾）

**触发条件**：`tier` = `tier_3` **且** ✅ 卡只剩「普通高考」一张（分数卡在本科线下、又未命中高职单招与其他路径）。此时在卡片之后附一行，不罗列任何 ❌ 路径：

```
建议同步关注高职提前招生 / 专科批次志愿，作为保底方向。
```

**不附的情形**：`tier_1` / `tier_2`（本科线上只有普通高考属正常，不必提示）；`tier_3` 已命中高职单招、或 `tier_4`（✅ 里已有专科层次路径，不重复提示）；`gaokao_province` = 不参加内地高考的（`tier` 未判，港澳台 / 华侨由「港澳台华侨招生」兜底）。

> 原「【🔎 值得关注】升学方向建议」兜底卡**已废弃**：它本用于兜「一条 ✅ 都没有」的情形，现已不再产出；零 ✅ 时按 ⑥「无内地成绩口径」如实输出（不追加兜底卡）。

## §3 完整示例（浙江军警 + 师范）

用户侧条件：浙江物理类，预估 620（≥2026 特控线 594），英语 125，选科物化，男，178cm，裸眼 4.9，职业兴趣 = 军警类 + 师范类。

应当输出的卡片：

- **匹配成功**：军校 / 公安警校 / 司法警校 / 定向培养军士 / 省属三位一体 / 普通高考，各一张 ✅ 卡
- **谨慎判断**：公费师范生 ⚠️（用户选了师范但分数未达投档线）→ 建议提升分数后尝试，或关注普通师范
- **值得关注**：三大专项 🔎（浙江达 TL，展示高校专项与地方专项条件 + 查询地址）；地区特色（浙江无 → 不展示）

白名单的效果：强基、综合评价、港澳、中外合作等因为「未选中且未自动匹配」全部不输出。

推理过程中用到的 `TL+50=645` 这类代数只是内部痕迹，**不出现在给用户看的「匹配依据」里**——用户只看到「是否达标」的结论和客观事实。

## §4 模板（逐字照抄，别自己排版）

```
【✅ 匹配成功】公安警校招生

一句话定位：面向高考生的公安类院校提前批招生，本科层次。

匹配依据：预估总分达到报考门槛；男生身高、裸眼视力均符合公安体检标准。

下一步建议：关注本省公安厅 6 月发布的报考公告，提前准备体测。

⚠️ 风险提示：体检、体测、面试、政审均为一票否决项，任一不过即失去资格。
```

对照检查：徽章原样、徽章与路径名同在第 1 行、四个字段各占一行（共 5 行、**每个字段行之间各空一整行**）、**字段行不以两个空格结尾**（换行靠空行，不靠行尾空格）、依据只有客观事实、既没有分数线数值、也没有硬门槛的门槛值。

## §5 三类卡的判定（SKILL.md 7.2 引用）

### ✅ 匹配成功

⑥判为 ✅ 的路径**全部输出、一张不漏**。排序从高相关到低：

> 身份驱动型（港澳台侨）＞ 高分自动规则型（强基 / 综合评价 / 省属三位一体）＞ 偏好驱动型（军警 / 师范 / 招飞 / 定向农科医学）＞ 普通高考兜底

`gaokao_province` = 不参加内地高考时，普通高考判 ➖不适用、不进排序；港澳台 / 华侨身份者兜底由「港澳台华侨招生」必中承担，内地考生无必中兜底（符合条件时只有身份类 / 非分数前提路径出 ✅）。

### ⚠️ 谨慎判断

**只在用户实际选中了某个职业兴趣、而 ⑥ 判 ❌ 时出现**；判 ➖不适用 的不在此列。核心是首条未满足原因，配一条可弥补建议 ——

- 视力不达标可矫正 → 提示"矫正后可达标"
- 分数不足 → 提示"冲到 X 分更有希望"
- 户籍相关 → 提示"定向类通常要求农村户籍，建议核实"

### 🔎 值得关注

四个子板块，**命中哪个展示哪个**：

**① 三大专项**：达线才展示 —— 国家专项 ≥ 本科一批线（3+1+2 / 3+3 取 TL），高校专项 ≥ TL，地方专项 ≥ BL（江苏 ≥ TL）。内容读 `three_major_programs.md`，附一句"仅供参考，请查官方通知对照户籍/学籍/分数"。都不达线则不展示。

**② 艺术体育**：这是艺体**唯一**允许出现的位置。先一句简介再追问兴趣 ——

- 艺术简介：`艺术升学分统考、校考等方向。`
- 体育简介：`体育升学分体育统招、单招、高水平运动队等路径。`
- 追问：`你对艺术或体育升学感兴趣吗？`
- 感兴趣 → `stage=art_sports`，读 `art_sports_rules.md` 补充收集并判定（高一高二满足输类别一，高三感兴趣归类别二）
- 不感兴趣 → 不展示，流程结束

艺体字段全部文本收集，不走表单。

**③ 地区特色**：命中省份时展示（适用省份见 `pathway_rules.md` §6.3，命中清单由引擎 `match` 的 `watch_region[]` 返回），标注"详情见本省考试院/招生简章"，不做匹配判定。

**④ 中外合作办学（层次冲刺提示）**：仅在 `tier_3` 且 `education_budget` ≠ 5万以上（含未答）且 `aspiration_goal` **含** 冲刺院校层次 时展示（引擎 `match` 返回 `watch_sino_foreign=true`，判定口径见 `pathway_rules.md` §6.4）。按卡片骨架写，**不出现分数线与阈值，也不评判家庭经济条件**：

```
【🔎 值得关注】中外合作办学

一句话定位：国内高校与境外高校合作举办的本科项目，部分项目可全程在国内就读。

匹配依据：你的升学目标偏向冲刺更好的院校层次，这类项目可能提供另一条进入本科层次的选择。

下一步建议：这类项目学费通常明显高于普通专业，建议按家庭预算评估；具体项目与学费以院校招生简章为准。

⚠️ 风险提示：招生计划与学费标准逐年调整，以当年官方简章为准。
```
