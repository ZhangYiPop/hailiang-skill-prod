# 省份高考模式 · 分数线口径 · 2026（references / province_lines_2026.md）

> **调用时机**：① 引擎 `compute-tier` 返回 `need_facts`（科类未知 / 缺 A·B 类 / 省份不在表）时，按本文件口径补问；② 用户当场给线 / 中途修正分数 / 更换省份 / 提到满分尺度时做复核；③ 输出阶段做「达线」判断的口径参考。
> **使用纪律**：**判档一律调 `scripts/engine.py`，不自行查表**。数值唯一出处是 `assets/province_line.json`（引擎内部读），本文件只保留**口径规则**（省份模式 / 科类判定 / 取值优先级 / 四档定义），不含数值表。**禁止凭记忆输出任何分数线数值**。
> 主文件（SKILL.md ⑤）只保留档位代号映射与引擎补问口径，其余规则以本文件为准。

## 5.1 省份高考模式与科类判定

| 模式 | 省份 | 科类判定 |
| --- | --- | --- |
| 3+3 | 北京、天津、上海、浙江、山东、海南 | 统一（不分区） |
| 3+1+2 | 河北、山西、辽宁、吉林、黑龙江、江苏、安徽、福建、江西、河南、湖北、湖南、广东、广西、重庆、四川、贵州、云南、陕西、甘肃、青海、宁夏、内蒙古 | 看首选：物理→物理类；历史→历史类 |
| 文理（老高考） | 西藏、新疆 | 按 `subject_choice`：含物理→理科；含历史→文科（与 3+1+2 同一条判据） |

> **倾向选科处理（高一/未选科）**：用户尚未选科、仅给倾向（如「偏物理」「想往历史方向」）时，按倾向首选判定科类——3+1+2 取倾向首选为物理类/历史类，老高考同样取倾向科类（含物理→理，含历史→文），3+3（浙江/山东等）不分区无需推断。据此算出的 `tier` 与匹配结果须在 4.5 复述与输出中标注「按倾向选科预判，正式选科后需复核」。
> **选科既不含物理也不含历史（含未答）** → 科类未知，**不得默认取列**：西藏 / 新疆考生在判档前正文补问一句（SKILL.md 4.1）；3+1+2 省份按「未知」处理，复述与输出中标注需补充。
> **省份不在表**（如回流生）→ 先问高考报名省份与模式；仍无法判定时请用户提供本省 TL/BL/ZL 并说明模式。
> **港澳台/华侨**：参加内地高考的一律**走分省高考**（不考虑联考），按其高考报名省份判档，与内地考生同一口径；不参加内地高考的不判档（见 SKILL.md ⑥「无内地成绩口径」）。

## 5.2 满分与命名口径

- **满分尺度**：上海 660、海南 900（标准分）、其余 750。比对前确认用户分数与线同尺度（上海/海南用户若按 750 制报分需换算，或请其按本省满分报）。
- **浙江/山东命名**：一段线 = BL（本科线）、二段线 = ZL（专科线），四档公式不变。
- **老高考特例**：西藏/新疆无特控线，TL = 本科一批线、BL = 本科二批线参与比较。
- **西藏 A/B 类**：分 A、B 两类考生取值（数据见 `assets/province_line.json`，西藏分「西藏（A类）/ 西藏（B类）」两套值）。A/B 类**不进问卷字段**，判档前由正文补问一句确认（SKILL.md 4.1）；未取得则记"未知"并标注需补充。

## 5.3 取值优先级与年份处理

1. **用户当场给线 ＞ 内置表（2026）**：以用户为准，并覆盖内置对应值。
2. **年份 ≠ 2026**：以用户给的年份线为准，并提示「分数线以当年本省考试院公布为准」。
3. **内置表缺省**：无用户提供线时用内置 2026 数据（在 `assets/province_line.json`，引擎内部读）。

## 5.4 四档划分与计算示例

设预估总分 S，对应「省份×科类」特控线 TL、本科线 BL、专科线 ZL（取值优先级见 5.3）：

| 条件 | tier |
| --- | --- |
| S ≥ TL | 特控线上 |
| BL ≤ S < TL | 一段本科线上 |
| ZL ≤ S < BL | 二段专科线上·一段本科线下 |
| S < ZL | 二段线下 |

示例：

- 浙江 3+3 统一，预估 600 → TL=594 → 600≥594 → **特控线上**。
- 河北首选物理，预估 450 → TL物=510、BL物=443 → 443≤450<510 → **一段本科线上**。
- 广东首选历史，预估 410 → TL史=546、BL史=440、ZL史=200 → 200≤410<440 → **二段专科线上·本科线下**。
- 天津 3+3 统一，预估 300 → TL=547、BL=458、ZL=110 → 110≤300<458 → **二段专科线上·本科线下**。
- 西藏 A 类文科，预估 320 → TL文=330、BL文=294 → 294≤320<330 → **一段本科线上**（TL 映射本科一批线）。

## 5.5 内置 2026 分数线（数据唯一出处已迁至 json）

**数值不再在本文件维护**。31 个省份与全部科类（统一 / 物理·历史 / 文·理、西藏 A·B 类）的 2026 分数线，已迁至 `assets/province_line.json`（58 条，字段 `province` / `subject` / `full_marks` / `TL` / `BL` / `ZL`），由 `scripts/engine.py` 判档与匹配时内部读取。数据来源：学信网·阳光高考信息平台「2026 年高考录取控制分数线」官方页面，抓取于 2026-07-20。**31 省 × 全部科类均已收录，无缺项**：判档不得因「该省分数线未收录」而挂起、降级或标注需补充。

**科类取值口径（引擎内部已实现，此处备忘）**：3+3 省份取统一列；3+1+2 按首选（含物理→物理类，含历史→历史类）取对应列；老高考（西藏 / 新疆）同样按 `subject_choice` 判科类（含物理→理科，含历史→文科），json 里西藏分 A/B 类两套值、按 `tibet_class` 取。**江西、甘肃两省的 ZL 分科类、数值不同，必须取对列**；其余省份两列数值相同，取任一列结果一致。新疆 ZL=140。

> 需要更新分数时，改 `assets/province_line.json`，改完重跑 `scripts/engine.py` 的 verify 自检，并核对 §5.1~§5.4 口径与示例是否仍与 json 一致。
