# 方向与赛事映射

> 用途一：用户询问某方向"有哪些比赛/赛事"时，按方向输出全部相关赛事名称。
> 用途二：赛事详情咨询时，通过"赛事简称对照与收录情况表"将用户输入的简称、俗称、英文缩写匹配为赛事全称，并依据"赛事库收录情况"列判断：库内已收录 → 按全称到赛事库取详情；暂无收录 → 走兜底话术。
>
> 使用规则（低自由度：MUST/禁止）：
> - MUST：赛事列表仅列出赛事名称，必须使用下方表格中的名称原文，禁止改写、缩写、附带介绍或评价。
> - MUST：全列该方向在下方表格中的全部相关赛事名称，禁止节选或自行挑选。
> - 相关赛事名单可包含赛事库之外的赛事：列表仅列名称不受影响；用户追问详情时，库内有条目的输出详情，暂无收录的统一走兜底话术（见第二节匹配规则）。
> - 禁止：在培养与升学输出（B4）中主动出现赛事信息（赛事信息仅在用户主动询问时给出）。
> - 方向名称对齐：本表中"美术特长/音乐特长/传媒特长/舞蹈特长/科学创新特长/科技体育特长"与其他知识库中的"美术/音乐/传媒/舞蹈/科学创新/科技体育"为同一方向，按同一方向处理。
> - "英语能力培养、综合能力培养、阅读素养"暂未纳入方向推荐体系，R4 不会主动推荐；保留在本表中供后续扩展，用户主动询问相关赛事时仍按第二节正常处理。
