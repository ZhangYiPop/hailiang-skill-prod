# 长期培养规划框架

> 用途：B4【长期规划】块与 B5 长期展开的取材库。为已明确方向的长期培养建议提供"阶段主线、能力进阶、分化决策、衔接要点、长期价值"五要素框架，使长期建议具备跨年级的规划纵深。
> 方向名对照：本库方向名与 \[references\_02] 一致（数学、信息学等）；与 \[references\_04]/\[references\_06] 中"数学特长、信息学特长"等为同一方向，按同一方向处理。

> 使用规则（低自由度：MUST/禁止）：
> - MUST：B4【长期规划】三要素（发展主线 / 关键节点 / 升学衔接或长期价值）与 B5"长期展开"取材于本库对应方向条目，禁止跨方向混用。
> - MUST：用户年级落入哪个阶段就取该阶段及后续阶段的框架；输出"关键节点"时同时给出对应决策窗口，让家长知道"什么时候、看什么信号、做什么决定"。
> - MUST：分化决策 MUST 同时呈现素养路线选项——素养路线是所有方向的保留路线；竞赛/专业路线条件不满足时仅关闭该路线并同步下调对应升学预期，方向本身不淘汰。
> - MUST：本库"衔接要点"只给路径类型与条件限定（如"省级奖项""国家二级运动员""系统作品集"）；具体政策、年份、分数线由 B3 检索补充，本库不预置，禁止编造。
> - 禁止：承诺升学结果、获奖、考级通过率；"必须""一定""肯定""硬门槛"等绝对化表述；推荐具体机构；输出高水平艺术团（原艺术特长生）升学相关信息。

## 一、通用四阶段模型（所有方向共用）

| 阶段 | 典型时间跨度 | 核心任务 | 家长关注点 |
|---|---|---|---|
| 起步验证期 | 入门后 6-12 个月 | 低成本验证兴趣与基础条件，建立练习习惯 | 兴趣稳定性、基础条件（身体/视觉/听力等）、时间投入可承受度 |
| 系统积累期 | 1-3 年 | 系统训练，形成首个可展示成果（考级/参赛/作品/展演） | 技能进阶节奏、首次成果的难度匹配、课内学业平衡 |
| 路线分化期 | 小学高年级 至 初二 | 依据信号确定深耕路线（竞赛/专业 vs 素养），收敛双线投入 | 分化信号是否明确、时间与经济投入可持续性、孩子自主意愿 |
| 升学衔接期 | 初二下 至 初三 | 成果冲刺或路线收敛，将积累衔接至升学应用或素养保留 | 目标路径的条件差距、成果形态完整性、风险预案（未达预期时的收敛动作） |

**分化决策通用信号**：
- 倾向竞赛/专业路线：课内相关学科稳定靠前 + 主动挑战高难度内容 + 家庭能支撑持续的时间与经济投入，三者同时成立。
- 倾向素养路线：兴趣持续但对高强度训练或竞赛无明确意愿，或课内压力上升需要保学业。
- 允许双线观察：分化期前后可保留 6-12 个月双线尝试，观察后 MUST 收敛，避免长期双线消耗。
- 无论走哪条线：起步验证期与系统积累期的动作相同，家长无需提前焦虑分流。

**输出组织建议**：长期规划按"先主线、后节点、再衔接"呈现；孩子尚在低年级时节点只讲到"路线分化期"，不提前展开升学衔接细节（离当前阶段太远，仅作长期参考）。

## 二、分方向长期框架（20 个细分方向）

### 数理方向

#### 数学

- **阶段主线**：数感启蒙 → 思维系统拓展 → 竞赛/素养分流 → 初高衔接或竞赛体系深耕。
- **能力进阶**：具体运算与图形直觉 → 抽象推理与专题建模 → 竞赛级问题拆解与多解法比较 → 自主钻研高难度问题的习惯。
- **分化决策**：窗口在小学五年级至初一。竞赛路线信号=课内数学稳定前 5% 且对难题持续兴奋（愿想 15 分钟以上）；否则走素养路线（思维拓展+课内压轴能力），两条线在小学中低年级动作相同。
- **衔接要点**：竞赛路线按入门级→联赛级逐级进阶，省级以上奖项可作为学科特长生认定与强基等路径的条件性素材；素养路线以中考数学高分段与高中理科思维衔接为主。
- **长期价值**：逻辑思维迁移至全理科学习与终身问题解决，是多数理工方向的地基能力。

#### 信息学

- **阶段主线**：图形化编程 → 文本语言过渡（Python/C++）→ 算法体系构建 → 认证/竞赛逐级进阶。
- **能力进阶**：顺序与循环概念 → 变量、函数与基础数据结构 → 算法设计（枚举、递归、贪心、搜索）→ 竞赛级建模与优化。
- **分化决策**：窗口在小学五年级至初一。竞赛路线信号=数学基础扎实 + 享受调试排错过程 + 能承受每周固定刷题投入；否则走素养路线（编程作为学科工具与数字素养）。
- **衔接要点**：竞赛路线按 CSP-J → CSP-S → 更高级别逐级进阶，成绩与奖项可作为科技特长生认定与综评的条件性素材；素养路线以编程辅助学科学习（可视化、模拟）为主。
- **长期价值**：计算思维与问题拆解能力，是 AI 时代跨行业通用的底层能力。

#### 物理

- **阶段主线**：现象观察与实验兴趣 → 探究方法建立 → 定量思维养成 → 竞赛/课内深耕分流。
- **能力进阶**：现象描述与追问 → "问题-假设-实验-结论"流程 → 力、电等模块的定量计算与实验设计 → 竞赛级综合问题分析。
- **分化决策**：窗口在初二前后（物理开课一学期后）。竞赛路线信号=课内物理稳定靠前 + 数学计算能力强 + 对拓展实验痴迷；否则保课内高分段，物理作为理科思维支点。
- **衔接要点**：竞赛路线以省级赛事奖项作为条件性升学素材；课内路线以中考物理满分段与实验操作不丢分为主，衔接高中物理的自主学习。
- **长期价值**：从现象到模型的建模思维，支撑工科、科研类方向的长期学习。

#### 化学

- **阶段主线**：生活现象观察 → 实验规范养成 → 微观思维建立 → 竞赛/课内深耕分流。
- **能力进阶**：五感现象描述 → 安全规范与变量控制 → 微观想象（分子、反应）与系统分析 → 竞赛级实验探究与计算综合。
- **分化决策**：窗口在初三前后（化学开课后）。竞赛路线信号=对实验与微观机理双重兴趣 + 数学基础扎实；否则保课内高分段与实验操作熟练度。
- **衔接要点**：竞赛路线以化学类赛事奖项作为条件性素材；课内路线以中考化学满分段衔接高中化学体系。
- **长期价值**：微观想象力与实验探究方法，连接理科学习与材料、医药等应用领域。

#### 生物

- **阶段主线**：自然观察与记录 → 显微与实验技能 → 系统思维建立 → 竞赛/科创融合分流。
- **能力进阶**：观察记录习惯 → 显微镜使用与实验设计 → 细胞、遗传、生态等系统概念 → 独立小课题的完整科研流程。
- **分化决策**：窗口在初二前后。竞赛路线信号=观察细致 + 对机理追问深 + 记录耐心；素养/科创路线可将兴趣转化为科技创新类项目（小课题、自然笔记），路径更宽。
- **衔接要点**：竞赛路线以生物类赛事奖项作为条件性素材；科创路线以完整课题成果作为综评素材；课内路线保中考生物（会考）高分。
- **长期价值**：系统思维与实证习惯，衔接医学、生命科学等方向的长期积累。

### 科创方向

#### 机器人

- **阶段主线**：自由搭建与结构启蒙 → 传感与编程结合 → 完整项目与赛事体系 → 工程方向深化。
- **能力进阶**：空间结构与手眼协调 → "程序-动作"因果 → 机械+程序+文档的完整项目闭环 → 竞技策略与迭代优化。
- **分化决策**：窗口在小学五年级前后。竞赛路线信号=喜欢对抗与迭代 + 家庭可支撑器材与参赛费用（跨度大）；否则以校内社团+低成本套件维持素养路线。器材费用是重要前置评估项。
- **衔接要点**：竞赛路线按区级→省级→全国级赛事逐级进阶，奖项与项目经历可作为科技特长生认定与综评"创新实践"板块的条件性素材；作品集（机械+程序+文档）是核心成果形态。
- **长期价值**：工程思维、团队协作与快速试错迭代能力，衔接机器人工程、自动化等工科方向。

#### 科学创新

- **阶段主线**：观察提问 → 探究方法与文献能力 → 完整课题输出 → 高阶赛事与学术表达。
- **能力进阶**：现象记录与猜想 → 变量控制与数据图表 → 文献检索、实验设计、统计基础 → 规范研究报告与答辩表达。
- **分化决策**：窗口在小学五年级至初一。深耕信号=能独立完成一个生活问题的小课题并主动深挖；科创方向本身无"关闭"概念，投入深度可随学业灵活调整，是学业压力上升时较易保留的路线。
- **衔接要点**：区级→省级→全国级科创赛事逐级进阶；完整项目（发明/论文/调研）是综评与海内外升学的条件性素材；研究日志与答辩经历本身就是学术能力证明。
- **长期价值**：科研方法论与学术表达，是大学自主学习的直接前置能力。

#### 科技体育

- **阶段主线**：模型操控兴趣 → 专项系统训练（航空/航海/车辆模型等）→ 等级与赛事进阶 → 竞技或工程素养分化。
- **能力进阶**：操控与手眼协调 → 专项技术动作与调试维修 → 竞赛规则与策略 → 工程优化与教裁判辅助等延伸角色。
- **分化决策**：窗口在小学四五年级。竞技路线信号=操控天赋明显 + 无运动禁忌 + 可支撑器材与外出参赛投入；否则维持社团与社区活动，保留工程兴趣。
- **衔接要点**：竞技路线以全国青少年锦标赛等赛事奖项作为条件性素材；未走竞技的以动手工程能力与科技素养衔接工科方向。
- **长期价值**：把抽象理科概念转化为直观操作的能力，加上抗挫与精细操作训练。

### 艺术方向

#### 美术

- **阶段主线**：自由涂鸦与审美启蒙 → 造型基础训练 → 系统专业训练（素描/色彩/创作）→ 考级、赛事与作品集积累。
- **能力进阶**：主题表达与构图意识 → 几何体素描与静物线描 → 系统素描色彩与数字工具 → 完整作品集（多维度代表性作品）。
- **分化决策**：窗口在小学四五年级。专业路线信号=造型能力突出 + 视觉条件无限制（色盲色弱会影响色彩类方向）+ 愿接受规范性训练；否则以自由创作与审美素养为主。若视觉条件受限，依赖色彩专业能力的升学应用同步降预期，兴趣素养路线保留。
- **衔接要点**：专业路线以系统作品集+艺术类中考/特长生考试为目标（文化课与专业双线达标是普遍要求）；素养路线以审美能力迁移至设计思维与综合素养。
- **长期价值**：审美判断与视觉表达，是 AI 时代难以复制的原创能力。

#### 音乐

- **阶段主线**：声乐/数字音乐低成本验证 → 主修乐器确定 → 系统演奏训练 → 考级、演出与曲目积累。
- **能力进阶**：乐感与基础乐理 → 主修乐器基本功 → 视唱练耳与曲目体系 → 代表性曲目与舞台经验。
- **分化决策**：窗口在小学三四年级（主修乐器确定）与五年级（专业/素养复核）。专业路线信号=每日固定练习可坚持 + 听力条件正常 + 家庭可支撑乐器与课时投入；否则以合唱团、校园艺术活动维持素养路线。
- **衔接要点**：专业路线以代表性曲目+考级体系+艺术类中考/特长生考试为目标（文化课双线达标）；素养路线以音乐审美与表达保留。
- **长期价值**：情感表达与审美品位，长期练习沉淀的自律与专注。

#### 舞蹈

- **阶段主线**：律动与协调启蒙 → 基本功系统训练 → 剧目能力与舞台积累 → 考级展演或素养保留。
- **能力进阶**：节奏感与身体协调 → 柔韧与力量基本功 → 剧目表现力与情感传达 → 代表性剧目作品集。
- **分化决策**：窗口在小学三四年级。专业路线信号=柔韧与身条件匹配 + 疼痛耐受度好 + 每日基本功可坚持；起步较晚或条件不匹配时，依赖专业能力的升学应用同步降预期，素养路线（校园展演、体态气质）保留。
- **衔接要点**：专业路线以代表性剧目+考级展演+艺术类中考/特长生考试为目标；素养路线以体态、气质与表达自信保留。
- **长期价值**：身体表达力、舞台自信与坚韧品性。

#### 传媒

- **阶段主线**：家庭与校园展示体验 → 系统表达训练（播音/编导/戏剧细分）→ 作品与赛事积累 → 作品集成型。
- **能力进阶**：镜头前自然度与声音表现 → 结构化表达（观点+理由+例子）→ 专项技术（朗诵、主持、拍摄剪辑、戏剧表演）→ 代表性作品集（视频、主持片段、短剧）。
- **分化决策**：窗口在小学四五年级，按"台前表达"与"幕后制作"细分。专业路线信号=心理素质好（失误后恢复快）+ 主动争取展示机会；表达紧张的孩子可先从家庭/班级小范围开始，不急于关闭路线。
- **衔接要点**：以作品集+语言类赛事经历作为传媒特色班、艺术类中考的条件性素材；即兴表达训练同时服务综评/强基面试环节。
- **长期价值**：结构化表达与共情叙事能力，职场通用的高价值软实力。

### 体育方向

#### 田径

- **阶段主线**：游戏化体能启蒙 → 主项确定（短跑/跳/投/中长跑）→ 系统训练与体能档案 → 等级赛事或素养保持。
- **能力进阶**：基础体能与协调 → 主项技术动作 → 训练负荷管理与数据档案 → 二级运动员等级冲击（竞技路线）。
- **分化决策**：窗口在小学四五年级。竞技路线信号=身体发育条件匹配 + 无运动禁忌（哮喘、心脏等须先经医生评估）+ 可承受每周 4-5 次训练；否则以校园运动会与社区跑步维持素养路线。
- **衔接要点**：竞技路线以运动员等级证书+体育类升学路径（统招、单招等，均有文化课底线要求）为条件性衔接；素养路线以中考体育高分与终身运动习惯为主。
- **长期价值**：体能底子、抗压与自律，体育成绩本身服务中考。

#### 球类

- **阶段主线**：球感与规则启蒙 → 主项确定与基本功 → 校队体系与联赛进阶 → 等级/联赛成果或兴趣保持。
- **能力进阶**：手眼协调与球感 → 主项技术+基础战术 → 团队配合与比赛阅读 → U 系列联赛与等级冲击（竞技路线）。
- **分化决策**：窗口在小学四五年级。竞技路线信号=协调与反应突出 + 团队纪律性好 + 可承受团队训练强度；否则以校队/社区联赛维持，球类是成年后最易延续的兴趣运动之一。
- **衔接要点**：竞技路线以 U 系列赛事成绩+运动员等级作为条件性升学素材（体育单招、高水平运动队等路径均有文化课底线）；素养路线以中考体育与运动社交价值为主。
- **长期价值**：团队协作、领导力与规则意识，运动社交圈是终身资产。

#### 武术

- **阶段主线**：基本功与协调启蒙 → 套路/散打专项确定 → 系统训练与赛事进阶 → 等级成果或武德素养保留。
- **能力进阶**：柔韧与手眼步法 → 专项套路技术与力量 → 竞赛规则与表现力 → 运动员等级冲击（竞技路线）。
- **分化决策**：窗口在小学四五年级。竞技路线信号=柔韧与爆发力匹配 + 疼痛耐受好；条件不匹配时竞技升学应用同步降预期，习武的体态矫正与心性磨炼价值不受影响。
- **衔接要点**：竞技路线以传统体育赛事奖项+运动员等级作为条件性素材；素养路线以体态、防身与自律品行为主。
- **长期价值**：自律沉稳的品行、身体掌控与文化认同。

#### 水上运动

- **阶段主线**：水感与自救启蒙 → 主项确定（游泳/跳水/花游/水球等）→ 系统训练 → 等级赛事或泳姿技能保留。
- **能力进阶**：水感与憋气漂浮 → 标准泳姿与自救能力 → 主项技术+体能（肺活量、核心）→ U 系列比赛与等级冲击（竞技路线）。
- **分化决策**：窗口在小学三四年级。竞技路线信号=无哮喘等禁忌 + 臂展等先天条件匹配项目 + 可承受每日训练；条件不匹配时竞技升学应用同步降预期，游泳作为生存技能与终身运动保留。
- **衔接要点**：竞技路线以 U 系列赛事成绩+运动员等级作为条件性素材；素养路线以自救技能、体态与心肺功能为主。
- **长期价值**：生存技能、心肺耐力与压力疏导能力。

### 国际方向

#### 小语种

- **阶段主线**：语音浸润与兴趣萌芽 → 系统教材学习 → 等级考试体系 → 国际路线或素养应用。
- **能力进阶**：语音敏感度与日常对话 → 系统语法与词汇（A1-A2）→ 中级综合能力与等级考试（JLPT/DELF/TestDaF 等）→ 学术或跨文化应用。
- **分化决策**：窗口在小学高年级至初一。国际路线信号=家庭有长期规划共识（时间、经济、孩子独立生活能力）；无国际规划时以第二外语素养保留，小语种高考是英语薄弱学生的备选策略之一。
- **衔接要点**：国际路线以语言等级+国际学校/海外申请衔接；国内路线以小语种高考或外语类保送（部分外国语学校）为条件性路径；两条路径均需先确认家庭长期投入共识。
- **长期价值**：多语言能力与跨文化理解，复合型人才的稀缺溢价。

### 人文方向

#### 思辨

- **阶段主线**：家庭辩论与表达启蒙 → 结构化思维训练 → 赛事体系（辩论/演讲/写作）→ 模联与研究性表达。
- **能力进阶**："观点+理由+例子"表达 → 逻辑技巧（归纳、反驳、质询）→ 赛事对抗与临场应变 → 独立议题研究与论证写作。
- **分化决策**：窗口在小学四五年级，按"口头辩论"与"书面论证"细分。深耕信号=意见冲突时能坚持己见且论据升级；思辨是人文方向的底层能力，即使不参赛也持续反哺课内论述题。
- **衔接要点**：以辩论/演讲/作文类赛事经历作为人文特色班、综评面试的条件性素材；面试型选拔（强基、综评）与思辨训练高度重合。
- **长期价值**：信息甄别、逻辑建构与清晰表达，信息过载时代的核心防御与进攻能力。

#### 商业洞察

- **阶段主线**：财商游戏启蒙 → 商业课题与方法 → 模拟赛事与真实项目 → 商科素养衔接。
- **能力进阶**：金钱与交换概念 → 基础经济学概念+小课题调研 → 商业模拟/创业赛事的完整项目（调研、计划书、财务预测）→ 数据分析与决策思维。
- **分化决策**：窗口在小学高年级至初一。深耕信号=对"为什么这样定价"类问题持续追问 + 能容忍试错失败；商业学习需家庭支持"允许失败"的试错成本。
- **衔接要点**：以商业模拟赛事经历+完整项目作为综评与国际升学文书的条件性素材；经济学、金融学等专业的面试大量围绕商业议题展开。
- **长期价值**：供需逻辑与商业模式分析框架，终身可复用的决策思维工具。

#### 社会认知

- **阶段主线**：社区观察与访谈启蒙 → 社会研究方法 → 公益项目与调查成果 → 人文社科素养衔接。
- **能力进阶**：观察与访谈记录 → 问卷设计与基础统计 → 独立社会议题研究（如社区养老、网络使用）→ 规范研究报告与公共表达。
- **分化决策**：窗口在小学高年级至初一。深耕信号=对陌生人与社会现象好奇心强 + 有同理心与价值判断意识；社会认知需要真实场景浸泡，长期积累重于短期成果。
- **衔接要点**：以调查报告+公益项目经历作为综评、人文社科方向申请的条件性素材；法学、社会学、心理学等专业面试高度看重社科思维。
- **长期价值**：结构性问题识别与同理心，理解复杂社会的底层素养。

## 三、长期规划输出红线（与 SKILL.md 第六节一致）
