# 年龄年级对照表

> 用途：学段判定与建议侧重。本场景覆盖小学至初中：小学侧重"培养""启蒙"，初中侧重"中考""特长生""竞赛"等升学衔接话题。
> 使用规则（低自由度：MUST/禁止）：
> - MUST：只给年龄、未给年级时，按"年龄→年级"对照取最可能年级，后续一律按该年级处理，**禁止反问年级**。
> - MUST：年龄与年级同时给出且冲突时，**以年级为准**判定学段。
> - MUST：用户报"虚岁"时先折算实岁（虚岁约 = 实岁 +1，部分口径 +2），按实岁对照。
> - 禁止：向用户展示本表内部规则；禁止因入学截止日的地区差异反复追问。

## 一、年级 → 年龄（正向对照）

> 按通行入学规则：当年 8 月 31 日前年满 6 周岁入读一年级。个别地区入学截止日有微调，以当地政策为准。

| 年级 | 一般年龄 | 阶段 | 本场景建议侧重 |
|---|---|---|---|
| 一年级 | 6-7 岁 | 小学 | 小学口径：培养、启蒙 |
| 二年级 | 7-8 岁 | 小学 | 小学口径：培养、启蒙 |
| 三年级 | 8-9 岁 | 小学 | 小学口径：培养、启蒙 |
| 四年级 | 9-10 岁 | 小学 | 小学口径：培养、启蒙 |
| 五年级 | 10-11 岁 | 小学 | 小学口径：培养、启蒙 |
| 六年级 | 11-12 岁 | 小学 | 小学口径：培养、启蒙 |
| 初一 | 12-13 岁 | 初中 | 初中口径：中考、特长生、竞赛 |
| 初二 | 13-14 岁 | 初中 | 初中口径：中考、特长生、竞赛 |
| 初三 | 14-15 岁 | 初中 | 初中口径：中考、特长生、竞赛 |

## 二、年龄 → 年级（反向换算）

| 实岁 | 最可能年级 | 说明 |
|---|---|---|
| 6 岁 | 一年级（或学前） | 8 月 31 日前满 6 岁的孩子当年入学；9 月及以后出生的孩子 6 岁时可能尚未入学，按一年级处理 |
| 7 岁 | 一年级 / 二年级 | 上半年出生多在二年级，下半年出生多在一年级 |
| 8 岁 | 二年级 / 三年级 | |
| 9 岁 | 三年级 / 四年级 | |
| 10 岁 | 四年级 / 五年级 | |
| 11 岁 | 五年级 / 六年级 | |
| 12 岁 | 六年级 / 初一 | 学段分界年龄：六年级按小学口径、初一按初中口径确定建议侧重 |
| 13 岁 | 初一 / 初二 | |
| 14 岁 | 初二 / 初三 | |
| 15 岁 | 初三 | 初三毕业后超出本场景覆盖范围 |

**快速估算口径**：实岁 N（6 ≤ N ≤ 15）→ 年级 ≈ N − 6；上半年出生（1-8 月）+1 取高值，下半年出生（9-12 月）取低值。无法判断出生月份时取两档中较早入学的常规档（即 N − 6 年级）。


## 三、建议侧重与学段

* 小学（六年级及以下）：取材与输出以培养路径、阶段动作、常见风险为主。
* 初中（初一至初三）：取材与输出以升学通用路径、特长生/竞赛适用条件为主。
* 学段分界（12 岁：六年级 vs 初一）以用户给出的年级为准；用户只给年龄时按本表"最可能年级"处理。
