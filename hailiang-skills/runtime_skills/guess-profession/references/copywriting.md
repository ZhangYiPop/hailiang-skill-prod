### B. 社交场景池与场景引入

#### B-1. 社交场景池（中性场所·NPC 以普通人身份出现）
> 推荐场景池，AI 可从中随机选取或自由发明同类场景。
> **硬性约束**：场景必须是陌生人自然相遇的中性社交场所；NPC 在场景中是顾客/路人/乘客/访客，**绝不在上班**。

| 场景 | NPC 身份 | 相遇方式 |
|------|---------|---------|
| 咖啡馆 | 排队的顾客 | 并排排队等候，随口搭话 |
| 公园长椅 | 休息的路人 | 坐在同一张长椅上，天气话题切入 |
| 书店 | 翻书的读者 | 同一书架前伸手拿同一本书 |
| 机场候机厅 | 等航班的旅客 | 邻座，航班延误闲聊 |
| 社区菜市场 | 买菜的居民 | 挑菜时碰巧伸手拿同一把 |
| 火车站候车室 | 等车的旅客 | 邻座，帮忙看行李 |
| 宠物公园 | 遛狗的主人 | 狗互相嗅闻，主人顺势聊天 |
| 小区快递柜 | 取快递的邻居 | 同时到快递柜取件 |
| 雨天屋檐 | 躲雨的路人 | 一起等雨停 |
| 超市收银台 | 排队的顾客 | 前后排队，闲聊几句 |
| 地铁换乘通道 | 匆匆的路人 | 撞了一下肩，对方道歉时搭话 |
| 博物馆展厅 | 参观的游客 | 在同一件展品前驻足 |
| 商场美食广场 | 吃饭的顾客 | 拼桌时聊起来 |
| 社区义卖活动 | 逛摊位的居民 | 在同一个摊位前驻足 |
| 共享办公休息区 | 喝咖啡的自由职业者 | 咖啡机旁排队闲聊 |

#### B-2. 场景引入示例（AI 可自由生成）
> 以下为示例；实际运行时 AI 基于随机场景自由生成引入文案，**必须确保 NPC 以普通人身份出现，不暴露职业**。

- 咖啡馆排队：`☕ 咖啡馆排队的队伍有点长，前面的人回头看了你一眼："今天人真多啊……估计得等十分钟。"(TA 看起来挺健谈，聊聊？)`
- 公园长椅：`🌳 公园长椅上，TA 拆了个三明治，看见你走过来挪了挪位置："坐吧，今天太阳不错。"(TA 看起来挺闲适，搭个话？)`
- 书店：`📚 书店里 TA 正踮脚够最上面那本书，差点没站稳："哎——这本怎么放这么高……"(TA 看起来需要帮忙，搭个手？)`
- 机场候机：`✈️ 航班又延误了，TA 叹了口气把手机扣在腿上："第三回了……你也是这班？"(同病相怜，聊聊？)`
- 菜市场：`🥬 菜摊前 TA 拎着个布袋挑西红柿，手速奇快："你看这个，捏一下就知道生不生。"(TA 挑菜的手法不太像普通人，聊聊？)`

### C. 轮次进度提醒
- 第 4 轮：`📍 进度 4/10 · 线索收集得怎么样啦？还差一口气～`
- 第 7 轮：`📍 进度 7/10 · 时间过半！再聊两句就能锁定了。`
- 第 10 轮：`⌛ 进度 10/10 · 最后一轮自由聊天，下一条消息进抢救卡——`

### D. 紧迫感（8-10 轮，融入虚拟人物台词）
> 设计提示：在 8 轮后，让虚拟人物的回复里自然出现"我快到了/待会还有事"，强化倒计时感，但不另起系统提示，保持沉浸。

### E. 猜测反馈
- 命中：`✅ 猜对了！就是「<职业>」！`
- 偏离：`❌ 不对哦～ 但你的方向有点靠近"/统筹"那块，再挖挖。`
- 模糊：`🤔 这不算明确猜测哦，用「猜 XXX」再试一次？`
