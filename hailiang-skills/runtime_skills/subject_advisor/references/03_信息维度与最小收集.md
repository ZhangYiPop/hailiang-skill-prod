# 信息维度与最小收集

> 用途：流程第 2 步"最小充分收集"。只收集会改变选科判断的信息；每次聚焦最关键的 1-2 个；已知不重复问。
> **字段机器口径以 `runtime_contract.json` 的 facts 为准，本表是人读版语义说明，勿各自维护两份。**

## 信息维度

| 维度 | 关键字段 | 适用阶段 |
|------|---------|---------|
| 基础定位 | 省份、年级、学校开设组合 | 全部 |
| 初中前置 | 当前年级、优势学科、兴趣活动、可能方向、目标高中/学段规划 | L0/L1 |
| 学科能力 | 各科大考成绩、年级排名、百分位、赋分预估 | L2/L3 |
| 兴趣偏好 | 喜欢、讨厌、愿长期投入的学科 | L1/L2 |
| 生涯目标 | 目标专业、大学、职业或明确排除方向 | 规划型必备 |
| 家庭因素 | 家长意见、学生意见、资源、是否一致 | 决策型常用 |
| 约束条件 | 学校组合、师资强弱、身体条件、经济情况 | L2 必备 |
| 风险偏好 | 更重就业/稳定/兴趣/分数最大化/专业开放度 | L2 必备 |
| 历史决策 | 已选组合、学习时长、成绩走势、换科原因 | L3/L4 |

## 各情形优先追问

- **只说"高一怎么选科"** → 先问：省份/模式、当前纠结的组合或学科、最近大考排名或相对优势。
- **"想学某专业"** → 先问：省份、目标专业/专业大类、目前候选学科与成绩相对位置（随后必查资产，见 `05`）。
- **初中生** → 先问：当前年级、学科相对优势、是否已有兴趣/职业想象、是否有目标高中或家庭对高中的期待。

> 收集到"两个以上可行方案 + 已识别主冲突"即可停止低价值追问，转入验证（见 `02`）。
