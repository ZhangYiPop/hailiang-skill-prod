# 选科要求结构化资产说明（单一信源）

> 本文是选科资产的**唯一权威说明**（SKILL.md 不重复，只给最短调用与红线）。资产把《2021 全国选科通用指引》Excel 结构化为 JSON，供 `subject_requirements` 工具查询，避免凭印象给选科要求。

## 资产与脚本

| 项 | 路径 |
|----|------|
| 结构化资产 | `assets/subject_selection/subject_requirements.json`（约 879 条） |
| 查询脚本 | `scripts/subject_requirements_lookup.py` |
| 构建脚本 | `scripts/build_subject_requirement_asset.py`（源 Excel 更新时重新生成资产） |
| 数据口径 | 2021 年《普通高校本科招生专业选考科目要求指引（通用版）》，适用 `3+3` 与 `3+1+2` 的通用最低要求 |

## 调用方式

```bash
# 按专业查最低要求
python scripts/subject_requirements_lookup.py --major "临床医学"
# 校验某组合能否报某专业
python scripts/subject_requirements_lookup.py --major "临床医学" --subjects "物理,化学"
# 按职业（内部会先映射专业类）
python scripts/subject_requirements_lookup.py --career "医生"
# 某组合能报哪些专业大类
python scripts/subject_requirements_lookup.py --subjects "物理,化学"
# 自然语言
python scripts/subject_requirements_lookup.py --query "想学计算机能不能只选物理"
```

返回 JSON 字段：`query_type`、`results[]`（每条 `major_category / major_name / minimum_requirement / required_subject_groups / compatibility`）、`compatibility_summary`、`warnings`、`interpretation_hints`。按 `interpretation_hints` 组织对用户的解释。

## 字段语义

| 字段 | 含义 |
|------|------|
| `major_category` / `major_name` | 专业类 / 专业名，筛选用 |
| `minimum_requirement` | 通用最低选科要求（高校可在此基础上加码，≠院校最终要求） |
| `required_subject_groups` | 解析后的可满足科目组：外层任选一组、内层科目全满足。如 `不限→[[]]`，`物化→[["物理","化学"]]`，`物理+化学/生物→[["物理","化学"],["物理","生物"]]` |
| `compatibility` | 候选组合对该专业的满足情况（如 `eligible/not_eligible/unknown_no_source`） |

## 必须查资产的场景【硬】

- 问明确专业类/方向的选科要求（医学、工科、法学、计算机…）；
- 问职业目标对应专业的选科要求（医生、程序员、律师、警察…）；
- 问某组合能报哪些专业（"物化能报什么""只选物理能读计算机吗"）；
- 出方案/复核前，校验候选组合是否覆盖目标专业/职业。

## 查询与解释规则

- **职业诉求**：先映射到专业/专业类，再查；不能从职业直接跳科目结论。
- **组合覆盖诉求**：概括专业大类和风险，不一次性罗列全部专业。
- **方案校验**：命中 `not_eligible` 必须说明缺哪些科目；命中 `unknown_no_source` 必须说"源资产未给要求"，**不得当作"不限"**。

## 使用边界【硬】

- 全国通用最低要求，**≠某省/某年/某高校最终招生要求**；涉及具体院校/专业组/年份，提醒核实当年本省考试院与高校招生章程。
- 空白要求 = 源文件未给出，**不能解释为"不限"**。
- 2021 后新增专业若源文件无对应项，只能参考所属专业类，不下确定结论。
- 对用户**不暴露** id / 源行号 / 文件路径 / 脚本名，统一表述"按当前通用指引"。
