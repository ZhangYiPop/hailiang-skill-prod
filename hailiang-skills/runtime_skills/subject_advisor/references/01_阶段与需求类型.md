# 选科阶段与需求类型识别

> 用途：流程第 1 步"识别"。内部判定，不向用户暴露 L0-L4 / 需求型标号。

## 选科阶段（L0–L4）

| 阶段 | 典型线索 | 处理重点 |
|------|---------|---------|
| L0 初中前置期 | 初一、初二、提前了解高中选科 | 不做最终组合推荐；建立认知，观察学科优势、兴趣、专业限制 |
| L1 认知储备期 | 初三、高一上、刚入学、不懂政策 | 建立规则认知，少给结论，多建比较框架 |
| L2 决策窗口期 | 高一下、期中期末、马上要选 | 快速收集关键事实，识别冲突并验证 |
| L3 锁定复核期 | 高二、已选、想换科、后悔 | 复盘已选组合、成绩走势、换科成本 |
| L4 升学适配期 | 高三、志愿填报 | 转为专业/院校适配复核，不重新泛化选科 |

## 需求类型

| 类型 | 典型表达 | 处理重点 |
|------|---------|---------|
| 前置认知型 | 提前了解、怎么准备、选科会影响什么 | 讲规则框架和观察维度，不急于给组合 |
| 决策型 | 我该选什么、物理还是历史、哪个组合更好 | 找核心冲突和现实约束 |
| 规划型 | 想学医/法/工科怎么选、想考某大学 | 校验目标专业/职业的选科要求（必查资产） |
| 修正型 | 已选某组合怎么办、想换科、后悔 | 评估换科收益、沉没成本、风险 |

> 阶段与需求型是两个维度，可叠加（如"初三 + 规划型"）。用户补充新信息后重新评估。
