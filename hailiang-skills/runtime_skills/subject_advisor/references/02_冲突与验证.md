# 冲突标签、验证问题与边界情况

> 用途：流程第 3 步"诊断"。识别用户无法自行判断的核心矛盾，区分主冲突/次冲突，再用验证问题区分方案。

## 冲突标签

| 标签 | 含义 |
|------|------|
| 自我认知冲突 | 喜欢的学科成绩一般，擅长的学科不喜欢 |
| 生涯目标冲突 | 目标专业与喜欢/擅长学科不匹配 |
| 家庭协同冲突 | 家长强参与，学生与家长意见不同 |
| 风险决策冲突 | 怕后悔、怕专业受限、怕就业不好 |
| 成绩优化冲突 | 以高考分数最大化为目标，兴趣权重低 |
| 认知缺失型 | 没有明确兴趣、专业或方向 |
| 资源约束型 | 学校开设组合、师资、身体、经济受限 |
| 复合冲突型 | 同时符合多个冲突 |
| 无明显冲突型 | 只需规则解释或方案复核 |

## 验证问题库（用于区分方案，问能改变结论的）

- **情境选择题**：A 组合分数更稳但专业面窄，B 组合更累但专业面宽，你更难接受哪种代价？
- **遗憾测试**：三年后最不想后悔的是"专业受限"，还是"为开放度选了不适合自己的学科"？
- **价值排序测试**：分数最大化 / 专业开放度 / 兴趣投入 / 就业稳定，哪个排第一？
- **机会成本测试**：若选物理需多投入约 30% 时间，你愿不愿意接受？

> 诊断结论门槛：核心冲突已识别 + 关键信息足够 + 至少完成 1 次关键验证 + 主要风险可解释，才进入方案生成（见 `04`）。

## 边界情况处理

| 情况 | 处理方式 |
|------|---------|
| 抑郁/自伤倾向 | 立即停止选科分析，共情 + 引导联系学校心理老师或心理援助热线（详见 SKILL 安全边界） |
| 要求预测高考分/录取概率 | 说明无法预测；可帮其找"不同分数下都相对不后悔"的组合 |
| 传统文理地区 | 切换传统文理模式，强调院校/专业的文理分科限制 |
| 完全无关话题 | 说明本场景专注新高考选科；回到选科困扰可继续 |
| 问具体高校专业要求 | 可给通用判断，但必须提醒核实当年本省《选考科目要求》与招生章程 |
| 学校不开某组合 | 先评估校内相近组合，再谈转班/转校/自学成本，不直接推荐不可执行组合 |
