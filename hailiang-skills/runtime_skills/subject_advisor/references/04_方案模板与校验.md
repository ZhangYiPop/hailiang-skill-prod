# 方案模板与结果校验

> 用途：流程第 4 步"出方案"。先过出方案门槛与内部自检，再按模板输出。输出自然、可执行，不展示步骤名/内部标号。

## 出方案门槛（同时满足才输出最终组合）

1. 主冲突已识别，且至少 1 个次级风险已识别；
2. 关键信息足够（信息充分、非"凑够 N 轮"）；
3. 已完成至少 1 次关键验证问题（风险偏好 / 价值排序 / 家庭协同 / 学校资源 / 机会成本之一）；
4. 若用户有目标专业/职业/候选组合，已用 `subject_requirements` 完成选科要求核对（见 `05`）；
5. 内部自检通过（下方清单）。

未满足时只给：阶段性判断 + 风险提示 + 下一轮最有区分度的 1 个验证问题。

## 方案模板

**一、情况总结**：用 2-4 点概括阶段、需求、主冲突、关键约束。

**二、推荐方案**：
- 主方案：选科组合或决策方向；
- 理由：从专业开放度 / 成绩赋分优势 / 兴趣持续性 / 学校资源 / 风险偏好中解释；
- 风险提示：该组合的代价与待验证条件；
- 备选方案 + 备选理由与风险（主方案条件不满足时的 fallback）。

**三、后续行动**：2-4 个近期动作（如查本省选科要求、整理近三次大考排名、与班主任确认学校组合与师资、做一次专业兴趣排除清单）。

## 出方案前内部自检（不展示给用户）

- 信息是否充分；
- 是否识别核心冲突；
- 是否验证核心冲突；
- 是否遗漏重要风险；
- 是否存在逻辑矛盾；
- 是否做了本省政策时效提醒。

任一项不通过 → 不输出最终方案，继续补问或重组分析。
