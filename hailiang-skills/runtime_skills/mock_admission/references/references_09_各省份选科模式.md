# references_09：各省份选科模式

> 本文件用于层级判定前确定用户所在省份的选科模式与科类取数方式，是"是否需要询问首选科目"的唯一判断依据。

## 使用说明

1. 获取用户省份后，先查本表确定选科模式，再决定是否询问首选科目：
   - **3+3 省份**：无需任何选科信息，直接对照省份层次表的"分数要求"列判定层级。
   - **3+1+2 省份**：**必须先获取首选科目（物理/历史）**，再按省份层次表的"物理组/历史组"列判定。再选科目（化学、生物、政治、地理）不影响层级判定，禁止追问。
   - **文理（老高考）**：本场景覆盖的 7 个省份不涉及此模式；西藏、新疆用户按未覆盖省份兜底话术处理。
2. 首选科目缺失时，与其他缺失信息一次性合并询问，禁止为此单独追加一轮提问。
3. 本场景覆盖省份对照：3+3——浙江、山东；3+1+2——江苏、安徽、湖北、四川、内蒙古。

## 选科模式总表

| 模式 | 省份 | 科类判定方式 |
| --- | --- | --- |
| 3+3 | 北京、天津、上海、浙江、山东、海南 | 统一（不分区） |
| 3+1+2 | 河北、山西、辽宁、吉林、黑龙江、江苏、安徽、福建、江西、河南、湖北、湖南、广东、广西、重庆、四川、贵州、云南、陕西、甘肃、青海、宁夏、内蒙古 | 看首选科目：物理→物理类；历史→历史类 |
| 文理（老高考） | 西藏、新疆 | 文科 / 理科（用户须说明文或理） |
